## 이름이 같거나 비슷한 것

| 헷갈리는 짝 | 차이 | 세션 |
|---|---|---|
| **pgvector** vs **PGVector** | PostgreSQL 확장(벡터 타입·거리 연산자·ANN 인덱스) vs LangChain 클래스(임베딩·SQL 생성·Document 변환). ⚠️ PGVector는 ANN 인덱스를 **자동으로 만들지 않는다** → 없으면 전수 검색 (검증 04-4) | [04](04_벡터저장소_PGVector.md) |
| **top-k의 k** vs **RRF의 k(c)** | 몇 개 가져올지 vs RRF 공식 안의 상수(보통 60). LangChain은 RRF 쪽을 `c`라고 부름 | [06](06_BM25와_하이브리드검색.md) |
| **BM25** vs **BM25Okapi** vs **BM25Retriever** | 수학 공식 vs 공식을 계산하는 rank_bm25 클래스 vs LangChain 리트리버 포장 | [06](06_BM25와_하이브리드검색.md) |
| **JSON** vs **JSONB** | 원본 그대로 저장(느린 검색) vs 이진 변환 저장(빠른 검색·인덱스 가능) | [04](04_벡터저장소_PGVector.md) |
| **Bi-Encoder** vs **Cross-Encoder** | 따로 임베딩 후 코사인(빠름) vs 붙여서 함께 인코딩 후 0~1 분류(정확) | [07](07_리랭킹과_압축.md) |

## 값의 방향이 반대인 것

| 헷갈리는 짝 | 비슷하면 | 세션 |
|---|---|---|
| **코사인 유사도** | 1에 가까움 (범위 -1 ~ 1) | [02](02_임베딩과_유사도.md) |
| **코사인 거리** = 1 − 유사도 | 0에 가까움 (범위 0 ~ 2) | [02](02_임베딩과_유사도.md) |
| **관련도 점수** = 1 − 거리 | 1에 가까움. ⚠️ 계산하면 **코사인 유사도와 같은 값**이라 이론상 -1 ~ 1. LangChain은 0~1을 기대하고 벗어나면 경고만 (검증 02-10) | [02](02_임베딩과_유사도.md), [05](05_리트리버와_RAG체인.md) |
| **유클리드 거리** | 0에 가까움 | [02](02_임베딩과_유사도.md) |
| **내적** vs **코사인** | ✅ 길이가 1로 정규화된 벡터면 **정확히 같다**. OpenAI 임베딩은 이미 정규화되어 나와서 코사인·유클리드 순위도 같다 (검증 02-7) | [02](02_임베딩과_유사도.md) |

- `similarity_search_with_score` → **거리** (작을수록 좋음)
- `similarity_search_with_relevance_scores`, `score_threshold` → **관련도** (클수록 좋음)

## "어떻게" vs "어디에"

| 축 | 선택지 |
|---|---|
| 어떻게 찾나 (검색 방식) | 키워드(BM25, sparse) / 의미(벡터, dense) / 하이브리드 |
| 어디에 두나 (저장 위치) | 메모리(BM25Retriever, InMemoryVectorStore) / 디스크(PGVector, Elasticsearch) |

→ 두 축은 별개다. Elasticsearch는 키워드 + 벡터를 둘 다 디스크에. ([06](06_BM25와_하이브리드검색.md))

## 평가 지표

| 짝 | 차이 | 세션 |
|---|---|---|
| **정밀도** vs **재현율** | 가져온 것 중 맞는 비율 TP/(TP+FP) vs 있어야 할 것 중 찾은 비율 TP/(TP+FN) | [09](09_RAG평가_지표.md) |
| **일반 정밀도** vs **RAGAS Context Precision** | ⚠️ 순서 상관없이 맞은 비율 vs **순위를 반영한 평균 정밀도**(관련 문서가 위에 있을수록 높음). 5개 중 3개가 맞아도 1~3위면 1.0, 3~5위면 약 0.48 (검증 09-2) | [09](09_RAG평가_지표.md) |
| **FP** vs **FN** | 잘못 가져옴(노이즈) vs 놓침 | [09](09_RAG평가_지표.md) |
| **Faithfulness** vs **Answer Relevancy** | 답이 문서에 근거했나(환각) vs 질문에 맞게 답했나(동문서답) | [09](09_RAG평가_지표.md) |
