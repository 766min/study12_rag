## 복습하는 방법 (추천)

1. 세션 맨 위 **"지금 위치"** 를 보고 전체 흐름 중 어디인지 먼저 떠올립니다.
2. **핵심 질문**에 내 말로 먼저 답해 본 다음 본문을 읽습니다.
3. 맨 아래 **스스로 점검** 질문에 답을 펼치기 전에 먼저 답해 봅니다.
4. **이 방식의 한계 → 다음 세션**을 읽고, 다음 세션이 왜 필요한지 말로 설명할 수 있으면 넘어갑니다.
