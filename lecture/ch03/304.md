## 2. 메타데이터 필터링의 원리와 필요성

<aside>
💡

<u>**메타데이터 필터링(Metadata Filtering)**</u>
문서마다 붙어 있는 속성 정보(일종의 '이름표')를 기준으로 검색 후보군을 사전에 압축하는 기술입니다. 단순히 벡터 유사도에만 의존할 때 생기는 모호함을 없애고, 작성 일자나 담당 부서, 문서 카테고리처럼 명확한 사실(Fact) 조건을 충족하는 문서만 정확히 골라내어 검색 품질을 크게 높입니다.

</aside>

### 2.1 유사도 검색의 한계와 메타데이터의 역할

<aside>

- **의미 유사도의 한계**: 벡터 검색은 의미적 유사성을 기반으로 탐색하므로, 2023년 규정과 2024년 규정처럼 문장 구조가 유사한 경우 구 버전 문서를 오답으로 가져올 위험이 있습니다.
- **사전 필터링(Pre-filtering)**: 벡터 거리를 계산하기 전 메타데이터 조건을 먼저 평가하여 조건에 맞지 않는 문서를 계산 대상에서 즉시 제외합니다.
- **연산 효율 향상**: 전체 벡터가 아닌 조건을 만족하는 특정 그룹 내에서만 검색을 수행하므로 검색 속도와 정확도가 동시에 향상됩니다.
</aside>

### 2.2 PGVector의 메타데이터 문법 구조

<aside>

- **JSONB 기반 속성 보관**: PGVector는 문서의 부가 속성을 JSON 구조(`metadata`)로 데이터베이스에 저장합니다.
- **단일 조건 문법**: `filter={"category": "장학"}` 형태로 특정 키와 값의 일치 여부를 지정합니다.
- **다중 조건 문법**: `filter={"category": "장학", "year": 2024}` 형태로 여러 조건을 딕셔너리에 함께 나열합니다.
</aside>

## 3. 메타데이터 기반 벡터 검색 실습

<aside>
💡

문서 본문과 메타데이터를 벡터 저장소에 함께 적재한 뒤, 특정 조건에 따라 필터링된 검색 결과를 직접 확인하고 검증합니다. 이전 차시에서 다룬 대학 규정 데이터를 한 단계 확장하여, 시행 연도와 규정 카테고리(학사, 장학, 행정 등) 정보가 포함된 구조화된 벡터 컬렉션을 구축해 봅니다.

</aside>

### 3.1 메타데이터를 포함한 규정 데이터 등록

<aside>

본문 텍스트와 메타데이터 딕셔너리를 포함하는 `Document` 객체를 생성하여 데이터베이스에 저장합니다.

```python
import os
from dotenv import load_dotenv
from langchain_core.documents import Document
from langchain_openai import OpenAIEmbeddings
from langchain_postgres.vectorstores import PGVector

load_dotenv()

embeddings_model = OpenAIEmbeddings(
    model="text-embedding-3-small"
)

# 데이터베이스 연결 주소를 확인합니다.
connection_url = os.getenv("DATABASE_URL")

# PGVector 벡터 저장소 컬렉션에 연결합니다.
vector_store = PGVector(
    embeddings=embeddings_model,
    collection_name="metadata_university_rules",
    connection=connection_url,
    use_jsonb=True
)

# 메타데이터가 포함된 규정 문서를 구성합니다.
sample_rules = [
    Document(
        page_content="[2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    ),
    Document(
        page_content="[2023년 구 장학 규정] 직전 학기 평점 3.5 이상 취득 시 전액 장학금을 지급합니다.",
        metadata={"category": "scholarship", "year": 2023, "target": "undergraduate"}
    ),
    Document(
        page_content="[2024년 도서관 규정] 학부생은 1인당 최대 7권까지 21일간 도서를 대출할 수 있습니다.",
        metadata={"category": "library", "year": 2024, "target": "undergraduate"}
    ),
    Document(
        page_content="[2024년 대학원 규정] 대학원생 연구 장학금은 지도교수 추천서를 필수로 제출해야 합니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "graduate"}
    )
]

# 문서를 벡터 저장소에 추가합니다.
vector_store.add_documents(sample_rules)
print("메타데이터를 포함한 규정 문서 적재 완료")
```

</aside>

### 3.2 필터 유무에 따른 검색 결과 비교

<aside>

필터 없이 검색했을 때와 카테고리 필터를 적용했을 때 반환되는 문서 차이를 확인합니다.

```python
# 테스트 질의를 정의합니다.
query = "장학금 지원 기준을 알려줘"

# 메타데이터 필터 없이 유사도 검색(Top-k=2)을 실행합니다.
raw_results = vector_store.similarity_search(query=query, k=2)

print("=== [필터 미적용 검색 결과] ===")
for idx, doc in enumerate(raw_results, 1):
    print(f"[{idx}위 문서]")
    print(f" - 본문: {doc.page_content}")
    print(f" - 메타데이터: {doc.metadata}")

# 2024년도 장학금 규정만 선별하는 필터를 적용합니다.
target_filter = {
    "category": "scholarship",
    "year": 2024,
    "target": "undergraduate"
}

filtered_results = vector_store.similarity_search(
    query=query,
    k=2,
    filter=target_filter
)

print("\n=== [복합 메타데이터 필터 적용 검색 결과] ===")
for idx, doc in enumerate(filtered_results, 1):
    print(f"[{idx}위 문서]")
    print(f" - 본문: {doc.page_content}")
    print(f" - 메타데이터: {doc.metadata}")
```

```
=== [필터 미적용 검색 결과] ===
[1위 문서]
 - 본문: [2024년 대학원 규정] 대학원생 연구 장학금은 지도교수 추천서를 필수로 제출해야 합니다.
 - 메타데이터: {'year': 2024, 'target': 'graduate', 'category': 'scholarship'}
[2위 문서]
 - 본문: [2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.
 - 메타데이터: {'year': 2024, 'target': 'undergraduate', 'category': 'scholarship'}

=== [복합 메타데이터 필터 적용 검색 결과] ===
[1위 문서]
 - 본문: [2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.
 - 메타데이터: {'year': 2024, 'target': 'undergraduate', 'category': 'scholarship'}
```

## 4. LLM 모델과 연동한 답변 생성

<aside>
💡

<u>**필터링된 문맥만을 LLM에 전달하여 연도 왜곡 없는 일관된 답변을 도출합니다.**</u>
구 버전 규정 문서가 모델 입력으로 들어가는 것을 원천 차단하여 최신 규정만을 바탕으로 응답하도록 제어합니다. 

</aside>

### 4.1  LLM 모델 연동 및 질의응답 함수 구현

<aside>

메타데이터 필터 조건으로 정제된 문서를 LLM 모델의 프롬프트 문맥으로 주입합니다. 

```python
from langchain.chat_models import init_chat_model
from langchain_core.messages import SystemMessage, HumanMessage

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0 # 일관된 사실 기반 답변 생성을 위해 0으로 설정합니다.
)

# 메타데이터 필터를 지원하는 질의응답 함수를 정의합니다.
def generate_rag_answer(user_query: str, search_filter: dict = None, k: int = 2):
    # 메타데이터 필터 조건이 있으면 전달하고 없으면 기본 유사도 검색을 수행합니다.
    if search_filter:
        retrieved_docs = vector_store.similarity_search(query=user_query, k=k, filter=search_filter)
    else:
        retrieved_docs = vector_store.similarity_search(query=user_query, k=k)
    
    # 검색된 문서가 없는 경우 안내 메시지를 반환합니다.
    if not retrieved_docs:
        return "조건에 일치하는 관련 규정을 찾을 수 없습니다."

    # 검색된 문서 본문을 결합하여 문맥(Context)을 생성합니다.
    context_text = "\n\n".join([d.page_content for d in retrieved_docs])

    # 시스템 및 사용자 프롬프트 메시지를 구성합니다.
    messages = [
        SystemMessage(content=(
            "당신은 대학 행정 규정 안내 비서입니다.\n"
            "반드시 아래 제공된 [참고 문서] 내용만을 근거로 정확하게 답변하세요.\n\n"
            f"[참고 문서]\n{context_text}"
        )),
        HumanMessage(content=user_query)
    ]

    # LLM을 호출하여 최종 답변을 생성합니다.
    response = model.invoke(messages)
    return response.content
```

</aside>

### 4.2 필터 조건에 따른 생성 응답 검증

<aside>

필터 적용 전후의 답변 내용을 비교하여 최신 기준이 정확히 반영되는지 검증합니다.

```python
# 실행할 질문을 정의합니다.
test_query = "학부생 전액 장학금 받으려면 평점 몇 점이어야 하나요?"

# 필터 없이 실행한 경우
print("[1. 필터 미적용 시 모델 응답]")
print(generate_rag_answer(user_query=test_query))
print("-" * 50)

# 2024년도 학부 규정 필터를 적용한 경우
print("[2. 2024년 학부 규정 필터 적용 시 모델 응답]")
scholarship_filter_2024 = {
    "category": "scholarship",
    "year": 2024,
    "target": "undergraduate"
}
print(generate_rag_answer(user_query=test_query, search_filter=scholarship_filter_2024))
```

```
[1. 필터 미적용 시 모델 응답]
최신 규정(2024년 개정)에 따르면 직전 학기 평점이 3.8 이상이면 전액 장학금을 받을 수 있습니다. (참고로 2023년 규정은 3.5 이상이었습니다.)
--------------------------------------------------
[2. 2024년 학부 규정 필터 적용 시 모델 응답]
직전 학기 평점 3.8 이상이어야 전액 장학금을 받을 수 있습니다. (2024년 개정 장학 규정 기준)
```

- **답안 설명**
    
    **정답:** 2번
    
    벡터 검색은 텍스트의 의미적 유사성만 비교하므로 연도, 부서, 대상자 등 구체적인 조건이 일치하지 않는 문서를 오답으로 가져올 수 있습니다. 메타데이터 필터는 이러한 사실 조건을 엄격하게 제한해 줍니다.
    
</aside>

### 5.2 개념 요약 키워드

- **메타데이터(Metadata)**: 문서 본문 외에 연도, 카테고리, 대상자 등을 표기한 속성 이름표
- **사전 필터링(Pre-filtering)**: 벡터 유사도 계산 전 특정 속성 조건을 만족하는 문서만 1차 선별하는 방식
- **복합 필터(Composite Filter)**: 연도와 분류 등 둘 이상의 속성 조건을 동시에 만족하도록 결합하는 검색 방식

### 5.3 용어 사전

| 용어 | 영어 표현 | 설명 |
| --- | --- | --- |
| 메타데이터 | Metadata | 본문 텍스트 외에 문서의 작성 연도, 출처, 분류, 권한 등을 기록한 부가 데이터입니다. |
| 사전 필터링 | Pre-filtering | 유사도 검색을 수행하기 전에 조건을 만족하지 않는 문서를 미리 제외하는 필터링 기법입니다. |
| JSONB | JSONB | PostgreSQL에서 JSON 데이터를 분해하여 이진(Binary) 형태로 저장함으로써 빠른 검색과 인덱싱을 지원하는 데이터 타입입니다. |
