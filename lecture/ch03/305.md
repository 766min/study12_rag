## 2. 검색 문맥 주입의 원리

<aside>
💡

<u>**문맥 주입(Context Injection)**</u>
AI에게 참고 문서를 지침과 함께 명확히 전달하여 자체 지식에 의한 왜곡을 차단하는 기술입니다.

</aside>

### 2.1 문맥 주입의 목적과 환각 제어

<aside>

- **외부 지식 강제**: AI가 사전에 학습한 오래된 기억 대신, 프롬프트에 직접 입력된 최신 문서를 최우선 기준으로 채택하도록 만듭니다.
- **답변 범위 한정**: <u>"제시된 문서 내용 외에는 답변하지 말 것"</u>이라는 제약 조건을 부여하여 허위 정보 생성을 방지합니다.
</aside>

### 2.2 RAG 프롬프트 템플릿의 3요소

<aside>

- **시스템 역할 및 지침 (System)**: AI의 역할, 답변 어조, 참고 문서 외 임의 답변 금지 규칙을 명시합니다.
- **참고 문맥 (Context)**: 검색기를 통해 추출된 복수의 문서 본문이 들어가는 영역입니다.
- **사용자 질문 (Question)**: 사용자가 실제로 입력한 자연어 질문입니다.
</aside>

## 3. 검색 결과 문맥 포맷팅 실습

<aside>
💡

데이터베이스에서 추출된 여러 개의 Document 객체를 하나의 구조화된 문자열로 결합합니다.

</aside>

### 3.1 규정 데이터 문서 객체 준비

<aside>

```python
from langchain_core.documents import Document

retrieved_docs = [
    Document(
        page_content="[2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    ),
    Document(
        page_content="[2024년 장학 지급 절차] 전액 장학금 수혜 대상자는 등록금 고지서에서 우선 감면 처리됩니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    )
]

print(f"가져온 문서 개수: {len(retrieved_docs)}개")
```

```
가져온 문서 개수: 2개
```

</aside>

### 3.2 문맥 포맷팅 함수 정의

<aside>

단순 결합 대신 문서 구분을 위한 번호와 줄바꿈 기호를 부여하여 가독성을 높입니다.

```python
# 문서 리스트를 단일 문자열 문맥으로 변환하는 함수를 정의합니다.
def format_docs(docs: list[Document]) -> str:
    formatted_chunks = []
    # 각 문서 본문 앞에 번호를 붙여 정렬합니다.
    for index, doc in enumerate(docs, 1):
        formatted_chunks.append(f"[문서 {index}]\n{doc.page_content}")

    # 각 문서를 두 줄 띄움(줄바꿈 2회)으로 구분하여 결합합니다.
    return "\n\n".join(formatted_chunks)

# 포맷팅 함수를 실행하여 문맥 문자열을 생성합니다.
context_text = format_docs(retrieved_docs)
print("=== [포맷팅 완료된 문맥 문자열] ===")
print(context_text)
```

```
=== [포맷팅 완료된 문맥 문자열] ===
[문서 1]
[2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.

[문서 2]
[2024년 장학 지급 절차] 전액 장학금 수혜 대상자는 등록금 고지서에서 우선 감면 처리됩니다.
```

</aside>

## 4. ChatPromptTemplate 설계 및 LLM 모델 연동

<aside>
💡

중괄호 `{ }`를 사용해 동적 입력 변수를 지정하고, LLM 모델과 결합하여 답변을 생성합니다.

</aside>

### 4.1 ChatPromptTemplate 구성

<aside>

시스템 메시지에 엄격한 사실 기반 답변 제약 조건을 명시합니다.

```python
from langchain_core.prompts import ChatPromptTemplate

# 문맥과 질문이 들어갈 템플릿을 선언합니다.
prompt_template = ChatPromptTemplate.from_messages([
    (
        "system",
        "당신은 대학 행정 규정 안내 비서입니다.\n"
        "반드시 아래 제공된 [참고 문서] 내용만을 근거로 정확하게 답변하세요.\n"
        "문서에 근거가 없는 내용은 절대 추측하지 말고 '제공된 규정에서 확인할 수 없습니다.'라고 답변하세요.\n\n"
        "[참고 문서]\n{context}"
    )
])

print("프롬프트 템플릿 등록 완료")
```

</aside>

### 4.2 LLM  연동 및 응답 생성

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0  # 일관된 사실 기반 생성을 위해 0으로 설정합니다.
)

# 사용자 질의를 정의합니다.
user_query = "학부생 전액 장학금 기준과 지급 방식은 어떻게 되나요?"

# 프롬프트 변수 주입 -> 언어 모델 호출 -> 문자열 출력을 하나의 파이프라인으로 연결합니다.
rag_chain = prompt_template | model | StrOutputParser()

# 체인을 실행하고 결과를 확인합니다.
response = rag_chain.invoke({
    "context": context_text,
    "question": user_query
})

print("=== [모델 최종 답변] ===")
print(response)
```

```
=== [모델 최종 답변] ===
안내 준비되었습니다. 아래 제공된 문서에 근거한 내용만 안내해 드립니다. 문서에 없는 내용은 절대 추측하지 않으며, 해당 경우에는 "제공된 규정에서 확인할 수 없습니다."라고 답변하겠습니다.

현재 제공된 규정 요지:
1. 2024년 개정 장학 규정: 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.
2. 2024년 장학 지급 절차: 전액 장학금 수혜 대상자는 등록금 고지서에서 우선 감면 처리됩니다.

질문하실 내용을 알려주시면, 위 문서들에 근거해 답변드리겠습니다.
```

</aside>

## 5. 컨텍스트 길이 관리와 최적화

<aside>
💡

**주입되는 문맥이 과도하게 길어지면 처리 비용이 상승하고 모델의 집중도가 떨어집니다.**

</aside>

### 5.1 Lost in the Middle 현상

<aside>

- **정의**: 프롬프트 길이가 지나치게 길 경우, 언어 모델이 문서의 시작과 끝부분 정보는 잘 기억하지만 중간 부분에 위치한 핵심 정보를 누락하는 현상입니다.
- **영향**: 불필요한 문서를 대량으로 주입하면 정답이 포함되어 있어도 오답을 출력할 위험이 증가합니다.
</aside>

### 5.2 문맥 길이 제어 전략

<aside>

- **Top-k 최적화**: 문맥으로 주입할 문서 수를 2~3개 수준으로 엄격하게 제한합니다.
- **불필요한 공백 및 메타데이터 정제**: 검색된 원문에서 줄바꿈이나 중복 텍스트를 제거한 후 주입합니다.
</aside>

### 6.2 개념 요약 키워드

- **ChatPromptTemplate**: 시스템 지시문과 사용자 입력을 분리하여 동적으로 메시지를 조립하는 템플릿 클래스
- **문맥 포맷팅(Context Formatting)**: 리스트 형태의 Document 객체 본문들을 연결 기호로 묶어 단일 텍스트로 가공하는 과정
- **Lost in the Middle**: 프롬프트의 길이가 과도하게 길어질 때 모델이 본문 중간 영역의 사실을 인식하지 못하는 현상

### 6.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| 프롬프트 템플릿 | Prompt Template | 고정된 지침 틀에 동적인 데이터(문맥, 질문)를 주입할 수 있도록 만든 프롬프트 서식입니다. |
| 문맥 주입 | Context Injection | 검색기를 통해 찾아낸 참조 텍스트를 언어 모델의 입력 프롬프트 안에 삽입하는 과정입니다. |
| 토큰 | Token | 언어 모델이 텍스트를 읽고 계산할 때 사용하는 최소 의미 글자 단위입니다. |
