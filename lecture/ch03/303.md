## 2. Top-k 설정과 검색 범위 제어

<aside>
💡

<u>**Top-k는 질문과의 유사도 점수가 가장 높은 문서를 몇 개까지 가져올지($k$) 결정하는 핵심 파라미터입니다.**</u> 데이터베이스 내 수많은 문서 후보 중 연관성이 가장 뛰어난 상위 $k$개의 핵심 청크만 엄선하여, LLM 프롬프트 컨텍스트와 같은 후속 추론 파이프라인으로 전달합니다.

</aside>

### 2.1 Top-k 파라미터의 트레이드오프

<aside>

- **k값이 과도하게 큰 경우**: 불필요한 정보(노이즈)가 포함되어 입력 토큰 비용이 증가하고 핵심 문맥이 흐려집니다.
- **k값이 과도하게 작은 경우**: 답변을 생성하는 데 필수적인 근거 문장이 누락되어 환각(Hallucination)이 발생할 위험이 있습니다.
- **적정값 설정 기준**: 일반적으로 단답형 질의는 `k=2~3`, 종합 분석형 질의는 `k=4~6` 범위에서 품질 테스트를 진행합니다.
</aside>

### 2.2 Top-k 지정 검색 실습

<aside>

이전 강에서 구축한 `integrated_university_rules` 컬렉션에 연결하고 `k` 값을 변경하며 결과를 비교합니다.

```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings
from langchain_postgres.vectorstores import PGVector

load_dotenv()

embeddings_model = OpenAIEmbeddings(
    model="text-embedding-3-small"
)

# 데이터베이스 연결 주소를 확인합니다.
connection_url = os.getenv("DATABASE_URL")

# PGVector 벡터 저장소에 연결합니다.
vector_store = PGVector(
    embeddings=embeddings_model,
    collection_name="integrated_university_rules",
    connection=connection_url,
    use_jsonb=True
)

# 테스트 질의를 정의합니다.
query = "도서관 책 대출 규정이 어떻게 되나요?"

# k=2로 설정하여 상위 2개의 문서만 검색합니다.
results_k2 = vector_store.similarity_search(query=query, k=2)

# 검색 결과 개수 및 내용을 확인합니다.
print(f"가져온 문서 개수: {len(results_k2)}개\n")
for idx, doc in enumerate(results_k2, 1):
    print(f"[{idx}위 문서]")
    print(f"- 내용: {doc.page_content}")
    print(f"- 출처: {doc.metadata.get('source')}")

```

```
가져온 문서 개수: 2개

[1위 문서]
- 내용: [개정 도서관 규정] 학부생은 최대 7권까지 21일간 대출 가능합니다.
- 출처: rules_library.txt
[2위 문서]
- 내용: [장학금 규정] 직전 학기 평점 3.5 이상 시 장학금 대상입니다.
- 출처: rules_scholarship.txt
```

## 3. Score Threshold를 통한 저품질 문서 제거

<aside>
💡

<u>**Score Threshold는 검색된 문서가 통과해야 하는 최소 유사도 기준선(임계값)입니다.**</u>
데이터베이스에 없는 질문이 들어왔을 때, 관련 없는 문서가 언어 모델로 전달되는 것을 차단합니다.

</aside>

### 3.1 코사인 거리 기준 임계치 설정 원리

<aside>

PGVector는 코사인 거리($1 - \text{유사도}$)를 기본 지표로 사용하므로 수치가 작을수록 연관성이 높습니다.설정한 임계값보다 **거리 점수가 큰 문서는 즉시 탈락(Filter-out)** 처리합니다.

| **품질 구간** | **거리 점수 범위** | **판별 결과 및 조치** |
| --- | --- | --- |
| **우수 구간** | 0.00 ~ 0.35 | 질문과 핵심 의도가 일치하므로 문맥으로 주입 |
| **보통 구간** | 0.35 ~ 0.60 | 부분 관련성이 존재하므로 Top-k 조건에 맞춰 선별 사용 |
| **주의/탈락** | 0.60 초과 | 무관한 노이즈 문서로 판별하여 모델 입력에서 제외 |
</aside>

### 3.2 점수 필터링 실습

<aside>

무관한 질문을 전달했을 때 점수 기준선을 통해 문서를 걸러내는 로직을 검증합니다.

```python
# 허용할 최대 코사인 거리 임계치를 정의합니다.
SCORE_THRESHOLD = 0.60

# 저장소에 정보가 없는 엉뚱한 질문을 전달합니다.
irrelevant_query = "캠퍼스 식당 오늘의 점심 메뉴 알려줘"

# 유사도 점수를 포함하여 상위 3건을 검색합니다.
scored_results = vector_store.similarity_search_with_score(
    query=irrelevant_query,
    k=3
)

# 임계치를 기준으로 문서를 선별합니다.
passed_documents = []
print(f"[질의]: {irrelevant_query}\n")

for doc, score in scored_results:
    print(f"> 측정된 거리 점수: {score:.4f}")
    if score <= SCORE_THRESHOLD:
        print("  -> 결과: [통과] 기준선 이하이므로 문맥에 포함합니다.")
        passed_documents.append(doc)
    else:
        print("  -> 결과: [탈락] 노이즈 문서로 판별되어 제외합니다.")

print(f"\n최종 전달 가능한 문서 수: {len(passed_documents)}개")
```

```
[질의]: 캠퍼스 식당 오늘의 점심 메뉴 알려줘

> 측정된 거리 점수: 0.9107
  -> 결과: [탈락] 노이즈 문서로 판별되어 제외합니다.
> 측정된 거리 점수: 0.9515
  -> 결과: [탈락] 노이즈 문서로 판별되어 제외합니다.

최종 전달 가능한 문서 수: 0개
```

</aside>

## 4. LLM 모델과 연동한 답변 생성

<aside>
💡

<u>**정제된 문서만을 LLM에 프롬프트로 전달하여 정확한 답변을 도출합니다.**</u>
필터링을 통과한 유효 문서가 0건인 경우, 모델이 억지로 추론하지 않고 정보 부재를 안내하도록 유도합니다.

</aside>

### 4.1 LLM 초기화 및 프롬프트 주입

<aside>

```python
from langchain.chat_models import init_chat_model
from langchain_core.messages import SystemMessage, HumanMessage

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0 # 일관된 사실 기반 답변 생성을 위해 0으로 설정합니다.
)

# 검색 및 필터링을 실행하는 함수를 정의합니다.
def retrieve_and_generate(user_query: str, k: int = 3, threshold: float = 0.60):
    # 벡터 검색 및 점수 추출
    docs_and_scores = vector_store.similarity_search_with_score(user_query, k=k)

    # Score Threshold 필터링 수행
    valid_docs = [doc for doc, score in docs_and_scores if score <= threshold]

    # 통과된 문서 유무에 따른 분기 처리
    if not valid_docs:
        return "제공된 규정 문서 내에서 질문과 관련된 내용을 찾을 수 없습니다."
    
    # LLM에 전달할 문맥(Context) 조합
    context_text = "\n\n".join([f"- {d.page_content}" for d in valid_docs])

    # 시스템 및 사용자 프롬프트 구성
    messages = [
        SystemMessage(content=(
            "당신은 대학 규정 안내 AI 비서입니다."
            "반드시 아래 제공된 [참고 문서]의 내용만을 근거로 정확하게 답변하세요.\n\n"
            f"[참고 문서]\n{context_text}"
        )),
        HumanMessage(content=user_query)
    ]

    # LLM 호출 및 응답 반환
    response = model.invoke(messages)
    return response.content

# 정상 질의 실행 테스트
query_valid = "도서관 책 대출 규정이 어떻게 되나요?"
print(f"[질문]: {query_valid}")
print(f"[답변]:\n{retrieve_and_generate(query_valid)}\n")
print("-" * 50)

# 무관한 질의 실행 테스트
query_invalid = "캠퍼스 식당 오늘의 점심 메뉴 알려줘"
print(f"[질문]: {query_invalid}")
print(f"[답변]:\n{retrieve_and_generate(query_invalid)}")
```

```
[질문]: 도서관 책 대출 규정이 어떻게 되나요?
[답변]:
참고 문서(개정 도서관 규정)에 따르면:
- 학부생은 최대 7권까지, 21일간 대출할 수 있습니다.

(대출 연장·벌금·대상자별 차이 등 그 밖의 사항은 해당 문서에 명시되어 있지 않습니다.)

--------------------------------------------------
[질문]: 캠퍼스 식당 오늘의 점심 메뉴 알려줘
[답변]:
제공된 규정 문서 내에서 질문과 관련된 내용을 찾을 수 없습니다.
```

### 5.2 개념 요약 키워드

- **Top-k**: 검색 결과로 반환할 최상위 문서의 개수를 제어하는 기준
- **Score Threshold**: 노이즈 문서를 차단하기 위해 설정하는 최소 유사도 합격선
- **문맥 정제(Context Pruning)**: 검증된 문서만 전달하여 환각과 비용을 줄이는 과정

### 5.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **상위 k개 추출** | Top-k | 유사도 순위가 높은 상위 k개의 문서를 선택하여 반환하는 파라미터입니다. |
| **점수 임계값** | Score Threshold | 문서의 품질과 연관성을 보장하기 위해 통과 기준이 되는 유사도 수치 기준선입니다. |
| **코사인 거리** | Cosine Distance | 두 벡터 간의 방향 차이를 거리화한 수치(1 - 유사도)로, 0에 가까울수록 관련성이 높습니다. |
| **노이즈 문서** | Noise Document | 질문 의도와 맞지 않음에도 검색 알고리즘에 의해 잘못 추출된 무관한 문서를 뜻합니다. |
| **경량 언어 모델** | gpt-5-mini | 적은 비용과 빠른 속도로 정확한 추론을 수행하는 OpenAI의 경량 대규모 언어 모델입니다. |
