## 2. 출처 표기와 문서 전달 원리

<aside>
💡

인공지능이 답변을 생성하는 마지막 순간까지, 본문 내용뿐만 아니라 출처가 적힌 메타데이터(꼬리표)를 놓치지 않도록 파이프라인 전체에 걸쳐 온전히 전달해 주는 과정입니다. 이를 통해 모델이 임의로 추측하지 않고 '몇 년도, 어떤 문서의 몇 조를 근거로 작성되었는지' 명확한 출처와 함께 신뢰도 높은 답변을 내놓을 수 있게 됩니다.

</aside>

### 2.1 문서 메타데이터 활용

<aside>

- **메타데이터(Metadata)**: 문서의 제목, 생성 연도, 카테고리 같은 추가 정보입니다.
- **출처의 근거**: 검색기(Retriever)가 찾아낸 문서의 원본 데이터를 버리지 않고, 체인 마지막 단계에서 답변과 함께 출력합니다.
</aside>

### 2.2 검색과 출처 분기 구조

<aside>

- 이전 강에서 배운 `RunnablePassthrough`를 활용하여 텍스트 문맥과 원본 문서를 분기 처리합니다.
- 텍스트로 합쳐진 문맥은 프롬프트로 들어가 답변을 만들고, 원본 문서 리스트는 그대로 보존되어 출처 표기에 사용됩니다.
</aside>

## 4. 출처 표기 RAG 구현하기

### 4.1 전체 파이프라인 코드 실행

<aside>

```python
import os
from dotenv import load_dotenv
from langchain_core.documents import Document
from langchain_openai import OpenAIEmbeddings
from langchain_postgres import PGVector
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

connection_url = os.getenv("DATABASE_URL")

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vector_store = PGVector(
    embeddings=embeddings,
    collection_name="university_scholarship",
    connection=connection_url,
    use_jsonb=True,
)

# 출처 표기를 위한 메타데이터가 포함된 샘플 문서 적재
sample_docs = [
    Document(
        page_content="[2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    ),
    Document(
        page_content="[2024년 장학 지급 절차] 전액 장학금 수혜 대상자는 등록금 고지서에서 우선 감면 처리됩니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    )
]
vector_store.add_documents(sample_docs)

# 검색기(Retriever) 생성 (상위 2개 문서 검색)
retriever = vector_store.as_retriever(search_kwargs={"k": 2})

# 문서를 단일 텍스트로 합쳐주는 포맷팅 함수
def format_docs(docs: list[Document]) -> str:
    formatted_chunks = []
    for index, doc in enumerate(docs, 1):
        formatted_chunks.append(f"[문서 {index}]\n{doc.page_content}")
    return "\n\n".join(formatted_chunks)

# 시스템 프롬프트 템플릿 선언
prompt_template = ChatPromptTemplate.from_messages([
    ("system", "당신은 대학 행정 비서입니다.\n반드시 아래 제공된 [참고 문서] 내용만을 근거로 정확하게 답변하세요.\n\n[참고 문서]\n{context}"),
    ("human", "{question}")
])

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

# 질문, 출처 문서, 프롬프트용 텍스트를 분기하는 함수
def retrieve_and_format(question):
    docs = retriever.invoke(question) # DB 검색 실행
    return {
        "question": question,
        "source_documents": docs, # 최종 출처 표기를 위해 원본 보존
        "context": format_docs(docs)
    }

# 답변 생성 체인 연결
generation_chain = prompt_template | model | StrOutputParser()

# 답변과 출처를 함께 정리해서 출력하는 후처리 함수
def final_post_processing(question):
    # 검색 및 데이터 준비
    inputs = retrieve_and_format(question)

    # 모델 답변 생성
    answer = generation_chain.invoke(inputs)

    print("[AI의 답변]")
    print(answer)
    print("\n[참고한 출처]")

    # 보존해둔 원본 문서의 메타데이터 출력
    for i, doc in enumerate(inputs["source_documents"], 1):
        category = doc.metadata.get("category", "분류 없음")
        year = doc.metadata.get("year", "연도 미상")
        print(f"{i}. 카테고리: {category} (제정 연도: {year}년)")

user_query = "학부생 전액 장학금 지급 방식이 어떻게 돼?"
final_post_processing(user_query)
```

```
[AI의 답변]
관련 규정에 따르면 다음과 같이 처리됩니다.

- 지급 기준: 직전 학기 평점 3.8 이상 취득 시 전액 장학금이 지급됩니다.  
- 지급 방식: 전액 장학금 수혜 대상자는 등록금 고지서에서 우선 감면 처리됩니다.

[참고한 출처]
1. 카테고리: scholarship (제정 연도: 2024년)
2. 카테고리: scholarship (제정 연도: 2024년)
```

## 5. 개념 체크 하기

### 5.1 개념 확인 문제

<aside>
💡

**Q1. 본 강의 코드에서 retrieve_and_format 함수 내부의 source_documents 딕셔너리 키(Key)가 하는 핵심 역할은 무엇인가요?**

---

- [ ]  (1) LLM이 답변을 영어로 번역하도록 강제하기 위해
- [ ]  (2) 사용자 질문을 PostgreSQL 데이터베이스 쿼리로 자동 변환하기 위해
- [ ]  (3) 검색된 원본 문서를 잃어버리지 않고 체인 마지막 단계까지 보존하여 출처를 표기하기 위해
- [ ]  (4) LLM 모델의 답변 생성 속도를 빠르게 높이기 위해

- **답안 설명**
    
    **정답:** 3번
    
    source_documents를 따로 분기하여 저장하면, 텍스트로 합쳐져 프롬프트에 들어간 문맥 외에도 원본 메타데이터(꼬리표)를 살릴 수 있어 최종 출처 표기가 가능합니다.
    
</aside>

<aside>
💡

**Q2. init_chat_model을 사용하여 최신 모델을 선언할 때, temperature=0으로 설정하는 이유는 무엇인가요?**

---

- [ ]  (1) 인덱싱 속도를 비약적으로 높이기 위해서
- [ ]  (2) 인공지능이 무작위성을 배제하고 제공된 검색 문맥에만 기반하여 엄격하고 일관된 답변을 생성하게 유도하기 위해서
- [ ]  (3) 데이터베이스 접속 권한을 안전하게 관리하기 위해서
- [ ]  (4) 문서 검색 개수를 자동으로 제한하기 위해서

- **답안 설명**
    
    **정답:** 2번
    
    온도를 뜻하는 temperature를 0으로 설정하면, 인공지능이 창의성을 발휘해 없는 말을 지어내는 것을 방지하고 사실 기반의 답변을 하도록 만듭니다.
    
</aside>
