## 2. 검색→생성 통합 체인의 원리

<aside>
💡

<u>**LCEL(LangChain Expression Language) 데이터 파이프라인**</u>
사용자의 단일 입력값을 검색기와 프롬프트 슬롯으로 나누어 보낸 뒤 모델의 답변까지 한 번에 도출하는 연결 기술입니다.

</aside>

### 2.1 단일 입력의 분기와 병합 구조

<aside>

- **입력 분기**: 사용자가 전달한 하나의 질문 텍스트가 검색기와 질문 보존 경로로 동시에 진입합니다.
- **문맥 생성 경로**: 질문 텍스트를 검색기(Retriever)에 넣어 문서를 찾고, 이를 포맷팅 함수로 묶어 `{context}`에 전달합니다.
- **질문 유지 경로**: `RunnablePassthrough`를 통해 질문 텍스트를 수정 없이 그대로 프롬프트의 `{question}`에 전달합니다.
- **파이프 연산자(`|`)**: 선행 작업의 결과값을 후행 작업의 입력값으로 넘겨주어 전체 과정을 하나의 체인으로 만듭니다.
</aside>

## 3. 기본 RAG QA 파이프라인 구현 실습

<aside>
💡

<u>**엔드투엔드 RAG 체인 조립**</u>
문서 검색, 문맥 포맷팅, 프롬프트 주입, LLM 모델 호출을 단일 실행 흐름으로 통합합니다.   

</aside>

### 3.1 문서 데이터 준비 및 검색기 구성

<aside>

```python
import os
from dotenv import load_dotenv
from langchain_core.documents import Document
from langchain_openai import OpenAIEmbeddings
from langchain_postgres import PGVector

load_dotenv()

connection_url = os.getenv("DATABASE_URL")
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

vector_store = PGVector(
    embeddings=embeddings,
    collection_name="university_regulations",
    connection=connection_url,
    use_jsonb=True,
)

# 실습에 사용할 학사 규정 문서 데이터를 생성합니다.
sample_docs = [
    Document(
        page_content="[2024년 개정 장학 규정] 직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    ),
    Document(
        page_content="[2024년 장학 지급 절차] 전액 장학금 수혜 대상자는 등록금 고지서에서 우선 감면 처리됩니다.",
        metadata={"category": "scholarship", "year": 2024, "target": "undergraduate"}
    )
]

# 준비된 문서 데이터를 PostgreSQL 벡터 테이블에 적재합니다.
vector_store.add_documents(sample_docs)

# 벡터 저장소를 기반으로 상위 2개 문서를 가져오는 검색기(Retriever)를 생성합니다.
retriever = vector_store.as_retriever(search_kwargs={"k": 2})
```

</aside>

### 3.2 문맥 포맷팅 함수 및 프롬프트 템플릿 선언

<aside>

데이터베이스에서 조회된 복수 문서를 정리하는 함수와 시스템 지시문을 정의합니다.

```python
from langchain_core.prompts import ChatPromptTemplate

# Document 리스트를 번호가 매겨진 단일 문자열로 변환하는 함수를 정의합니다.
def format_docs(docs: list[Document]) -> str:
    formatted_chunks = []
    # 각 문서 본문 앞에 고유 번호를 부여하여 리스트에 담습니다.
    for index, doc in enumerate(docs, 1):
        formatted_chunks.append(f"[문서 {index}]\n{doc.page_content}")
    # 가독성을 위해 두 줄 바꿈 문자로 문서들을 연결합니다.
    return "\n\n".join(formatted_chunks)

# 시스템 규칙과 입력 변수가 정의된 프롬프트 서식을 선언합니다.
prompt_template = ChatPromptTemplate.from_messages([
    (
        "system",
        "당신은 대학 행정 규정 안내 비서입니다.\n"
        "반드시 아래 제공된 [참고 문서] 내용만을 근거로 정확하게 답변하세요.\n"
        "문서에 근거가 없는 내용은 절대 추측하지 말고 '제공된 규정에서 확인할 수 없습니다.'라고 답변하세요.\n\n"
        "[참고 문서]\n{context}"
    ),
    (
        "human",
        "{question}"
    )
])
```

</aside>

### 3.3 LLM 모델 기반 엔드투엔드 RAG 체인 완성

<aside>

LCEL 문법으로 검색부터 답변 생성까지 일괄 실행하는 체인을 구성합니다.   

```python
from langchain.chat_models import init_chat_model
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

# 데이터베이스 검색, 포맷팅, 프롬프트 주입, 모델 추론을 하나의 체인으로 연결합니다.
rag_chain = (
    # context는 질문 기반 DB 검색 결과 문자열을 매핑하고, question은 사용자 질문을 전달합니다.
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough()
    }
    | prompt_template 
    | model
    | StrOutputParser()
)

user_query = "학부생 전액 장학금 기준과 지급 방식은 어떻게 되나요?"
response = rag_chain.invoke(user_query)

print("=== [RAG 최종 답변] ===")
print(response)

```

```
=== [RAG 최종 답변] ===
요약해서 답변드립니다.

- 기준: 제공된 규정(문서 1)에 따르면 "직전 학기 평점 3.8 이상 취득 시 전액 장학금을 지급합니다."

- 지급 방식: 제공된 규정(문서 2)에 따르면 전액 장학금 수혜 대상자는 "등록금 고지서에서 우선 감면 처리"됩니다(즉 등록금 고지 시 우선적으로 감면됩니다).

- 추가(확인 불가 사항): 이 제도가 학부생에게만 해당되는지, 신청 절차·지급 시기·환불 등 상세 운영사항은 제공된 규정에서 확인할 수 없습니다.
```

</aside>

**Q1. langchain-postgres의 PGVector를 활용하여 생성한 retriever의 주된 역할은 무엇인가요?**

---

- [ ]  (1) 사용자 질문을 입력받아 PostgreSQL 벡터 테이블에서 유사도 높은 문서를 조회한다.

### 4.2 개념 요약 키워드

- **PGVector**: PostgreSQL 데이터베이스 내부에서 벡터 유사도 연산 및 문서 저장을 수행하는 랭체인 전용 벡터 저장소 모듈
- **RunnablePassthrough**: 입력된 데이터를 별도 가공 없이 파이프라인의 다음 단계로 그대로 전달하는 컴포넌트
- **통합 체인(Integrated Chain)**: 검색, 포맷팅, 프롬프트 생성, LLM 추론 단계를 파이프 연산자(`|`)로 자동화한 파이프라인

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| PGVector | PGVector | PostgreSQL 데이터베이스에서 임베딩 벡터를 저장하고 유사도 검색을 수행하는 확장 기능 및 연동 클래스입니다. |
| 리트리버 | Retriever | 입력된 질문과 의미적으로 가장 가까운 문서를 데이터베이스에서 검색하여 반환하는 컴포넌트입니다. |
| 런너블 패스스루 | RunnablePassthrough | 들어온 데이터의 형태를 변경하지 않고 다음 단계의 입력값으로 그대로 전달하는 통로 모듈입니다. |
| 출력 파서 | StrOutputParser | 언어 모델이 출력한 복합 객체 메시지에서 순수 문자열 텍스트만 추출해 주는 도구입니다. |
