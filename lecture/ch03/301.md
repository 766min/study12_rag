## 2. 벡터 저장소 연결 및 질의 임베딩

<aside>
💡

사전에 구축된 벡터 저장소(문서 창고)를 불러오고, 사용자가 입력한 자연어 질문을 검색 가능한 수치 데이터로 변환합니다. 즉, 사람이 쓰는 텍스트 형태의 질문을 컴퓨터가 수학적으로 유사도를 계산할 수 있도록 고차원 실수 벡터(Vector) 배열로 바꾸는 단계입니다.

</aside>

### 2.1 PGVector 저장소 연결 실습

<aside>

```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings
from langchain_postgres.vectorstores import PGVector

load_dotenv()

embeddings_model = OpenAIEmbeddings(
    model="text-embedding-3-small"
)

connection_url = os.getenv("DATABASE_URL")

vector_store=PGVector(
    embeddings=embeddings_model,
    collection_name="integrated_university_rules",
    connection=connection_url,
    use_jsonb=True
)

print("PGVector 저장소 인스턴스 연결 완료")
```

</aside>

### 2.2 질의 임베딩(Query Embedding) 원리 및 생성 실습

<aside>

- **질의 임베딩의 역할**: 자연어로 표현된 사용자의 질문 의도를 벡터 공간의 한 점(좌표)으로 변환합니다.
- **embed_query()**: 단일 질문 문장을 입력받아 1,536차원의 부동소수점 배열로 변환하는 함수입니다.

```python
# 사용자 질문을 정의합니다.
user_query = "학부생 도서 대출 권수와 기간을 알려주세요."

# 질문 문장을 벡터(숫자 좌표 배열)로 변환합니다.
query_vector = embeddings_model.embed_query(user_query)

# 생성된 벡터의 차원 수와 샘플 값을 출력합니다.
print(f"질의 텍스트: {user_query}")
print(f"생성된 벡터 차원: {len(query_vector)}차원")
print(f"변환된 좌표 샘플 (앞 5개): {query_vector[:5]}")

```

```
질의 텍스트: 학부생 도서 대출 권수와 기간을 알려주세요.
생성된 벡터 차원: 1536차원
변환된 좌표 샘플 (앞 5개): [0.010833740234375, 0.01522064208984375, 0.0228271484375, -0.002750396728515625, 0.0193939208984375]
```

</aside>

## 3. Retriever 인터페이스 구성 및 파라미터 제어

<aside>
💡

구축해 둔 벡터 저장소를 표준 검색 컴포넌트인 리트리버(Retriever)로 변환하여, 질문에 꼭 맞는 문서를 자동으로 찾아내도록 연결합니다. 복잡한 벡터 유사도 연산이나 상위 문서(Top-k) 추출 로직을 개발자가 일일이 코딩할 필요 없이, LangChain의 Retriever 인터페이스를 호출해 검색 파이프라인을 깔끔하게 완성합니다.

</aside>

### 3.1 Retriever 인터페이스 구성 실습

<aside>

- **Retriever의 정의**: 비정형 텍스트 질의를 입력받아 관련 Document 객체 목록을 반환하는 표준 모듈입니다.
- **as_retriever()**: 기존 VectorStore 객체를 검색 전용 컴포넌트로 즉시 변환합니다.
- **invoke()**: 검색기 객체에 질의를 전달하여 유사도 검색 프로세스를 실행합니다.

```python
# PGVector 저장소를 Retriever 인터페이스로 변환합니다.
retriever = vector_store.as_retriever()

# Retriever를 호출하여 질문과 가장 유사한 문서를 검색합니다.
retrieved_docs = retriever.invoke(user_query)

# 검색된 문서 건수와 가장 연관성 높은 1순위 문서를 확인합니다.
print(f"검색된 문서 건수: {len(retrieved_docs)}건")
print("=== [1순위 검색 문서 본문] ===")
print(retrieved_docs[0].page_content)
print("=== [1순위 검색 문서 메타데이터] ===")
print(retrieved_docs[0].metadata)
```

```
검색된 문서 건수: 2건
=== [1순위 검색 문서 본문] ===
[개정 도서관 규정] 학부생은 최대 7권까지 21일간 대출 가능합니다.
=== [1순위 검색 문서 메타데이터] ===
{'year': 2027, 'source': 'rules_library.txt', 'category': 'library'}
```

</aside>

### 3.2 검색 파라미터(Search Parameters) 제어 실습

<aside>

- **search_kwargs**: 검색 실행 시 전달할 세부 옵션을 딕셔너리 형태로 지정합니다.
- **k (Top-k)**: 유사도 점수가 가장 높은 상위 문서의 반환 개수를 제한합니다.

```python
# 상위 1개의 문서만 정확히 추출하도록 파라미터(k=1)를 설정합니다
custom_retriever = vector_store.as_retriever(
    search_kwargs={"k": 1}
)

# 장학금 관련 질문으로 검색을 수행합니다.
scholarship_query = "장학금을 받기 위한 직전 학기 평점 기준이 어떻게 되나요?"
custom_results = custom_retriever.invoke(scholarship_query)

# k값 설정에 따라 반환된 결과를 확인합니다.
print(f"반환된 문서 개수: {len(custom_results)}건")
for idx, doc in enumerate(custom_results, 1):
    print(f"[{idx}번 문서] {doc.page_content}")
```

```
반환된 문서 개수: 1건
[1번 문서] [장학금 규정] 직전 학기 평점 3.5 이상 시 장학금 대상입니다.
```

</aside>

## 4. Retriever와 LLM 모델 연동 검증

<aside>
💡

<u>**리트리버(검색기)가 찾아낸 관련 문서 문맥(Context)을 최신 LLM에 전달하여 완성도 높은 최종 답변을 생성합니다.**</u> 특히 LangChain의 표준 표현식인 LCEL을 활용하면, 문서 검색부터 프롬프트 주입, 모델 생성에 이르는 전 과정을 단 하나의 깔끔한 파이프라인으로 매끄럽게 연결할 수 있습니다.

</aside>

### 4.1 LLM 모델 초기화 및 프롬프트 구성

<aside>

- **init_chat_model**: 통일된 인터페이스로 채팅 모델을 인스턴스화합니다.
- **모델 지정**: 비용 효율성과 추론 성능을 갖춘 gpt-5-mini 모델을 적용하고 temperature=0으로 설정하여 일관성을 확보합니다.
- **문맥 주입**: 검색기가 가져온 규정 문서 본문만 프롬프트의 {context} 슬롯에 채워 넣습니다.
</aside>

### 4.2 체인 구성 및 최종 질의응답 실습

<aside>

- **문서 포맷팅**: 검색된 Document 리스트의 page_content를 줄바꿈 문자로 병합합니다.
- **LCEL 파이프라인**: Retriever → Format → Prompt → gpt-5-mini → StrOutputParser 순으로 데이터를 전달합니다.

```python
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "당신은 대학 학사 규정 안내 도우미입니다.\n"
        "제공된 [참고 문서]에만 근거하여 답변하고, 문서에 없는 내용은 지어내지 마세요.\n\n"
        "[참고 문서]:\n{context}"
    )),
    ("user", "{question}")
])

# 검색된 문서 리스트를 문자열로 결합하는 함수를 정의합니다.
def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)

# Top-1 설정이 적용된 Retriever와 LLM 모델을 LCEL 파이프라인으로 결합합니다.
rag_chain = (
    {"context": custom_retriever | format_docs, "question": RunnablePassthrough()}
    | prompt 
    | model 
    | StrOutputParser()
)

final_response = rag_chain.invoke("도서관 대출 권수와 기간 규정을 알려줘.")

print("=== [생성 답변] ===")
print(final_response)
```

```
=== [생성 답변] ===
제공된 개정 도서관 규정에 따르면:
- 학부생은 최대 7권까지, 대출 기간은 21일입니다.

참고 문서에는 그 외(대상자 구분, 연장·연체 규정 등)에 대한 추가 내용은 명시되어 있지 않습니다.
```

</aside>

### 5.2 개념 요약 키워드

- **질의 임베딩 (Query Embedding)**: 사용자의 질문을 벡터 공간의 숫자 배열로 수치화하는 프로세스.
- **검색기 (Retriever)**: 질의를 받아 관련 문서를 탐색하고 추출하는 표준 인터페이스.
- **Top-k 파라미터**: 검색 결과로 반환받을 최상위 문서의 개수를 제어하는 인자.

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **질의 임베딩** | Query Embedding | 사용자의 텍스트 질문을 컴퓨터가 유사도를 계산할 수 있도록 고차원 숫자 배열로 변환하는 작업입니다. |
| **검색기** | Retriever | 문자열 질의를 입력받아 데이터베이스에서 관련된 문서를 찾아 반환하는 LangChain의 표준 컴포넌트입니다. |
| **검색 설정 인자** | search_kwargs | 추출할 문서 개수(k), 유사도 임계치 등 검색 조건을 지정하는 딕셔너리 형태의 매개변수입니다. |
| **단일 실행 호출** | invoke | 체인, 모델, 검색기 등의 컴포넌트에 입력을 전달하여 연산을 실행하는 표준 메서드입니다. |
