## 2. 벡터 검색 실행과 유사도 점수 추출

<aside>
💡

단순히 관련 문서를 가져오는 것에 그치지 않고, 각 문서가 질문과 얼마나 의미상 일치하는지 유사도 점수(Score)를 통해 눈으로 직접 확인하는 과정입니다. LangChain VectorStore가 제공하는 점수 반환 메서드(similarity_search_with_score)를 호출하여, 검색된 문서 청크와 함께 매핑된 유사도 수치를 수집하고 신뢰도를 평가합니다.

</aside>

### 2.1 PGVector 저장소 연결

<aside>

```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings
from langchain_postgres.vectorstores import PGVector

load_dotenv()

embeddings_model = OpenAIEmbeddings(
    model="text-embedding-3-small"
)

connection_url = os.getenv("DATABASE_URL")

vector_store = PGVector(
    embeddings=embeddings_model,
    collection_name="integrated_university_rules",
    connection=connection_url,
    use_jsonb=True
)
```

</aside>

### 2.2 점수 포함 검색 (similarity_search_with_score)

<aside>

- **similarity_search()**: 관련 Document 객체만 리스트로 반환합니다.
- **similarity_search_with_score()**: 각 Document 객체와 함께 계산된 유사도 점수를 튜플 형태 `(Document, score)`로 반환합니다.

```python
# 사용자 질문을 정의합니다.
query_text = "도서관 책 대출 규정이 어떻게 되나요?"

# 유사도 점수를 포함하여 상위 3개의 문서를 검색합니다.
results_with_scores = vector_store.similarity_search_with_score(
    query=query_text,
    k=3
)
print(results_with_scores)
# 검색된 결과와 점수를 차례대로 출력합니다.
print(f"질문: {query_text}\n")
for rank, (doc, score) in enumerate(results_with_scores, 1):
    print(f"[{rank}순위 문서]")
    print(f"- 유사도 점수: {score:.4f}")
    print(f"- 문서 내용: {doc.page_content}")
    print(f"- 메타데이터: {doc.metadata}")
    print("-" * 50)
```

## 3. 유사도 점수 해석과 거리 지표의 원리

<aside>
💡

반환된 점수가 0에 가까울수록 질문과 일치하는 '거리(Distance)' 지표인지, 1에 가까울수록 일치하는 '유사도(Similarity)' 지표인지 명확히 판별하는 기준을 학습합니다. 사용하는 벡터 데이터베이스(예: pgvector)와 거리 측정 알고리즘(L2, 코사인 등)에 따라 점수 해석 체계가 완전히 달라질 수 있으므로, 수치의 성격을 정확히 파악하고 임계값을 설정해야 합니다.

</aside>

### 3.1 코사인 거리(Cosine Distance)의 이해

<aside>

- **코사인 유사도 (Cosine Similarity)**: 두 벡터의 방향이 완벽히 일치하면 1, 직교하면 0, 정반대면 -1을 가집니다.
- **코사인 거리 (Cosine Distance)**: 데이터베이스에서는 '거리' 개념을 위해  $1 - \text{코사인 유사도}$  공식을 사용합니다.
- **수치 판별 기준**: 코사인 거리는 **0에 가까울수록 질문과 매우 유사함**을 의미하며, 숫자가 커질수록 관련성이 떨어집니다.

| **지표 구분** | **계산 수식** | **완벽 일치 시 값** | **완전 불일치 시 값** | **수치 해석 방법** |
| --- | --- | --- | --- | --- |
| **코사인 유사도** | $\cos(\theta)$ | `1.0` | `0.0` 또는 `-1.0` | **높을수록** 관련성이 높음 |
| **코사인 거리** (PGVector 기본) |  $1 - \cos(\theta)$ | `0.0` | `1.0` 이상 | **낮을수록** 관련성이 높음 |
</aside>

### 3.2 유사도 점수 구간별 판별 기준

<aside>

- **우수 구간 (0.0 ~ 0.35)**: 질문의 핵심 의도와 문서의 내용이 직접적으로 부합하는 상태입니다.
- **보통 구간 (0.35 ~ 0.60)**: 주제는 관련되어 있으나 세부적인 조건이나 키워드가 일부 일치하는 상태입니다.
- **주의 구간 (0.60 초과)**: 질문과 의미적 연관성이 거의 없으며 노이즈로 작용할 가능성이 높은 상태입니다.
</aside>

## 4. 검색 결과 디버깅 및 품질 분석

<aside>
💡

원치 않는 엉뚱한 문서가 검색되었을 때, 문제의 원인을 단계별로 추적하고 바로잡는 체계적인 트러블슈팅(Troubleshooting) 기법입니다. 일부러 모호한 질문이나 완전히 다른 도메인의 질문(Out-of-Domain)을 던져보는 '네거티브 테스트'를 통해 점수의 변동 폭을 관찰하고, 노이즈를 걸러낼 적정 임계값(Threshold) 기준을 찾아냅니다.

</aside>

### 4.1 정상 질의 vs 비정상 질의 점수 비교 실습

<aside>

- **관련 질문 테스트**: 데이터베이스에 존재하는 도서관 관련 질문을 전달합니다.
- **무관한 질문 테스트**: 규정에 없는 엉뚱한 주제를 전달하여 점수가 어떻게 변하는지 확인합니다.

```python
# 비교할 두 가지 질문 리스트를 정의합니다.
test_queries = [
    "도서 대출 가능 권수",              # 저장소에 존재하는 학사 규정 질문
    "캠퍼스 식당 오늘의 점심 메뉴 알려줘"   # 저장소에 없는 무관한 질문
]

for query in test_queries:
    print(f"\n[질의 분석 실행]: '{query}'")
    # 상위 2건의 문서와 점수를 검색합니다.
    search_results = vector_store.similarity_search_with_score(query=query, k=2)

    for rank, (doc, score) in enumerate(search_results, 1):
        print(f"  > {rank}위 (거리 점수: {score:.4f}) | 내용 요약: {doc.page_content[:40]}...")
```

### 4.2 검색 실패 시 점검 체크리스트

<aside>

- **1순위 점수 과다 (거리 점수 0.6 이상)**: 데이터베이스 내에 질문에 대응하는 지식 문서 자체가 누락되었는지 확인합니다.
- **엉뚱한 문서 상위 노출**: 텍스트 청크가 너무 길어서 여러 주제가 섞여 임베딩의 초점이 흐려졌는지 검토합니다.
- **동음이의어 왜곡**: 질문 문장의 특정 단어가 엉뚱한 문맥으로 임베딩되었는지 질문 문장 구조를 재점검합니다.
</aside>

### 5.2 개념 요약 키워드

- **similarity_search_with_score**: 문서 본문과 벡터 간 거리 점수를 한 번에 추출하는 검색 메서드
- **코사인 거리 (Cosine Distance)**: 두 벡터 간의 방향 차이를 거리화한 지표로, 0에 가까울수록 유사함
- **검색 디버깅**: 유사도 점수와 반환된 문맥을 비교하여 노이즈 문서를 판별하고 원인을 진단하는 작업

### 5.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **유사도 점수** | Similarity Score | 질문 벡터와 문서 벡터가 수학적으로 얼마나 닮았는지를 나타내는 수치 지표입니다. |
| **코사인 거리** | Cosine Distance | 코사인 유사도를 거리 개념(1 - 유사도)으로 변환한 것으로, 값이 작을수록 유사합니다. |
| **점수 임계치** | Score Threshold | 유효한 정보만 남기고 품질이 낮은 문서를 걸러내기 위해 설정하는 점수 기준선입니다. |
| **검색 디버깅** | Retrieval Debugging | 검색 결과가 기대와 다를 때 점수와 메타데이터를 분석하여 파이프라인의 결함을 찾는 절차입니다. |
