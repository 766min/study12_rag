## 2. RAGAS 생성 평가 지표의 원리

<aside>
💡

<u>**답변 생성 단계의 신뢰성과 유용성을 정량적인 수치로 검증합니다.**</u>
검색된 문서 내용을 왜곡 없이 반영했는지와 질문의 본래 의도에 맞게 서술했는지를 0부터 1 사이의 점수로 환산합니다.

</aside>

### 2.1 사실성 (Faithfulness)

<aside>

- **개념**: AI 모델이 생성한 답변이 검색된 참고 문서(Contexts)의 사실에 근거하여 작성되었는지 측정합니다.
- **측정 방식**: 답변을 개별 진술 단위로 분해한 후, 각 진술이 제공된 문서 내용으로부터 사실 확인이 가능한지 검증합니다.
- **특징**: 문서에 명시되지 않은 허위 사실을 지어내는 환각(Hallucination)이 포함될수록 점수가 하락합니다.
</aside>

### 2.2 답변 관련성 (Answer Relevance)

<aside>

- **개념**: 생성된 답변이 사용자가 최초에 질의한 질문(Question)의 목적과 의도에 얼마나 부합하는지 측정합니다.
- **측정 방식**: 생성된 답변을 바탕으로 역방향 질문을 생성한 후, 원본 질문과의 임베딩 유사도를 계산하여 점수를 도출합니다.
- **특징**: 제공된 문서에 부합하는 사실이더라도, 원래 질문과 상관없는 내용을 서술하면 점수가 하락합니다.
</aside>

<aside>

<u>**LLM 모델을 평가 심사위원으로 연동하여 자동 채점을 수행합니다.**</u>
규격화된 평가 데이터를 구축하고 RAGAS 평가 파이프라인을 실행하여 지표를 산출합니다.

### 3.1 RAGAS 전용 데이터셋 변환

<aside>

- **필수 스키마 매핑**: `user_input`(질문), `retrieved_contexts`(검색된 문서 목록), `response`(생성된 답변) 형태로 데이터를 구조화합니다.
- **구조체 변환**: 판다스 데이터프레임을 RAGAS 연산 파이프라인이 요구하는 Dataset 객체로 변환합니다.

```python
import sys
from types import ModuleType

# 제거된 vertexai 모듈을 메모리에 가짜로 등록하여 라이브러리 충돌을 방지합니다.
dummy_chat_vertex = ModuleType("langchain_community.chat_models.vertexai")
dummy_chat_vertex.ChatVertexAI = type("ChatVertexAI", (), {})
sys.modules["langchain_community.chat_models.vertexai"] = dummy_chat_vertex

dummy_llm_vertex = ModuleType("langchain_community.llms.vertexai")
dummy_llm_vertex.VertexAI = type("VertexAI", (), {})
sys.modules["langchain_community.llms.vertexai"] = dummy_llm_vertex

import pandas as pd
from ragas import EvaluationDataset

# 이전 강에서 다룬 도서관 안내 데이터를 바탕으로 질문, 검색 문서, 생성 답변을 정의합니다.
# contexts 항목은 검색기가 찾아온 문서 목록이며, response 항목은 평가 대상이 되는 생성 답변입니다.
eval_raw_data = {
    "user_input": [
        "도서관 주말 운영 시간과 대출 가능 권수는 어떻게 되나요?",
        "시험 기간 평일 도서관 마감 시간은 몇 시인가요?"
    ],
    "retrieved_contexts": [
        [
            "중앙도서관 운영 안내: 주말(토, 일)은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다.",
            "중앙도서관 매점 운영 안내: 평일 오전 9시부터 오후 6시까지 운영합니다."
        ],
        [
            "중앙도서관 특별 규정: 시험 기간 평일은 09시부터 22시까지 연장 운영합니다.",
            "도서관 분실물 보관소는 1층 로비 안내실에서 상시운영됩니다."
        ]
    ],
    "response": [
        # 문서에 명시된 사실만을 정확히 서술한 답변입니다. (높은 사실성 기대)
        "주말은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다.",
        # 문서에 없는 24시간 개방 내용을 추가하여 환각이 포함된 답변입니다. (낮은 사실성 유도)
        "시험 기간 평일 마감 시간은 22시까지입니다. 또한 주말에는 24시간 특별 개방을 실시합니다."
    ]
}

# 딕셔너리 데이터를 2차원 표 형태의 판다스 DataFrame으로 변환합니다.
df_generation_eval = pd.DataFrame(eval_raw_data)

# DataFrame을 RAGAS 평가 함수 규격에 맞는 Dataset 객체로 변환합니다.
ragas_dataset = EvaluationDataset.from_pandas(df_generation_eval)

print("=== [RAGAS 평가용 데이터셋 변환 완료] ===")
print(ragas_dataset)
```

### 3.2 심사위원 모델 연동 및 생성 평가 실행

<aside>

- **프레임워크 호환성 처리**: 일부 모듈 import 충돌을 방지하기 위해 가상 모듈을 등록합니다.
- **모델 래핑**: init_chat_model로 gpt-4o-mini 모델을 선언하고 LangchainLLMWrapper로 포장합니다.
- **평가 수행**: `evaluate()` 함수에 faithfulness와 answer_relevancy 지표를 전달하여 채점을 진행합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_openai import OpenAIEmbeddings
from ragas import evaluate
from ragas.metrics import Faithfulness, ResponseRelevancy
from ragas.llms import LangchainLLMWrapper
from ragas.embeddings import LangchainEmbeddingsWrapper

load_dotenv()

# 일관되고 객관적인 채점을 위해 temperature는 0으로 고정합니다.
judge_model = init_chat_model(
    model="gpt-4o-mini",
    model_provider="openai",
    temperature=0
)

# 답변 관련성 평가 시 문장 유사도 비교를 위한 임베딩 모델을 선언합니다.
embedding_model = OpenAIEmbeddings(model="text-embedding-3-small")

# LangChain 객체를 RAGAS 평가 엔진이 인식할 수 있는 래퍼 클래스로 감쌉니다.
evaluator_llm = LangchainLLMWrapper(judge_model)
evaluator_embeddings = LangchainEmbeddingsWrapper(embedding_model)

# 개별 지표 인스턴스에 LLM 및 임베딩 모델 명시적 전달
metrics = [
    Faithfulness(llm=evaluator_llm),
    ResponseRelevancy(llm=evaluator_llm, embeddings=evaluator_embeddings)
]

print("생성 평가를 실행합니다. gpt-4o-mini 모델이 충실도와 관련성을 채점 중입니다...")

# evaluate 실행 (raise_exceptions=True로 디버깅 가시성 확보)
evaluation_result = evaluate(
    dataset=ragas_dataset,
    metrics=metrics,
    raise_exceptions=True
)

print("생성 지표 측정이 정상적으로 완료되었습니다.")
```

- [ ]  (1) 생성된 답변이 검색된 참고 문서의 사실에 근거하여 작성되었는지 검증하기 위해

- [ ]  (4) 사용자가 입력한 프롬프트의 오탈자를 자동으로 교정하기 위해

    충실도(Faithfulness)는 생성 모델이 주어진 근거 문서 외의 허구 내용을 지어내는 환각(Hallucination) 현상을 억제하고 사실에 기반했는지 측정하는 지표입니다.

- [ ]  (1) 문맥 정밀도(Context Precision)
- [ ]  (2) 문맥 재현율(Context Recall)
- [ ]  (3) 충실도(Faithfulness)

### 4.2 개념 요약 키워드

- **충실도 (Faithfulness)**: AI가 검색된 문서 내용을 임의로 왜곡하거나 없는 사실을 지어내지 않고, 근거에 기반하여 답변을 작성한 비율을 측정합니다.
- **답변 관련성 (Answer Relevance)**: AI가 생성한 최종 답변이 사용자의 질문 의도와 목적에 얼마나 직접적으로 부합하는지 평가합니다.
- **심사위원 모델 (LLM as a Judge)**: 객관적인 지표 채점을 위해 프레임워크 표준 인터페이스를 거쳐 평가 작업을 전담하는 고성능 언어 모델입니다.

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| 충실도 | Faithfulness | 생성된 답변 내 각 진술이 검색 문서의 내용으로부터 유도 가능한지 검증하는 생성 지표입니다. |
| 답변 관련성 | Answer Relevance | 질문과 답변 간의 의미론적 일치도를 비교하여 사용자의 질의 목적 충족 여부를 평가하는 지표입니다. |
| 환각 | Hallucination | 인공지능 모델이 제공된 사실 데이터에 존재하지 않는 거짓 정보를 사실인 것처럼 꾸며내는 현상입니다. |
| 심사위원 모델 | LLM as a Judge | 평가 규칙을 프롬프트 형태로 전달받아 타 모델의 결과물을 정량 채점하는 평가 전담 모델입니다. |
