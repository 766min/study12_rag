## 2. RAGAS 검색 평가 지표의 원리

<aside>
💡

<u>**검색 품질 측정의 2대 기준**</u>
검색기가 가져온 정보의 순도(정밀도)와 누락 여부(재현율)를 0부터 1 사이의 점수로 환산하는 기준입니다.

</aside>

### 2.1 문맥 정밀도 (Context Precision)

<aside>

- **개념**: 검색된 문서 묶음 중 질문의 정답 도출에 실제 기여하는 유의미한 문서가 상위에 잘 위치하는지 측정합니다.
- **특징**: 불필요한 노이즈 문서가 섞여 있거나 핵심 문서가 아래 순위로 밀려날수록 지표 점수가 하락합니다.
</aside>

### 2.2 문맥 재현율 (Context Recall)

<aside>

- **개념**: 모범 정답(Ground Truth)을 완성하는 데 필요한 모든 핵심 근거를 검색기가 빠짐없이 찾아왔는지 측정합니다.
- **특징**: 정답 작성에 필수적인 정보가 검색 결과에서 누락될수록 지표 점수가 하락합니다.
</aside>

## 3. RAGAS 검색 지표 측정 실습

<aside>
💡

<u>**LLM 모델 기반 자동 검색 평가**</u>
정형화된 평가 데이터를 Hugging Face Dataset 객체로 변환하고 LLM 모델을 통해 정량 지표를 측정합니다.

</aside>

### 3.1 RAGAS 전용 데이터셋 변환

<aside>

- **필수 스키마 매핑**: `user_input`(질문), `reference`(모범 정답), `retrieved_contexts`(검색된 문서 목록) 규격으로 구성합니다.
- **Dataset 변환**: 판다스 데이터프레임을 RAGAS가 연산 가능한 `Dataset` 구조체로 변환합니다.

```python
import sys
from types import ModuleType

# 제거된 vertexai 모듈을 메모리에 가짜로 등록
dummy_chat_vertex = ModuleType("langchain_community.chat_models.vertexai")
dummy_chat_vertex.ChatVertexAI = type("ChatVertexAI", (), {})
sys.modules["langchain_community.chat_models.vertexai"] = dummy_chat_vertex

dummy_llm_vertex = ModuleType("langchain_community.llms.vertexai")
dummy_llm_vertex.VertexAI = type("VertexAI", (), {})
sys.modules["langchain_community.llms.vertexai"] = dummy_llm_vertex

import pandas as pd
from ragas import EvaluationDataset

# 검색 지표(정밀도, 재현율)를 평가하기 위한 데이터를 정의합니다.
# user_input: 사용자 질문
# reference: 정답 기준 문서 (RAGAS 최신 표준 키)
# retrieved_contexts: 검색기가 반환한 청크 리스트 (RAGAS 최신 표준 키)
eval_raw_data = {
    "user_input": [
        "도서관 주말 운영 시간과 대출 가능 권수는 어떻게 되나요?",
        "시험 기간 평일 도서관 마감 시간은 몇 시인가요?"
    ],
    "reference": [
        "주말은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다.",
        "시험 기간 평일 마감 시간은 22시까지입니다."
    ],
    "retrieved_contexts": [
        [
            "중앙도서관 운영 안내: 주말(토, 일)은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다.",
            "중앙도서관 매점 운영 안내: 평일 오전 9시부터 오후 6시까지 운영합니다."
        ],
        [
            "중앙도서관 특별 규정: 시험 기간 평일은 09시부터 22시까지 연장 운영합니다.",
            "도서관 분실물 보관소는 1층 로비 안내실에서 상시 운영됩니다."
        ]
    ]
}

# 딕셔너리 데이터를 2차원 표 구조의 판다스 DataFrame으로 변환합니다.
df_search_eval = pd.DataFrame(eval_raw_data)

# DataFrame을 RAGAS 평가 함수가 요구하는 Dataset 객체로 변환합니다.
ragas_dataset = EvaluationDataset.from_pandas(df_search_eval)

print("=== [RAGAS 평가용 데이터셋 변환 완료] ===")
print(ragas_dataset)
```

```
=== [RAGAS 평가용 데이터셋 변환 완료] ===
Dataset({
    features: ['user_input', 'reference', 'retrieved_contexts'],
    num_rows: 2
})
```

</aside>

### 3.2 심사위원 모델 연동 및 검색 평가 실행

<aside>

- **모델 래핑**: init_chat_model로 초기화한 LLM 모델을 LangchainLLMWrapper로 감싸 심사위원으로 지정합니다.
- **평가 수행**: `evaluate()` 함수에 데이터셋, 평가 지표 목록, 평가 모델을 전달하여 채점을 진행합니다.

```python
import os
from dotenv import load_dotenv
from datasets import Dataset
from langchain.chat_models import init_chat_model
from langchain_openai import OpenAIEmbeddings
from ragas import evaluate
from ragas.metrics import ContextPrecision, ContextRecall
from ragas.llms import LangchainLLMWrapper

load_dotenv()

# RAGAS 내부 평가 파라미터(temperature)와 호환되는 gpt-4o-mini 모델을 선언합니다.
# 일관되고 객관적인 채점을 위해 temperature는 0으로 고정합니다.
judge_model = init_chat_model(
    model="gpt-4o-mini",
    model_provider="openai",
    temperature=0
)

# LangChain 객체를 RAGAS에서 인식할 수 있는 래퍼 클래스로 포장합니다.
evaluator_llm = LangchainLLMWrapper(judge_model)

# 메트릭 클래스 인스턴스화 및 LLM 주입
metrics = [
    ContextPrecision(llm=evaluator_llm),
    ContextRecall(llm=evaluator_llm)
]

# evaluate 함수를 호출하여 context_precision과 context_recall 지표를 일괄 측정합니다
evaluation_result = evaluate(
    dataset=ragas_dataset,
    metrics=metrics,
    raise_exceptions=True
)

print("검색 지표 측정이 정상적으로 완료되었습니다.")
```

```
검색 평가를 실행합니다. gpt-4o-mini 모델이 정밀도와 재현율을 채점 중입니다...
Evaluating: 100%|██████████| 4/4 [00:02<00:00,  1.72it/s]
검색 지표 측정이 정상적으로 완료되었습니다.
```


### 4.2 개념 요약 키워드

- **RAGAS (Retrieval Augmented Generation Assessment)**: RAG 파이프라인의 검색 및 생성 각 단계를 분리하여 정량 평가하는 전문 라이브러리입니다.
- **문맥 정밀도 (Context Precision)**: 검색된 문서들 중 실제 유효한 근거 문서가 상위 순위에 배치된 비율을 나타냅니다.
- **문맥 재현율 (Context Recall)**: 모범 정답을 도출하기 위해 필요한 모든 지식이 검색 문서 내에 누락 없이 포함된 비율을 나타냅니다.

### 4.3 용어 사전

| --- | --- | --- |

| **문맥 재현율** | Context Recall | 모범 정답 작성을 위해 필요한 모든 기준 정보의 포괄 비율을 측정하는 지표입니다. |
| **데이터셋 객체** | Dataset | RAGAS의 다차원 지표 채점 파이프라인에 입력하기 위해 표준 규격으로 구조화한 데이터입니다. |
| **모델 래퍼** | LLM Wrapper | 외부 프레임워크(LangChain)의 모델을 RAGAS 표준 인터페이스 규격에 맞게 연결해 주는 어댑터 클래스입니다. |
