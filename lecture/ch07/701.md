## 2. RAG 평가셋 설계 원칙과 골든셋(Golden Set)

<aside>
💡

<u>**골든셋(Golden Set)</u>**
인공지능의 성능을 객관적으로 측정하기 위해 질문, 모범 정답, 근거 문서를 엄격하게 묶어둔 '표준 정답지'입니다.

</aside>

### 2.1 평가 목적 정의와 지표 연계

<aside>

- **평가 목적 구체화**: 단순 사내 안내용인지, 오답 발생 시 치명적인 법률·규정 안내용인지에 따라 검증 강도를 결정합니다.
- **채점 지표와의 연계**: 평가 데이터는 검색 단계의 적합성 지표와 생성 단계의 사실성(Faithfulness), 관련성(Answer Relevance)을 모두 측정할 수 있도록 구성되어야 합니다.
</aside>

### 2.2 골든셋의 3대 핵심 요소

<aside>

- **질문 (Question)**: 실제 사용자가 질의할 법한 자연스럽고 명확한 입력 문장입니다.
- **모범 정답 (Ground Truth / Answer)**: 인공지능이 반드시 출력해야 하는 이상적인 표준 답변입니다.
- **근거 문서 (Context)**: 답변의 출처가 되는 원본 텍스트 청크이며, 검색 실패와 생성 실패를 명확히 판별하는 기준선이 됩니다.
</aside>

### 2.3 질의 유형(Query Type) 커버리지

<aside>

- **단순 사실 확인**: 단일 문서 내에 명시된 사실을 그대로 확인하는 기본 문항입니다.
- **복합 추론 질문**: 둘 이상의 문서 조각을 종합하여 논리적 인과관계를 비교하거나 요약해야 하는 고난도 문항입니다.
- **문서 외 함정 질문**: 근거 문서에 정답이 없는 문항으로, 모델이 외부 지식을 임의로 끌어와 거짓말을 하는 '환각(Hallucination)' 현상을 유발하는지 검증합니다.
</aside>

## 3. 평가셋 설계서 구축 및 LLM 모델 연동 실습

<aside>
💡

정의된 골든셋 데이터를 표 형태로 구조화하고, LLM 모델을 활용해 질의 유형을 자동 검증합니다.

</aside>

### 3.1 골든셋 데이터 스키마 정의 및 pandas 구조화

<aside>

평가 기준 3요소와 질의 유형을 파이썬 딕셔너리로 묶고 pandas를 활용해 표 데이터로 변환합니다.

```python
import pandas as pd

# 평가 데이터(골든셋)를 담을 리스트를 정의합니다.
# 유형, 질문, 정답, 근거 문서를 일대일로 매칭합니다.
eval_dataset = [
    {
        "query_type": "단순 사실 확인",
        "question": "도서관 주말 운영 시간과 대출 가능 권수는 어떻게 되나요?",
        "answer": "주말은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다.",
        "context": "중앙도서관 운영 안내: 주말(토, 일)은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다."
    },
    {
        "query_type": "문서 외 함정 질문",
        "question": "도서관 주말 대출 권수를 10권으로 늘리는 특별 신청 방법이 있나요?",
        "answer": "제공된 문서에는 대출 권수를 늘리는 별도의 신청 방법이 안내되어 있지 않습니다.",
        "context": "중앙도서관 운영 안내: 주말(토, 일)은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다."
    }
]

# 파이썬 리스트 데이터를 2차원 표 구조의 DataFrame으로 변환합니다.
df_eval = pd.DataFrame(eval_dataset)

# 생성된 표 구조를 확인하고 파일로 내보냅니다.
print("=== [평가셋 설계 데이터프레임] ===")
print(df_eval[["query_type", "question"]])

# 추후 RAGAS 평가에 즉시 활용할 수 있도록 CSV 포맷으로 저장합니다.
df_eval.to_csv("rag_golden_set.csv", index=False, encoding="utf-8-sig")
```

```

   query_type                                question
0    단순 사실 확인        도서관 주말 운영 시간과 대출 가능 권수는 어떻게 되나요?
1  문서 외 함정 질문  도서관 주말 대출 권수를 10권으로 늘리는 특별 신청 방법이 있나요?
```

</aside>

### 3.2 LLM 모델 기반 질의 유형 검증 체인

<aside>

LLM 모델을 로드하고, 작성된 질문이 평가 목적에 맞게 설계되었는지 자동으로 판별합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

# 일관성 있는 평가 판정을 위해 창의성 수치(temperature)를 0으로 고정합니다.
model = init_chat_model(
    model="gpt-5-mini",
    model_provider="openai",
    temperature=0
)

# 평가셋 질문의 유형 적합성을 판별하는 프롬프트를 작성합니다.
type_check_prompt = PromptTemplate.from_template(
    "당신은 RAG 평가셋 품질 검수관입니다.\n"
    "[근거 문서]와 [질문]을 비교하여 해당 질문의 '질의 유형'을 아래 3가지 중 하나로 분류하고 판정 이유를 1줄로 작성하세요.\n\n"
    "1. 단순 사실 확인: 문서에 직접적인 정답이 명시되어 있는 경우\n"
    "2. 복합 추론 질문: 여러 문맥을 종합해야 정답 도출이 가능한 경우\n"
    "3. 문서 외 함정 질문: 문서 내용만으로는 정답을 알 수 없거나 문서에 없는 내용을 묻는 경우\n\n"
    "[근거 문서]: {context}\n"
    "[질문]: {question}\n\n"
    "[출력 형식]:\n"
    "판정 유형: <유형명>\n"
    "판정 이유: <1줄 사유>"
)

# 프롬프트, LLM, 문자열 파서를 파이프라인 체인으로 결합합니다.
validate_chain = type_check_prompt | model | StrOutputParser()

# 테스트할 평가 데이터셋 항목을 지정합니다.
sample_target = eval_dataset[1]

# 체인을 실행하여 LLM 모델의 자동 검증 결과를 확인합니다.
validation_result = validate_chain.invoke({
    "context": sample_target["context"],
    "question": sample_target["question"]
})

print("=== [질의 유형 검증 결과] ===")
print(validation_result)
```

```
=== [질의 유형 검증 결과] ===
판정 유형: 문서 외 함정 질문
판정 이유: 문서에는 주말 대출이 최대 5권이라고만 명시되어 있고 10권으로 늘리는 특별 신청 방법에 대한 언급이 없어 문서만으로는 답을 알 수 없습니다.
```

### 4.2 개념 요약 키워드

- **평가셋 (Evaluation Set)**: 인공지능의 검색 및 답변 능력을 다각도로 검증하기 위해 미리 구성해 둔 모의고사 데이터 세트입니다.
- **골든셋 (Golden Set)**: 질문, 모범 정답, 원본 근거 문서가 완벽한 삼위일체로 구축된 고품질 기준 데이터입니다.
- **질의 유형 커버리지 (Query Coverage)**: 단순 질의부터 고난도 추론 및 환각 검증용 함정 질의까지 골고루 다루는 문항 다양성 범위입니다.

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| 골든셋 | Golden Set | 채점의 절대적인 기준선 역할을 수행하는 [질문 + 정답 + 근거 문서] 정합 데이터입니다. |
| 질의 커버리지 | Query Coverage | 평가셋이 단순 질문부터 복합 추론, 함정 질문까지 다양한 시나리오를 다루는 범위를 의미합니다. |
| 데이터프레임 | DataFrame | 행과 열로 이루어진 2차원 표 형태의 구조화된 데이터 객체입니다. |
| 온도 | Temperature | 언어 모델의 출력 무작위성을 제어하는 값으로, 평가 시에는 일관성을 위해 0으로 고정합니다. |
