## 2. 파이프라인 개선과 회귀 검증 원리

<aside>
💡

<u>**회귀 검증(Regression Verification)**</u>
파이프라인 수정 후 기존에 정상 작동하던 기능이 훼손되지 않았는지 동일한 평가셋으로 점검하는 작업입니다.

</aside>

### 2.1 진단 결과 기반 파이프라인 개선

<aside>

- **Grounding 제약 강화**: 참고 문서에 없는 외부 지식을 임의로 생성하는 환각을 억제합니다.
- **지시 조건 명확화**: 글자 수 제한, 줄 수 요약 등의 포맷 지침을 엄격히 준수하도록 수정합니다.
- **부작용 방어**: 오류를 막기 위해 추가한 규칙 때문에 정상 질문까지 답변을 거부하지 않도록 설계합니다.
</aside>

### 2.2 Ragas 기반의 정량적 회귀 평가 원리

<aside>

- **Faithfulness (사실성)**: 생성된 답변이 참고 문서의 내용에 온전히 근거하는지 측정합니다 (0~1점)
- **Answer Relevance (답변 관련성)**: 생성된 답변이 사용자의 질문 의도에 직접적으로 부합하는지 측정합니다 (0~1점)
- **정량적 A/B 비교**: 직관에 의존하지 않고 수치화된 지표를 통해 개선 효과와 회귀 발생 여부를 확인합니다.
</aside>

## 3. 파이프라인 개선 및 Ragas 회귀 검증 실습

### 3.1 검증용 데이터셋 정의 및 RAG 체인 구축

<aside>

- **평가 데이터 준비**: 이전 강에서 분류한 오류 케이스(환각, 문맥 무시, 지시 불이행)와 정상 케이스를 준비합니다.
- **체인 비교 구성**: 느슨한 프롬프트(Baseline)와 규칙을 보강한 프롬프트(Improved)를 각각 선언합니다.

```python
import os
from dotenv import load_dotenv

# 데이터 처리를 위해 pandas를 불러옵니다.
import pandas as pd

# LangChain의 OpenAI 모델 및 프롬프트, 출력 파서를 불러옵니다.
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

# 답변 생성 및 평가에 사용할 gpt-4o-mini 모델을 선언합니다. (일관성을 위해 temperature=0 설정)
model = init_chat_model(model_provider="openai", model="gpt-4o-mini", temperature=0)

# 4가지 테스트 사례(환각, 문맥 무시, 지시 불이행, 정상)를 정의합니다.
eval_raw_data = {
    "question": [
        "2026년 공과대학 봄 축제 초청 가수는 누구인가요?",
        "중앙도서관 일일 연체료는 얼마인가요?",
        "학생 식당 운영 시간을 1줄로 요약해 주세요.",
        "기숙사 헬스장 이용 시간은 언제인가요?"
    ],
    "contexts": [
        "2026년 공과대학 봄 축제 공식 초청 가수는 아이유입니다.",
        "2026학년도부터 개정된 규정에 따라 중앙도서관 도서 연체료는 일일 1,000원으로 적용됩니다.",
        "학생 식당 조식은 08:00~09:30, 중식은 11:30~13:30, 석식은 17:30~19:00에 운영됩니다.",
        "기숙사 헬스장은 연중무휴 24시간 자율 개방됩니다."
    ],
    "reference": [
        "2026년 공과대학 봄 축제 초청 가수는 아이유입니다.",
        "중앙도서관 일일 연체료는 1,000원입니다.",
        "학생 식당은 조식 08:00~09:30, 중식 11:30~13:30, 석식 17:30~19:00에 운영됩니다.",
        "기숙사 헬스장은 24시간 자율 개방됩니다."
    ]
}

# 딕셔너리를 판다스 데이터프레임으로 변환합니다.
df_eval = pd.DataFrame(eval_raw_data)

# 개선 전(Baseline) 프롬프트: 제약 조건이 모호하여 환각과 서술 확장이 발생하기 쉬운 형태입니다.
baseline_prompt = ChatPromptTemplate.from_template(
    """당신은 대학 생활 도우미입니다. 질문에 대해 친절하게 답해 주세요.

참고 정보:
{contexts}

질문: {question}"""
)
baseline_chain = baseline_prompt | model | StrOutputParser()

# 개선 후(Improved) 프롬프트: 문서 외 지식 의존을 차단하고 출력 형식을 강제한 형태입니다.
improved_prompt = ChatPromptTemplate.from_template(
    """당신은 대학 학사 행정을 안내하는 RAG 답변 생성 도우미입니다.
반드시 아래 제시된 [참고 문서]의 내용에만 근거하여 질문에 답변하세요.

[규칙]:
1. [참고 문서]에 명시된 사실만을 서술하며, 과거 기억이나 추측은 절대 포함하지 마세요.
2. 질문에서 요약이나 분량 제한(예: 1줄 요약)을 지정한 경우, 인사말 없이 한 문장으로만 답변하세요.
3. 문서 내용과 무관하거나 문서에서 확인할 수 있는 정보는 '제공된 문서에서 확인할 수 없습니다'라고 답하세요.

[참고 문서]:
{contexts}

[질문]:
{question}"""
)
improved_chain = improved_prompt | model | StrOutputParser()
```

</aside>

### 3.2 개선 전후 응답 생성

<aside>

- **순차 실행**: 동일한 질문과 컨텍스트를 두 파이프라인에 주입하여 각각의 응답을 수집합니다.
- **응답 기록**: 수집된 응답 문자열을 리스트에 적재하여 Ragas 평가용 데이터 입력으로 준비합니다.

```python
# 답변을 담을 리스트를 초기화합니다.
baseline_answers = []
improved_answers = []

print("두 파이프라인의 응답 생성을 시작합니다...\n")

# 데이터셋을 행 단위로 순회하며 답변을 생성합니다.
for idx, row in df_eval.iterrows():
    input_data = {
        "question": row["question"],
        "contexts": row["contexts"]
    }
    
    # 개선 전 파이프라인 응답 생성
    base_ans = baseline_chain.invoke(input_data)
    baseline_answers.append(base_ans)
    
    # 개선 후 파이프라인 응답 생성
    impr_ans = improved_chain.invoke(input_data)
    improved_answers.append(impr_ans)
    
    print(f"[사례 {idx + 1}] 질문: {row['question']}")
    print(f" - 개선 전 응답: {base_ans}")
    print(f" - 개선 후 응답: {impr_ans}\n")
```

```
 - 개선 후 응답: 학생 식당은 조식 08:00~09:30, 중식 11:30~13:30, 석식 17:30~19:00에 운영됩니다.

 - 개선 전 응답: 기숙사 헬스장은 연중무휴 24시간 자율 개방되므로, 언제든지 원하는 시간에 이용하실 수 있습니다. 편리하게 이용하세요!
```

### 3.3 Ragas 회귀 평가 및 리포트 저장

<aside>

- **EvaluationDataset 구축**: Ragas 네이티브 규격인 `EvaluationDataset.from_list()`로 데이터를 변환합니다.
- **평가자 래핑**: gpt-4o-mini 모델과 임베딩 모델을 LangchainLLMWrapper로 래핑하여 심사위원으로 등록합니다.
- **최종 CSV 저장**: 평가 결과를 데이터프레임으로 변환한 뒤 UTF-8 BOM 인코딩으로 저장합니다.

```python
import sys
from types import ModuleType

# 라이브러리 간 import 충돌을 방지하기 위해 가상 모듈을 등록합니다.
dummy_chat_vertex = ModuleType("langchain_community.chat_models.vertexai")
dummy_chat_vertex.ChatVertexAI = type("ChatVertexAI", (), {})
sys.modules["langchain_community.chat_models.vertexai"] = dummy_chat_vertex

dummy_llm_vertex = ModuleType("langchain_community.llms.vertexai")
dummy_llm_vertex.VertexAI = type("VertexAI", (), {})
sys.modules["langchain_community.llms.vertexai"] = dummy_llm_vertex

from ragas import EvaluationDataset, evaluate
from ragas.metrics import Faithfulness, AnswerRelevancy
from ragas.llms import LangchainLLMWrapper
from ragas.embeddings import LangchainEmbeddingsWrapper
from langchain_openai import OpenAIEmbeddings

# 평가 심사에 사용할 gpt-4o-mini 모델과 임베딩 모델을 선언합니다.
evaluator_llm = init_chat_model(model_provider="openai", model="gpt-4o-mini", temperature=0)
evaluator_embedding = OpenAIEmbeddings(model="text-embedding-3-small")

# Ragas 인터페이스 규격으로 래핑합니다.
ragas_llm = LangchainLLMWrapper(evaluator_llm)
ragas_embeddings = LangchainEmbeddingsWrapper(evaluator_embedding)

# 지표 객체를 인스턴스화하고 평가 모델을 주입합니다.
metrics = [
    Faithfulness(llm=ragas_llm),
    AnswerRelevancy(llm=ragas_llm, embeddings=ragas_embeddings)
]

# 개선 전(Baseline) 데이터를 EvaluationDataset 규격 리스트로 구성합니다.
baseline_samples = []
for idx, row in df_eval.iterrows():
    baseline_samples.append({
        "user_input": row["question"],
        "retrieved_contexts": [row["contexts"]],
        "response": baseline_answers[idx],
        "reference": row["reference"]
    })

# Ragas 전용 EvaluationDataset 객체로 생성합니다.
eval_dataset_baseline = EvaluationDataset.from_list(baseline_samples)

# 개선 후(Improved) 데이터를 EvaluationDataset 규격 리스트로 구성합니다.
improved_samples = []
for idx, row in df_eval.iterrows():
    improved_samples.append({
        "user_input": row["question"],
        "retrieved_contexts": [row["contexts"]],
        "response": improved_answers[idx],
        "reference": row["reference"]
    })

# Ragas 전용 EvaluationDataset 객체로 생성합니다.
eval_dataset_improved = EvaluationDataset.from_list(improved_samples)

print("Ragas 회귀 평가를 실행합니다 (gpt-4o-mini 심사 진행 중)...")

# 개선 전 파이프라인 지표 측정
result_baseline = evaluate(
    dataset=eval_dataset_baseline,
    metrics=metrics,
    raise_exceptions=True
)

# 개선 후 파이프라인 지표 측정
result_improved = evaluate(
    dataset=eval_dataset_improved,
    metrics=metrics,
    raise_exceptions=True
)

# Ragas 결과 객체를 판다스 데이터프레임으로 변환합니다.
df_res_base = result_baseline.to_pandas()
df_res_impr = result_improved.to_pandas()

# 최종 비교용 데이터프레임을 구성합니다.
df_report = pd.DataFrame({
    "question": df_eval["question"],
    "baseline_answer": baseline_answers,
    "improved_answer": improved_answers,
    "base_faithfulness": df_res_base["faithfulness"],
    "impr_faithfulness": df_res_impr["faithfulness"],
    "base_relevancy": df_res_base["answer_relevancy"],
    "impr_relevancy": df_res_impr["answer_relevancy"]
})

print("\n=== [회귀 평가 최종 비교 리포트] ===")
print(df_report[["question", "base_faithfulness", "impr_faithfulness", "base_relevancy", "impr_relevancy"]])

# UTF-8 BOM 인코딩을 적용하여 CSV 파일로 저장합니다.
output_csv = "regression_evaluation_report.csv"
df_report.to_csv(output_csv, index=False, encoding="utf-8-sig")
print(f"\n회귀 검증 결과 리포트가 성공적으로 저장되었습니다: '{output_csv}'")
```

### 4.2 개념 요약 키워드

- **EvaluationDataset**: Ragas의 자체 표준 데이터 구조로, 평가 지표가 요구하는 컬럼 스키마를 검증하고 보관하는 컨테이너입니다.
- **회귀 검증 (Regression Verification)**: 파이프라인을 개선한 뒤 기존의 정상 동작이 손상되지 않았음을 동일 평가셋으로 확인하는 품질 보증 작업입니다.
- **충실도 (Faithfulness)**: 언어 모델의 답변이 제공된 참고 문서의 팩트에 얼마나 엄격하게 기반하고 있는지를 나타내는 지표입니다.

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **평가 데이터셋** | EvaluationDataset | Ragas 0.2+에서 질의, 문맥, 응답, 모범 답안을 구조화하여 관리하는 전용 데이터 객체입니다. |
| **회귀 검증** | Regression Verification | 시스템을 수정한 후 기존에 정상 작동하던 기능에 오류가 생기지 않았는지 재확인하는 테스트입니다. |
| **답변 관련성** | Answer Relevancy | 생성된 모델의 답변이 질문자의 질문 의도에 알맞게 부합하는지를 평가하는 지표입니다. |
| **충실도** | Faithfulness | 생성 답변에 포함된 주장이 참고 문서의 사실에 근거하는지 확인하여 환각 여부를 측정하는 지표입니다. |
