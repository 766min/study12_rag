### 2.1 평가셋 데이터 스키마 정의 및 pandas 변환

<aside>

- **골든셋 3대 요소 매칭**: 질의 유형, 질문, 정답, 근거 문서를 딕셔너리로 구성합니다.
- **데이터프레임 변환**: 파이썬 리스트 데이터를 2차원 표 구조로 가공합니다.

```python
import pandas as pd

# 질문, 모범 정답, 근거 문서를 포함한 평가 데이터셋을 정의합니다.
eval_dataset = [
    {
        "query_type": "단순 사실 확인",

        "context": "중앙도서관 운영 안내: 주말(토, 일)은 오전 10시부터 오후 5시까지 운영하며, 1인당 최대 5권까지 대출 가능합니다."
    },
    {
        "query_type": "복합 추론 질문",
        "question": "시험 기간 평일과 주말 중 도서관을 더 늦게까지 이용할 수 있는 날은 언제인가요?",
        "answer": "평일에 더 늦게까지 이용할 수 있습니다. 평일은 22시까지, 주말은 17시까지 운영합니다.",
        "context": "중앙도서관 운영 안내: 시험 기간 평일은 09시부터 22시까지 운영하며, 주말(토, 일)은 10시부터 17시까지 운영합니다."
    },
    {
        "query_type": "문서 외 함정 질문",
        "question": "도서관 주말 대출 권수를 10권으로 늘리는 특별 신청 방법이 있나요?",

# 파이썬 리스트를 2차원 표(DataFrame)로 변환합니다.
```

## 3. LLM 모델 기반 평가셋 품질 자동 검수

<aside>
💡

<u>**LLM 모델을 활용한 자동 품질 점검**</u>
작성된 정답이 근거 문서에 기반하고 있는지 LLM 모델로 자동 교정 및 판별합니다.

</aside>

### 3.1 LLM 모델 로드 및 검수 프롬프트 설정

<aside>

- **일관된 판정 제어**: 출력의 일관성을 위해 `temperature=0`으로 설정합니다.
- **검수 기준 정의**: 모범 정답이 근거 문서의 내용과 일치하는지 판별하는 규칙을 프롬프트에 주입합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

# 채점 및 검수의 일관성을 유지하기 위해 temperature를 0으로 고정합니다.
model = init_chat_model(
    model="gpt-5-mini",
    model_provider="openai",
    temperature=0
)

# 평가셋의 모범 정답이 근거 문서에 부합하는지 검수하는 프롬프트를 작성합니다.
quality_check_prompt = PromptTemplate.from_template(
    "당신은 RAG 평가셋 품질 검수관입니다.\n"
    "제공된 [근거 문서]를 바탕으로 [질문]과 [모범 정답]의 정합성을 검수하세요.\n\n"
    "[검수 기준]\n"
    "1. 일치: 모범 정답이 근거 문서의 사실에 완벽히 부합하거나, 정보가 없는 경우 적절히 문서 부재를 명시한 경우\n"
    "2. 불일치: 모범 정답이 근거 문서의 사실과 다르거나 근거 없는 내용을 단정한 경우\n\n"
    "[근거 문서]: {context}\n"
    "[질문]: {question}\n"
    "[모범 정답]: {answer}\n\n"
    "[출력 형식]:\n"
    "판정 결과: <일치 또는 불일치>\n"
    "검수 의견: <1줄 설명>"
)

# 프롬프트, 모델, 파서를 결합하여 검수 파이프라인 체인을 구성합니다.
quality_chain = quality_check_prompt | model | StrOutputParser()

```

</aside>

### 3.2 평가셋 전수 자동 검수 및 파일 저장

<aside>

- **배치 검수 수행**: 작성된 평가 문항을 차례대로 검수 체인에 입력하여 품질을 판별합니다.
- **CSV 내보내기**: 검수가 완료된 데이터를 UTF-8 형식의 CSV 파일로 보관합니다.

```python
# 평가셋의 각 문항을 순회하며 gpt-5-mini 모델로 품질을 검수합니다.
inspection_results = []

for index, row in df_eval.iterrows():
    # 체인을 호출하여 검수 결과를 도출합니다.
    result = quality_chain.invoke({
        "context": row["context"],
        "question": row["question"],
        "answer": row["answer"]
    })
    inspection_results.append(result)

# 검수 결과를 데이터프레임의 새로운 열로 추가합니다.
df_eval["inspection_result"] = inspection_results

# 검수 결과 요약을 출력합니다.
print("=== [평가셋 자동 검수 완료 리포트] ===")
for i, res in enumerate(df_eval["inspection_result"]):
    print(f"[문항 {i+1}]\n{res}\n")

# 검수가 완료된 최종 평가셋을 CSV 파일로 저장합니다.
output_file = "rag_golden_set.csv"
df_eval.to_csv(output_file, index=False, encoding="utf-8-sig")
print(f"최종 저장 완료: '{output_file}' 파일이 생성되었습니다.")
```

```
=== [평가셋 자동 검수 완료 리포트] ===
[문항 1]
판정 결과: 일치
검수 의견: 모범 정답이 근거 문서의 주말 운영 시간(오전 10시~오후 5시)과 대출 한도(1인당 최대 5권)를 정확히 반영하고 있습니다.

[문항 2]

검수 의견: 모범 정답이 근거 문서의 운영시간(평일 09:00–22:00, 주말 10:00–17:00)을 정확히 반영하여 평일이 더 늦게까지 이용 가능하다고 명시했습니다.

최종 저장 완료: 'rag_golden_set.csv' 파일이 생성되었습니다.
```

### 4.2 개념 요약 키워드

- **골든셋 (Golden Set)**: 질문, 모범 정답, 근거 문서가 정확하게 묶인 RAG 평가의 기준선 데이터입니다.
- **자동 검수 파이프라인 (Auto-Inspection Chain)**: LLM 모델을 활용해 평가셋 내 모범 정답이 근거 문서에 부합하는지 검증하는 자동화 구조입니다.
- **결측치 (Missing Value)**: 입력되지 않고 비어있는 셀로, 정량 평가 실행 전 반드시 0으로 정리되어야 합니다.

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **골든셋** | Golden Set | 평가의 절대적 기준 역할을 수행하는 [질문 + 정답 + 근거 문서] 정합 데이터 세트입니다. |
| **데이터프레임** | DataFrame | 행과 열로 구성된 판다스의 2차원 표 형태 데이터 객체입니다. |
| **온도** | Temperature | 언어 모델의 창의성 및 무작위성을 제어하는 파라미터이며, 평가 시에는 0으로 고정합니다. |
| **체인** | Chain | 프롬프트, 언어 모델, 출력 파서를 파이프(`|`) 연산자로 연결한 일련의 실행 흐름입니다. |
