## 2. 하이브리드 검색의 원리와 결합 방식

<aside>
💡

<u>**하이브리드 검색(Hybrid Search)**</u>
하이브리드 검색은 정확한 단어를 짚어내는 '키워드 검색(BM25)'과 문맥과 뉘앙스를 파악하는 '의미 기반 벡터 검색'의 장점을 결합하여, 중요한 문서가 누락되는 문제를 방지하는 기술입니다. 서로의 빈틈을 완벽히 메워주는 이 두 검색 결과를 하나의 신뢰도 높은 목록으로 자연스럽게 합쳐주는 순위 융합 알고리즘(RRF 등)이 전체 시스템의 핵심입니다.

</aside>

### 2.1 키워드 검색과 벡터 검색의 상호 보완

<aside>

- **키워드 검색의 강점**: 고유명사, 제품 일련번호, 정확한 날짜 매칭에 뛰어납니다.
- **벡터 검색의 강점**: 동의어, 오타, 문맥적 뉘앙스 파악에 뛰어납니다.
- **결합 목적**: 질문에 모델명과 추상적 묘사가 섞여 있어도 놓치지 않고 문서를 찾기 위함입니다.
</aside>

### 2.2 검색 결과 결합 방식 (가중합과 RRF)

<aside>

- **가중합 (Weighted Sum)**: 각 검색 점수에 비중을 곱하여 더하는 직관적인 방식입니다.
    
    `최종 점수 = (키워드 점수 × 0.3) + (벡터 점수 × 0.7)`
    
- **역순위 융합 (RRF, Reciprocal Rank Fusion)**: 점수 단위가 다른 두 결과를 '등수(순위)' 기준으로 합산하는 공식입니다.
    
    `RRF 점수 = 1 / (순위 + 60)`
    
</aside>

## 3. 코드로 보는 하이브리드 검색과 답변 생성

### 3.1 하이브리드 검색기 구성 및 LLM 모델 선언

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_community.retrievers import BM25Retriever
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain_classic.retrievers import EnsembleRetriever

load_dotenv()

# 검색 대상 가상 문서 리스트 준비
documents = [
    Document(page_content="애플의 새로운 스마트폰 아이폰 15가 출시되었습니다."),
    Document(page_content="삼성전자의 갤럭시 S24는 온디바이스 AI 기능이 뛰어납니다."),
    Document(page_content="현대자동차의 전기차 아이오닉은 배터리 연비가 우수합니다.")
]

# [방식 1] 키워드 검색기 (BM25) 생성
# 단어 일치 여부를 기반으로 2개의 문서를 추출하도록 설정합니다.
bm25_retriever = BM25Retriever.from_documents(documents)
bm25_retriever.k = 2

# [방식 2] 벡터 검색기 생성
# 문장을 숫자로 변환하는 임베딩 모델을 선언합니다.
embeddings_model = OpenAIEmbeddings(model="text-embedding-3-small")
# 메모리 기반 벡터 데이터베이스에 문서를 적재합니다.
vectorstore = InMemoryVectorStore.from_documents(documents, embeddings_model)
vector_retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

# 하이브리드 검색기 (EnsembleRetriever) 결합
# 키워드 검색에 30%(0.3), 벡터 검색에 70%(0.7)의 가중치를 배정합니다.
hybrid_retriever = EnsembleRetriever(
    retrievers=[bm25_retriever, vector_retriever],
    weights=[0.3, 0.7]
)

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)
```

</aside>

### 3.2 검색 실행 및 LLM 모델 답변 생성

<aside>

```python
# 검색어 설정 (고유명사 'AI'와 문맥적 표현 '사과 모양'이 공존)
query = "사과 모양 로고 휴대폰이랑 AI 기능이 들어간 폰 알려줘"

# 하이브리드 검색 실행
retrieved_docs = hybrid_retriever.invoke(query)

# 검색된 문맥 문서 텍스트 병합
context = "\n\n".join([f"- {doc.page_content}" for doc in retrieved_docs])

# LLM 모델에 전달할 프롬프트 구성
prompt = f"""다음 문서를 참고하여 질문에 명확하고 친절하게 답변하세요.

[참고 문서]
{context}

[질문]
{query}"""

# 언어 모델 추론 실행
response = model.invoke(prompt)

# 실행 결과 출력
print(f"질문: {query}\n")
print("[하이브리드 검색 결과 문서]")
for idx, doc in enumerate(retrieved_docs):
    print(f"{idx + 1}위: {doc.page_content}")

print("\n[최종 답변]")
print(response.content)
```


### 4.2 개념 요약 키워드

- **하이브리드 검색 (Hybrid Search)**: 정확한 키워드 매칭과 깊은 의미 분석을 결합하여 실패율을 줄이는 RAG 검색 파이프라인의 필수 기술.
- **앙상블 리트리버 (EnsembleRetriever)**: 서로 다른 검색 알고리즘을 묶고 가중치를 부여하여 통합된 문서 랭킹을 산출하는 도구.

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **하이브리드 검색** | Hybrid Search | 키워드 일치 검색과 시맨틱 벡터 검색을 결합하여 상호 보완하는 검색 방식 |
| **앙상블 리트리버** | Ensemble Retriever | 복수의 검색기를 하나의 인터페이스로 통합해 결합 점수를 계산하는 LangChain 클래스 |
| **가중합** | Weighted Sum | 서로 다른 검색기 점수에 비중(예: 0.3 대 0.7)을 곱해 더하는 결합 방식 |
| **역순위 융합** | Reciprocal Rank Fusion (RRF) | 점수 척도의 편향을 제거하기 위해 순위의 역수를 기준으로 문서를 재정렬하는 기법 |
