## 2. Query 변환의 원리와 4대 핵심 전략

<aside>
💡

<u>**Query 변환(Query Transformation)</u>**
사용자의 자연어 질문을 검색 시스템이 이해하기 쉬운 최적의 표현으로 재작성하는 전처리 기법입니다.

</aside>

### 2.1 검색 전단계(Pre-Retrieval) 최적화의 필요성

<aside>

- **어휘 불일치 해소**: 구어체 질문과 데이터베이스 문서 간의 단어 표현 차이를 극복합니다.
- **모호성 제거**: 오타, 축약어, 생략된 주어 및 대명사를 명확한 단어로 보완합니다.
- **검색 품질 사전 확보**: 잘못된 질의로 인한 1차 검색 실패를 선제적으로 차단합니다.
</aside>

### 2.2 질의 특성별 4대 변환 기법 비교

<aside>

| **기법** | **영문 표기** | **핵심 동작** | **최적 적용 시나리오** |
| --- | --- | --- | --- |
| **질문 재작성** | Query Rewrite | 맞춤법 교정 및 핵심 명사 중심 재구성 | 질문이 지나치게 짧거나 은어·오타가 포함된 경우 |
| **가설 문서 임베딩** | HyDE | 가상의 예상 답변 문서를 먼저 생성 후 검색 | 질문과 정답 문서 간의 문체·전문성 격차가 큰 경우 |
| **질문 라우팅** | Query Routing | 질문의 성격을 판별하여 저장소 경로 지정 | 복수의 특화 데이터베이스(문서, SQL, 웹)가 존재하는 경우 |
| **대화 맥락 반영** | Memory 기반 검색 | 직전 대화 기록을 참조해 생략된 대명사 복원 | 멀티턴 챗봇 환경에서 연속된 질문을 처리하는 경우 |
</aside>

## 3. 코드로 구현하는 Query 변환 기법

### 3.1 Query Rewrite: 질문 재작성

<aside>

- 사용자의 모호한 구어체 질문을 검색 엔진이 식별하기 쉬운 표준 단어로 다시 구성합니다.
- LLM 모델을 사용하여 핵심 키워드가 포함된 문장으로 재작성합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate

load_dotenv()

model = init_chat_model(
    model="gpt-5-mini",
    model_provider="openai",
    temperature=0
)

# 질문 재작성을 위한 프롬프트 정의
rewrite_prompt = PromptTemplate.from_template(
    "사용자의 질문을 검색 시스템이 문서를 탐색하기 유리하도록 핵심 명사 중심의 명확한 문장으로 다시 작성하세요.\n"
    "사용자 질문: {question}\n"
    "변환된 질문:"
)

# 체인 연결
rewrite_chain = rewrite_prompt | model

# 실행 및 결과 확인
raw_query = "사과폰 최신형 배터리 얼마나 가?"
rewritten_query = rewrite_chain.invoke({"question": raw_query})

print(f"원본 질문: {raw_query}")
print(f"변환 질문: {rewritten_query.content}")
```

```
원본 질문: 사과폰 최신형 배터리 얼마나 가?
변환 질문: 최신형 아이폰의 배터리 수명은 얼마입니까?
```

</aside>

### 3.2 HyDE: 가설 문서 임베딩 (Hypothetical Document Embeddings)

<aside>

- 질문과 유사한 문서를 직접 찾지 않고, 언어 모델이 상상하여 작성한 가상의 답변을 먼저 생성합니다.
- 생성된 가설 문서를 임베딩하여 실제 정답 문서와의 벡터 유사도를 극대화합니다.

```python
# 가설 답변 생성을 위한 프롬프트 정의
hyde_prompt = PromptTemplate.from_template(
    "다음 질문에 대한 객관적인 사실을 서술하는 한 단락의 학술적 답변을 작성하세요.\n"
    "질문: {question}\n"
    "가설 답변:"
)

# 체인 연결
hyde_chain = hyde_prompt | model

# 실행 및 가설 문서 도출
medical_query = "열이 펄펄 끓고 목이 따가울 때 먹는 약"
hypothetical_doc = hyde_chain.invoke({"question": medical_query})

print(f"원본 질문: {medical_query}\n")
print("[HyDE 가설 문서 생성 결과]")
print(hypothetical_doc.content)
```

```
원본 질문: 열이 펄펄 끓고 목이 따가울 때 먹는 약

[HyDE 가설 문서 생성 결과]
고열과 인두통(목이 따가움)에 대한 처치는 증상 완화를 목표로 하며, 해열·진통제로서 아세트아미노펜(파라세타몰)이나 비스테로이드성 소염진통제(NSAID: 예, 이부프로펜 등)가 흔히 사용되어 열과 통증을 줄여 주지만 질환의 경과 자체를 바꾸지는 못한다. 인두염의 원인이 바이러스인 경우가 많아 휴식·수분공급·국소적 진통 보조(목사탕, 따뜻한 소금물 가글 등)로 호전되는 반면, 연쇄상구균성 인두염과 같이 세균성이 의심되거나 검사를 통해 확인된 경우에는 항생제가 적응증이 된다(항생제는 진단에 따른 처방이 필요하고 부적절한 사용은 항생제 내성·부작용을 초래할 수 있음). 소아에게 아스피린 투여는 라이 증후군 위험으로 권장되지 않으며, 간질환·출혈경향·임신 등 특정 상황에서는 약 선택에 주의가 필요하므로 만성질환이 있거나 증상이 심하거나 48시간 이상 지속되거나 호흡곤란·삼킴곤란·탈수·발진·목 경직 등의 경고증상이 있으면 의료진의 평가를 받아야 한다.
```

</aside>

### 3.3 Query Routing: 질의 라우팅

<aside>

- 입력된 질문의 의도를 분석하여 사내 규정 문서, SQL 데이터베이스, 외부 웹 검색 등 최적의 수집 경로를 선택합니다.
- 파이프라인의 불필요한 탐색 비용을 절감하고 답변 정확도를 높입니다.

```python
# 질문 분류를 위한 프롬프트 정의
routing_prompt = PromptTemplate.from_template(
    "질문을 읽고 다음 3가지 저장소 중 가장 적절한 대상을 하나만 선택하여 단어로 출력하세요: "
    "[사내규정_벡터DB, 매출실적_SQL, 최신동향_웹검색]\n"
    "질문: {question}\n"
    "선택된 저장소:"
)

# 체인 연결
routing_chain = routing_prompt | model

# 다양한 질의에 대한 분기 테스트
sample_queries = [
    "연차 유급휴가 발생 기준과 신청 절차",
    "2023년 분기별 총 매출액 및 영업이익 통계",
    "오늘 발표된 국내외 주요 인공지능 연구 뉴스"
]

print("[Query Routing 분류 결과]")
for q in sample_queries:
    routed_target = routing_chain.invoke({"question": q})
    print(f"질문: {q} -> 라우팅 경로: {routed_target.content.strip()}")
```

```
[Query Routing 분류 결과]
질문: 연차 유급휴가 발생 기준과 신청 절차 -> 라우팅 경로: 사내규정_벡터DB
질문: 2023년 분기별 총 매출액 및 영업이익 통계 -> 라우팅 경로: 매출실적_SQL
질문: 오늘 발표된 국내외 주요 인공지능 연구 뉴스 -> 라우팅 경로: 최신동향_웹검색
```

</aside>

### 3.4 Memory 기반 검색: 대화 맥락 복원

<aside>

- 이전 대화 이력(Chat History)을 분석하여 지시대명사("그거", "거기")나 생략된 목적어를 명시적 단어로 복원합니다.
- 독립 실행이 가능한 완전한 질의 형태로 변환하여 단일 검색기에 전달합니다.

```python
# 맥락 복원을 위한 프롬프트 정의
memory_prompt = PromptTemplate.from_template(
    "이전 대화 내용을 바탕으로 현재 질문에 생략된 맥락과 대명사를 복원하여 완전한 단일 검색 질문으로 재작성하세요.\n"
    "[이전 대화]\n"
    "{chat_history}\n"
    "[현재 질문]\n"
    "{question}\n"
    "복원된 질문:"
)

# 체인 연결
memory_chain = memory_prompt | model

# 연속 대화 상황 설정
history = "사용자: 어제 개봉한 마블 영화 이름이 뭐야?\nAI: '데드풀과 울버린'입니다."
follow_up_query = "그거 주인공 배우가 누구야?"

# 문맥 복원 질의 생성
contextualized_query = memory_chain.invoke({
    "chat_history": history,
    "question": follow_up_query
})

print(f"원래 질문: {follow_up_query}")
print(f"맥락 복원 질문: {contextualized_query.content}")
```

```
원래 질문: 그거 주인공 배우가 누구야?
맥락 복원 질문: 복원된 질문: 어제 개봉한 마블 영화 '데드풀과 울버린'의 주인공 배우가 누구야?
```

### 4.2 개념 요약 키워드

- **Query 변환 (Query Transformation)**: 검색 실패를 방지하기 위해 사용자 입력을 검색 엔진에 최적화된 형태로 재구성하는 전처리 전략
- **HyDE**: 질문에 대한 가상 답변을 선제작하여 실제 지식 문서와의 벡터 거리 일치율을 높이는 기술
- **Query Routing**: 질문의 의도에 맞추어 적절한 데이터 저장소(벡터 DB, SQL, 웹)로 검색 요청을 분기하는 구조

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **질문 변환** | Query Transformation | 모호하거나 불완전한 사용자 질의를 검색 시스템에 최적화된 형태로 가공하는 기법 |
| **가설 문서 임베딩** | HyDE | 질문에 대한 가상의 정답 문서를 임베딩하여 실제 유사 문서를 탐색하는 전략 |
| **질문 라우팅** | Query Routing | 질문의 의도와 데이터 유형을 판별하여 최적의 검색 도구나 DB 경로로 전달하는 기능 |
| **문맥 복원** | Contextualization | 대화 이력을 바탕으로 현재 질문의 생략된 주어 및 대명사를 구체적인 명사로 채워 넣는 작업 |
