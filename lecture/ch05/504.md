## 2. 2단계 검색과 Cross-Encoder 리랭킹 구조

<aside>
💡

<u>**리랭킹(Re-ranking)**</u>
리랭킹(Re-ranking)은 가볍고 빠른 1차 검색기로 후보 문서들을 먼저 신속하게 건져 올린 뒤, 문맥과 뉘앙스를 깊이 이해하는 고성능 리랭커(Cross-Encoder 등)로 순위를 정밀하게 다시 매기는 2단계(Two-Stage) 최적화 기술입니다. 수만, 수십만 개의 문서 전체를 무거운 AI 모델로 일일이 비교하려면 엄청난 시간과 연산 비용이 들기 때문에, 상위 후보군(Top-k)만 엄선해 집중 채점함으로써 검색 속도와 정확도라는 두 마리 토끼를 모두 잡는 전략입니다.

</aside>

### 2.1 2단계(2-Stage) 검색의 필요성과 효율성

<aside>

- **1단계 (Retrieval, 후보 추출)**: 수만 건의 데이터 중에서 관련 가능성이 높은 문서 10~20건을 밀리초(ms) 단위로 빠르게 선별합니다.
- **2단계 (Re-ranking, 정밀 재정렬)**: 1단계에서 올라온 소수의 후보 문서만을 대상으로 질문과의 실제 의미 관계를 심층 분석하여 1~3위를 다시 결정합니다.
- **처리 효율성**: 계산 비용이 큰 모델의 입력 대상을 극적으로 줄이면서도 최종 정확도는 최고 수준으로 유지할 수 있습니다.
</aside>

### 2.2 Bi-Encoder vs Cross-Encoder 동작 원리 비교

<aside>

- **Bi-Encoder (기존 벡터 검색)**: 질문과 문서를 각각 독립된 좌표(벡터)로 변환한 뒤 각도 차이만 계산하므로 매우 빠르지만, 단어 간의 세부 문맥 상호작용을 놓치기 쉽습니다.
- **Cross-Encoder (리랭커)**: 질문과 문서를 하나의 입력창에 나란히 붙여서 모델에 넣고, 두 문장이 얼마나 긴밀하게 맞물리는지 직접 교차 연산하므로 정확도가 뛰어납니다.

| **비교 항목** | **Bi-Encoder (1단계 벡터 검색)** | **Cross-Encoder (2단계 리랭커)** |
| --- | --- | --- |
| **입력 방식** | 질문과 문서를 각자 따로 임베딩 | 질문과 문서를 한 쌍으로 묶어 동시 입력 |
| **연산 속도** | 사전 계산된 벡터 비교로 매우 빠름 | 쌍(Pair)마다 실시간 심층 연산으로 상대적 느림 |
| **문맥 이해도** | 전반적인 주제 유사도 파악 | 문장 간의 세밀한 인과관계 및 일치도 파악 |
| **주요 역할** | 전체 데이터에서 상위 후보군 선별 | 선별된 후보군 내 최종 순위 뒤집기 및 재배치 |
</aside>

## 3. 코드로 구현하는 리랭킹과 LLM 연동 파이프라인

<aside>
💡

<u>**랭체인의 ContextualCompressionRetriever를 활용해 기본 검색기에 Cross-Encoder 리랭커를 조립하고, LLM 모델과 연결해 완성도 높은 QA를 구현합니다.**</u>
단어 빈도로 인해 잘못 올라온 1순위 문서를 밀어내고, 질문의 실제 의도를 담은 문서를 최상위로 재배치하는 과정을 확인합니다.

### 3.1 텍스트 데이터 준비 및 개별 검색기 생성

<aside>

사내 IT 규정 문서를 바탕으로 BM25 키워드 검색기를 1차 기본 검색기로 초기화합니다.

```python
from langchain_core.documents import Document
from langchain_community.retrievers import BM25Retriever

# 실습용 사내 IT 규정 문서를 정의합니다.
raw_documents = [
    Document(page_content="보안 규정: 업무용 PC는 3개월마다 비밀번호를 변경해야 하며 특수문자를 포함해야 합니다."),
    Document(page_content="원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다."),
    Document(page_content="장비 지급 규정: 신규 입사자에게는 노트북 1대와 외장 모니터 1대가 기본 지급됩니다."),
    Document(page_content="계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.")
]

# 공백 기준 단순 토크나이저 함수를 정의합니다.
def custom_tokenizer(text: str) -> list[str]:
    # 문장을 띄어쓰기 단위로 쪼개어 단어 목록을 생성합니다.
    return text.split()

# 1단계 기본 검색기(BM25)를 생성하고 후보군 추출 개수를 3개로 설정합니다.
base_retriever = BM25Retriever.from_documents(
    documents=raw_documents,
    preprocess_func=custom_tokenizer
)
# 1단계 검색에서 상위 3개의 문서를 뽑아오도록 지정합니다.
base_retriever.k = 3
```

</aside>

### 3.2 Cross-Encoder 모델을 활용한 순위 재조정(Re-ranking)

<aside>

오픈소스 고성능 다국어 크로스 인코더 모델을 로드하고 압축기(Compressor) 형태로 1차 검색기에 결합합니다.

```python
# 허깅페이스 기반 Cross-Encoder 래퍼 클래스를 가져옵니다.
from langchain_community.cross_encoders import HuggingFaceCrossEncoder
# 문서를 재정렬해 상위 결과를 선별하는 리랭커 모듈을 가져옵니다.
from langchain_classic.retrievers.document_compressors import CrossEncoderReranker

# 기본 검색기와 압축기를 하나로 묶어주는 리트리버를 가져옵니다.
from langchain_classic.retrievers import ContextualCompressionRetriever

# 한국어와 영어를 지원하는 다국어 경량 Cross-Encoder 모델을 초기화합니다.
cross_encoder_model = HuggingFaceCrossEncoder(model_name="Dongjin-kr/ko-reranker")

# Cross-Encoder 기반 리랭커를 정의하고, 재정렬 후 최종 2건만 남기도록 지정합니다.
reranker = CrossEncoderReranker(
    model=cross_encoder_model,
    top_n=2
)

# 1차 검색기(base_retriever)와 2차 리랭커(reranker)를 연결합니다.
rerank_retriever = ContextualCompressionRetriever(
    base_compressor=reranker,
    base_retriever=base_retriever
)

```

</aside>

### 3.3 리랭킹 전후 검색 순위 및 점수 비교 분석

<aside>

질문 문맥에 따라 1차 검색 결과의 순위가 리랭커를 통해 어떻게 역전되는지 확인합니다.

```python
# 질문 정의: 비밀번호 실패로 인한 계정 잠금 문제를 묻는 우회적 질문
query = "사내 망 들어가려다 비밀번호 여러 번 틀렸을 때 처리 방법"

# 1차 기본 검색기(BM25)만의 결과 확인
docs_before = base_retriever.invoke(query)
print(f"=== [1차 검색 (BM25 단독)] 검색어: {query} ===")
for idx, doc in enumerate(docs_before):
    print(f"{idx + 1}순위: {doc.page_content}")

print("\n" + "=" * 60 + "\n")

# 2단계 리랭킹(BM25 + Cross-Encoder)이 적용된 최종 결과 확인
docs_after = rerank_retriever.invoke(query)
print(f"=== [2단계 리랭킹 적용] 검색어: {query} ===")
for idx, doc in enumerate(docs_after):
    print(f"{idx + 1}순위: {doc.page_content}")
```

```
=== [1차 검색 (BM25 단독)] 검색어: 사내 망 들어가려다 비밀번호 여러 번 틀렸을 때 처리 방법 ===
1순위: 보안 규정: 업무용 PC는 3개월마다 비밀번호를 변경해야 하며 특수문자를 포함해야 합니다.
2순위: 원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다.
3순위: 계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.

============================================================

=== [2단계 리랭킹 적용] 검색어: 사내 망 들어가려다 비밀번호 여러 번 틀렸을 때 처리 방법 ===
1순위: 계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.
2순위: 원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다.
```

1차 BM25 검색에서는 단순히 '비밀번호' 단어가 많이 일치한 보안 규정이 1순위로 나왔지만, Cross-Encoder는 질문의 핵심 의도('틀렸을 때 처리 방법')를 인지하여 **계정 관리(5회 로그인 실패)** 문서를 1순위로 역전시켰습니다.

### 3.4 LLM 모델 연동 질의응답 파이프라인 완성

<aside>

리랭킹으로 추출된 최상위 문맥을 LLM 모델에 전달하여 최종 답변을 생성합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate

load_dotenv()

model = init_chat_model(
    model="gpt-5-mini",
    model_provider="openai",
    temperature=0
)

# 질문과 문맥을 전달받을 프롬프트 템플릿을 생성합니다.
qa_prompt = PromptTemplate.from_template(
    "다음 제공된 [참고 문서]를 바탕으로 [질문]에 대해 핵심 조치 사항을 간결하게 답변하세요.\n\n"
    "[참고 문서]: \n{context}\n\n"
    "[질문]: \n{question}\n\n"
    "[답변]:"
)

# 리랭킹으로 선별된 2건의 문서를 문맥 텍스트로 합칩니다.
selected_query = "사내 망 들어가려다 비밀번호 여러 번 틀렸을 때 처리 방법"
reranked_docs = rerank_retriever.invoke(selected_query)
context_text = "\n".join([doc.page_content for doc in reranked_docs])

# 프롬프트와 모델을 파이프로 연결하여 체인을 생성합니다.
qa_chain = qa_prompt | model

# 질의응답을 실행합니다.
response = qa_chain.invoke({
    "context": context_text,
    "question": selected_query
})

print(f"[질문]: {selected_query}\n")
print("[생성 답변]")
print(response.content)
```

```
[질문]: 사내 망 들어가려다 비밀번호 여러 번 틀렸을 때 처리 방법

[생성 답변]
핵심 조치(간결):
- 재택 시엔 먼저 사내 VPN을 연결한 후 인트라넷에 접속 시도. (VPN 미연결로 인증 실패할 수 있음)
- 비밀번호를 여러 번 틀렸다면 더 이상 연속 시도하지 않기(5회 연속 실패 시 계정 잠김).
- 계정이 잠기면 IT 지원팀에 잠금 해제 요청.
```

### 4.2 개념 요약 키워드

- **2단계 검색 (2-Stage Retrieval)**: 가벼운 1차 검색(후보 선별)과 정밀한 2차 리랭킹(순위 재조정)을 결합하여 속도와 정확도를 극대화하는 검색 파이프라인
- **크로스 인코더 (Cross-Encoder)**: 질문과 문서를 한 쌍으로 묶어 문맥 적합도 점수를 직접 산출하는 고정밀 인공지능 모델
- **컨텍스트 압축 (Contextual Compression)**: 검색된 결과 중 연관성이 낮은 노이즈를 제거하고 꼭 필요한 문맥만 남겨 LLM에 전달하는 기술

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **리랭킹** | Re-ranking | 1차 검색으로 찾아낸 후보 문서들을 질문과의 문맥 연관성에 따라 다시 평가하여 순위를 재정렬하는 과정입니다. |
| **크로스 인코더** | Cross-Encoder | 질문과 본문을 결합하여 한 번에 읽고, 두 문장 사이의 실제 의미적 연관도를 정밀하게 점수화하는 AI 모델입니다. |
| **압축 리트리버** | Contextual Compression Retriever | 기본 검색기 결과에 리랭커나 필터를 적용하여 불필요한 문서를 걸러내고 상위 핵심 문서만 반환하는 랭체인 모듈입니다. |
