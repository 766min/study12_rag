## 2. PostgreSQL Vector와 Hybrid Search 구조

<aside>
💡

엔터프라이즈 관계형 데이터베이스인 PostgreSQL에 벡터 검색 기능을 더하고, 단어 기반 BM25 알고리즘과 결합하여 상호 보완적인 검색망을 완성합니다.

### 2.1 저장소 분리와 검색 방식의 역할 분담

<aside>

- **PostgreSQL + Vector**: 텍스트의 임베딩 벡터를 보관하며, 문맥과 의도가 유사한 문서를 고속으로 탐색합니다.
- **BM25 검색 엔진**: 본문 내 단어 빈도(TF)와 희귀도(IDF)를 기반으로 고유 명사나 약어를 식별합니다.
- **결합 목적**: 단어는 다르지만 뜻이 통하는 문서(벡터)와 문맥 파악이 어려운 고유 규정명(BM25)을 동시에 확보합니다.
</aside>

### 2.2 EnsembleRetriever 가중치 배분 원리

<aside>

- 두 검색기가 각자 찾아온 상위 문서 목록에 가중치(Weights)를 곱해 단일 순위 점수를 계산합니다.
- 동등한 비중(0.5 : 0.5)으로 출발하여 데이터 특성에 맞게 특정 검색기의 영향력을 조절할 수 있습니다.
</aside>

## 3. 코드로 구현하는 Hybrid Search와 LLM 연동

<aside>
💡

BM25 검색기와 PostgreSQL 벡터 저장소를 각각 구축하고, 앙상블 검색기로 묶어 LLM 모델 기반 질의응답을 구현합니다.

</aside>

### 3.1 텍스트 데이터 준비 및 BM25 키워드 검색기 생성

<aside>

사내 IT 규정 문서를 정의하고 단어 단위 분절을 위한 토크나이저를 연결합니다.

```python
from langchain_core.documents import Document
from langchain_community.retrievers import BM25Retriever

# 검색 대상이 될 사내 IT 규정 문서를 생성합니다.
raw_documents = [
    Document(page_content="보안 규정: 업무용 PC는 3개월마다 비밀번호를 변경해야 하며 특수문자를 포함해야 합니다."),
    Document(page_content="원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다."),
    Document(page_content="장비 지급 규정: 신규 입사자에게는 노트북 1대와 외장 모니터 1대가 기본 지급됩니다."),
    Document(page_content="계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.")
]

# 문장을 공백 단위로 분리하는 커스텀 토크나이저를 정의합니다.
def custom_tokenizer(text: str) -> list[str]:
    # 전달받은 문장을 공백 기준으로 쪼개어 단어 목록으로 반환합니다.
    return text.split()

# 문서 목록과 토크나이저로 BM25 검색기를 초기화합니다
bm25_retriever = BM25Retriever.from_documents(
    documents=raw_documents,
    preprocess_func=custom_tokenizer
)

# BM25 검색기가 반환할 상위 문서 수를 2개로 설정합니다.
bm25_retriever.k = 2

print(f"BM25 검색기 생성 완료 (반환 문서 수: {bm25_retriever.k}개)")
```

</aside>

### 3.2 PostgreSQL + Vector 저장소 구축 및 벡터 검색기 생성

<aside>

PostgreSQL의 벡터 확장 테이블에 문서를 적재하고 벡터 검색기를 생성합니다.

```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings
from langchain_postgres import PGVector

load_dotenv()

connection = os.getenv("DATABASE_URL")

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# PostgreSQL pgvector 테이블에 문서를 벡터로 변환하여 적재합니다.
vectorstore = PGVector.from_documents(
    documents=raw_documents,
    embedding=embeddings,
    connection=connection,
    collection_name="it_regulations_collection",
    use_jsonb=True
)

# 벡터 검색기 인터페이스를 생성하고 반환 문서 수를 2개로 지정합니다.
vector_retriever = vectorstore.as_retriever(
    search_kwargs={"k": 2}
)
```

</aside>

### 3.3 EnsembleRetriever 결합 및 Hybrid 검색 실행

<aside>

두 검색기를 통합하여 키워드와 의미가 복합된 질문을 탐색합니다.

```python
from langchain_classic.retrievers import EnsembleRetriever

# BM25 검색기와 PostgreSQL 벡터 검색기를 5:5 비중으로 결합합니다.
hybrid_retriever = EnsembleRetriever(
    # 결합할 검색기 객체를 리스트로 등록합니다.
    retrievers=[bm25_retriever, vector_retriever],
    # 두 검색기 결과의 반영 비율을 균등하게 설정합니다.
    weights=[0.5, 0.5]
)

# 키워드(VPN)와 뉘앙스(외부 접속)가 섞인 검색 질의를 작성합니다.
query = "외부 장소에서 회사 시스템 연결 시 VPN 보안 수칙"

# Hybrid 검색기를 실행하여 최적의 관련 문서를 추출합니다.
retrieved_docs = hybrid_retriever.invoke(query)

print(f"입력 검색어: {query}\n")
print("[Hybrid 검색 결과]")
for idx, doc in enumerate(retrieved_docs):
    print(f"{idx + 1} 순위: {doc.page_content}")
```

```
입력 검색어: 외부 장소에서 회사 시스템 연결 시 VPN 보안 수칙

[Hybrid 검색 결과]
1 순위: 보안 규정: 업무용 PC는 3개월마다 비밀번호를 변경해야 하며 특수문자를 포함해야 합니다.
2 순위: 원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다.
3 순위: 계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.
```

</aside>

### 3.4 LLM 모델 연동 질의응답 파이프라인 완성

<aside>

통합 추출된 문맥을 프롬프트에 주입하고 LLM 모델로 명확한 근거 답변을 생성합니다.

```python
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate

model = init_chat_model(
    model="gpt-5-mini",
    model_provider="openai",
    temperature=0
)

# 검색된 문맥을 반영할 프롬프트 구조를 설계합니다.
qa_prompt = PromptTemplate.from_template(
    "다음 제공된 [참고 문서]를 바탕으로 [질문]에 대해 간결하고 정확하게 답변하세요.\n\n"
    "[참고 문서]:\n{context}\n\n"
    "[질문]:\n{question}\n\n"
    "[답변]:"
)

# 결합 검색 결과 문서들을 줄바꿈 문자로 연결합니다.
context_text = "\n".join([doc.page_content for doc in retrieved_docs])

# 프롬프트와 LLM 모델을 파이프 연산자로 연결합니다.
qa_chain = qa_prompt | model

# 질의응답 체인을 실행합니다.
response = qa_chain.invoke({
    "context": context_text,
    "question": query
})

print("[최종 답변]")
print(response.content)
```

```
[최종 답변]
외부 장소에서 회사 시스템에 연결할 때의 VPN 보안 수칙(간결 정리)

직접 문서 근거 사항
- VPN 연결 필수: 재택/외부에서 사내 인트라넷 접근 시 반드시 사내 VPN을 연결한다. (원격 근무 가이드)
- 비밀번호 정책 준수: 업무용 PC·계정 비밀번호는 3개월마다 변경하고 특수문자를 포함한다. (보안 규정)
- 반복 로그인 실패 주의: 동일 계정으로 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 한다. 실패 반복을 피할 것. (계정 관리)

추가 권장 수칙
- 회사 지급 기기 사용 및 최신 상태 유지: 개인 기기 사용 시 보안 위험이 크므로 가능하면 회사 기기 사용. 운영체제·보안패치·백신을 최신으로 유지.
- 공용 Wi‑Fi 주의: 공용 무선랜 연결은 피하고 부득이할 경우 모바일 핫스팟이나 신뢰할 수 있는 네트워크만 사용.
- 자격증명 보호: 비밀번호 공유 금지, 화면 잠금(자리 비움 시) 적용, 비밀번호 관리자 사용 권장.
- 사용 후 연결 종료: 작업 종료 시 VPN 연결을 끊고 로그아웃.
- 이상 징후 즉시 보고: 접속 이상·의심스러운 알림 발생 시 즉시 IT 보안팀에 신고.

필요하면 위 수칙을 사내 정책 문서 형식으로 정리해 드리겠습니다.
```

### 4.2 개념 요약 키워드

- **PostgreSQL + Vector (pgvector)**: 관계형 데이터베이스 내에서 고차원 임베딩 벡터의 저장 및 유사도 탐색을 지원하는 확장 모듈
- **EnsembleRetriever**: 키워드 기반 BM25 검색과 PostgreSQL 벡터 검색 결과를 통합해 단일 순위표를 생성하는 랭체인 융합 모듈
- **Hybrid Search**: 단어의 출현 빈도와 문맥의 의미적 유사성을 함께 고려하여 질문 의도에 최적화된 문서를 찾는 검색 전략

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| 하이브리드 검색 | Hybrid Search | 형태적 단어 일치를 찾는 키워드 방식과 의미적 유사도를 찾는 벡터 방식을 융합한 검색 기법입니다. |
| pgvector | PostgreSQL Vector Extension | 오픈소스 데이터베이스인 PostgreSQL에 벡터 유사도 검색 기능을 제공하는 공식 확장 모듈입니다. |
| 앙상블 검색기 | Ensemble Retriever | 독립된 여러 검색 인터페이스의 결과를 전달받아 지정된 가중치에 따라 종합 순위를 매기는 결합 도구입니다. |
| 가중치 | Weights | 결합 검색 단계에서 각 검색기가 최종 문서 순위 결정에 기여하는 상대적 영향력 비율입니다. |
