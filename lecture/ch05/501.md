## 2. 키워드 검색과 BM25 알고리즘

<aside>
💡

<u>**BM25 알고리즘**</u>
문서 안에 특정 단어가 얼마나 자주 나오는지(단어 빈도, TF)와 전체 문서들 사이에서 그 단어가 얼마나 희귀한지(역문서 빈도, IDF)를 종합 계산해 순위를 매기는 대표적인 키워드 검색 알고리즘입니다. 문장의 숨은 뉘앙스나 의미를 추론하기보다는, 사용자가 입력한 고유명사나 전문 용어가 본문에 실제로 존재하는지 여부를 빠르고 정확하게 찾아내는 데 탁월합니다.

</aside>

### 2.1 키워드 검색의 원리와 3대 계산 요소

<aside>

- **단어 빈도 (TF, Term Frequency)**: 검색한 단어가 한 문서 안에 자주 등장할수록 해당 문서의 관련도 점수가 올라갑니다.
- **역문서 빈도 (IDF, Inverse Document Frequency)**: 여러 문서에 너무 흔하게 나오는 일반 단어는 가중치를 낮추고, 희귀한 핵심 단어에 높은 가중치를 부여합니다.
- **문서 길이 정규화**: 문서의 길이가 비정상적으로 길어서 단어가 많이 포함된 경우 점수가 과도하게 높아지지 않도록 문서 전체 길이에 비례해 보정합니다.
</aside>

### 2.2 토크나이저(Tokenizer)의 역할

<aside>

- **토크나이저 정의**: 긴 텍스트 문장을 검색 시스템이 분석할 수 있도록 가장 작은 단위인 토큰(단어) 목록으로 쪼개는 도구입니다.
- **분절 기준**: 띄어쓰기 공백 기준으로 나누거나 한국어 형태소 단위로 분절하여 BM25 알고리즘에 단어 목록을 전달합니다.
</aside>

## 3. 코드로 구현하는 BM25 키워드 검색

### 3.1 토크나이저 정의 및 BM25 검색기(Retriever) 생성

<aside>

텍스트 데이터를 토큰 단위로 나누고 **BM25Retriever**를 생성합니다.

```python
# 랭체인 문서 객체와 BM25 검색 모듈을 불러옵니다.
from langchain_core.documents import Document
from langchain_community.retrievers import BM25Retriever

# 검색 대상이 될 사내 IT 규정 예시 문서를 생성합니다.
raw_documents = [
    Document(page_content="보안 규정: 업무용 PC는 3개월마다 비밀번호를 변경해야 하며 특수문자를 포함해야 합니다."),
    Document(page_content="원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다."),
    Document(page_content="장비 지급 규정: 신규 입사자에게는 노트북 1대와 외장 모니터 1대가 기본 지급됩니다."),
    Document(page_content="계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.")
]

# 문장을 공백 단위로 쪼개는 간단한 토크나이저 함수를 작성합니다.
def custom_tokenizer(text: str) -> list[str]:
    # 전달받은 문장을 공백 기준으로 분리하여 단어 리스트로 반환합니다.
    return text.split()

# 문서 목록과 커스텀 토크나이저를 연결하여 BM25 검색기를 초기화합니다.
bm25_retriever = BM25Retriever.from_documents(
    documents=raw_documents,
    preprocess_func=custom_tokenizer
)

# 검색 결과로 반환받을 최상위 문서 개수(k)를 2개로 지정합니다.
bm25_retriever.k = 2

# 검색기 설정이 정상적으로 완료되었음을 출력합니다.
print(f"BM25 검색기 생성 완료 (반환 문서 수: {bm25_retriever.k}개)")
```

```
BM25 검색기 생성 완료 (반환 문서 수: 2개)
```

</aside>

### 3.2 키워드 검색 실행 및 결과 확인

<aside>

특정 단어가 포함된 질문을 입력하여 정확히 일치하는 문서가 탐색되는지 검증합니다.

```python
# 사용자의 검색 질문을 정의합니다. (정확한 단어 매칭 테스트)
query = "재택 근무 VPN 접속"

# 검색기 객체의 invoke 함수를 호출하여 질의와 가장 관련된 문서를 찾습니다.
retrieved_docs = bm25_retriever.invoke(query)

# 검색 질의를 화면에 출력합니다.
print(f"입력 검색어: {query}\n")

# 검색된 문서들을 순서대로 출력하여 확인합니다.
print("[BM25 검색 결과]")
for idx, doc in enumerate(retrieved_docs):
    # 문서의 순위와 실제 텍스트 내용을 출력합니다.
    print(f"{idx + 1}순위: {doc.page_content}")
```

```
입력 검색어: 재택 근무 VPN 접속

[BM25 검색 결과]
1순위: 원격 근무 가이드: 재택 근무 시 반드시 사내 VPN을 연결하여 사내 인트라넷에 접속해야 합니다.
2순위: 계정 관리: 사내 계정 5회 연속 로그인 실패 시 계정이 잠기며 IT 지원팀에 잠금 해제를 요청해야 합니다.
```

</aside>

### 3.3 BM25 검색 결과와 LLM 모델 연동 질의응답

<aside>

검색된 문맥을 바탕으로 LLM 모델이 근거 중심의 정확한 답변을 생성하도록 파이프라인을 연결합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import PromptTemplate

load_dotenv()

model = init_chat_model(
    model="gpt-5-mini",
    model_provider="openai",
    temperature=0
)

# 검색된 문맥을 주입하기 위한 프롬프트 템플릿을 정의합니다.
qa_prompt = PromptTemplate.from_template(
    "다음 제공된 [참고 문서]를 바탕으로 [질문]에 대해 간결하고 정확하게 답변하세요.\n\n"
    "[참고 문서]:\n{context}\n\n"
    "[질문]:\n{question}\n\n"
    "[답변]:"
)

# BM25로 찾은 문서들을 하나의 문자열 문맥으로 병합합니다.
context_text = "\n".join([doc.page_content for doc in retrieved_docs])

qa_chain = qa_prompt | model

response = qa_chain.invoke({
    "context": context_text,
    "question": query
})

# 최종 도출된 답변 내용을 화면에 출력합니다.
print("[최종 답변]")
print(response.content)
```

```
[최종 답변]
재택 근무 시 사내 인트라넷 접속은 반드시 사내 VPN 연결 후에 해야 합니다. 로그인 시 비밀번호를 연속으로 5회 실패하면 계정이 잠기므로 정확한 자격증명을 사용하고, 잠긴 경우 IT 지원팀에 잠금 해제 요청을 하세요.
```

</aside>

### 4.2 개념 요약 키워드

- **BM25 알고리즘**: 단어의 출현 횟수(TF)와 단어의 희소 가치(IDF)를 계산해 키워드가 정확히 포함된 문서를 찾아내는 대표적인 희소 검색 엔진
- **토크나이저 (Tokenizer)**: 문장을 단어 단위로 쪼개어 검색 시스템이 단어 빈도를 파악할 수 있도록 변환하는 전처리 모듈

### 4.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **BM25** | Best Matching 25 | 단어 빈도와 문서 길이를 종합적으로 고려해 문서의 관련도를 수치화하는 확률 기반 검색 알고리즘입니다. |
| **토크나이저** | Tokenizer | 문장을 단어나 형태소 단위의 작은 토큰으로 쪼개어 주는 텍스트 전처리 도구입니다. |
| **단어 빈도** | Term Frequency (TF) | 특정 단어가 해당 문서 안에서 나타난 횟수를 의미합니다. |
| **역문서 빈도** | Inverse Document Frequency (IDF) | 흔한 단어의 점수는 깎고, 드물게 나타나는 고유 단어에 더 높은 가중치를 주는 수학적 지표입니다. |
| **희소 검색** | Sparse Retrieval | 단어의 형태적 일치 여부와 빈도수만을 계산하여 문서를 찾는 방식입니다. |
