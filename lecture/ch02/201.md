## 2. 문서 로딩(Document Loading)의 원리와 필요성

<aside>
💡

PDF, 웹페이지, 텍스트 등 제각각인 포맷의 외부 파일들을 LangChain의 표준 규격인 Document 객체로 일관되게 변환해 주는 데이터 인입(Ingestion)의 첫 번째 관문입니다.

</aside>

### 2.1 문서 로딩이 필요한 기술적 배경

<aside>

<u>**포맷의 이질성 해소**</u>

<aside>
PDF, 웹페이지, 워드 문서는 저장 구조가 달라 모델이 직접 읽을 수 없습니다.

</aside>

**<u>표준화된 규격 변환</u>**

<aside>
모든 입력 데이터를 **page_content**(본문)와 **metadata**(속성) 구조로 일원화합니다.

</aside>

**<u>파이프라인 연속성 보장</u>**

<aside>
지난 강에서 설계한 메타데이터 기반 필터링 및 청킹 작업을 수행하기 위한 필수 전제 조건입니다.

</aside>

</aside>

### 2.2 LangChain Document 객체와 로더 인터페이스

<aside>

<u>**로더(Loader)**</u>

<aside>
특정 포맷의 문서를 열어 **Document** 리스트 형태로 반환하는 도구입니다.

</aside>

**<u>일관된 메서드</u>**

<aside>
모든 로더는 **.load()** 함수를 호출하여 동일한 방식으로 데이터를 적재합니다.

</aside>

</aside>

## 3. 다양한 포맷 문서 로딩 실습

<aside>
💡

실무에서 가장 널리 사용되는 PDF 및 웹페이지(HTML) 문서를 직접 파이썬 환경으로 불러옵니다.

</aside>

### 3.1 PDF 문서 로딩과 메타데이터 보존 실습

<aside>

<u>**PyMuPDFLoader**</u>

<aside>
PDF 문서의 텍스트 추출 속도가 매우 빠르고 페이지별 메타데이터를 안정적으로 추출합니다.

</aside>

<u>**실습용 파일**</u>

academic_rules_2026.pdf

```python
# langchain_community에서 PyMuPDFLoader 클래스를 불러옵니다.
from langchain_community.document_loaders import PyMuPDFLoader
import os

sample_pdf_path = "academic_rules_2026.pdf"

# 실습용 PDF가 없는 환경을 위해 임베딩 텍스트를 담은 대체 로직을 명시하거나 지정 경로를 연결합니다.
# PDF 경로를 인자로 전달하여 로더 인스턴스를 초기화합니다.
pdf_loader = PyMuPDFLoader(file_path=sample_pdf_path)

# 문서를 페이지 단위로 파싱하여 Document 객체 리스트로 적재합니다.
pdf_documents = pdf_loader.load()

# 로드된 전체 페이지 수를 출력합니다.
print(f"=== [로드 완료] 총 페이지 수: {len(pdf_docs := pdf_documents)}장 ===")

# 1페이지(인덱스 0)의 본문 일부와 메타데이터 속성을 확인합니다.
print(f"본문 내용 미리보기:\n{pdf_documents[0].page_content[:150]}")
print(f"\n자동 보존된 메타데이터:\n{pdf_documents[0].metadata}")
```

```
=== [로드 완료] 총 페이지 수: 2장 ===
본문 내용 미리보기:
[2026학년도 대학 학사 규정]
제1장 총칙 및 기본 요건
제1조(목적)
본 학사규정은 2026학년도 대학 입학생의 졸업 요건 및 학점 이수에 관한 제반
사항을 규정함을 목적으로 합니다.
제2조(전공 이수 학점)
모든 학부생은 졸업을 위해 전공 필수 36학점을 포함하

자동 보존된 메타데이터:
{'producer': '', 'creator': '', 'creationdate': '', 'source': 'academic_rules_2026.pdf', 'file_path': 'academic_rules_2026.pdf', 'total_pages': 2, 'format': 'PDF 1.7', 'title': '', 'author': '', 'subject': '', 'keywords': '', 'moddate': '', 'trapped': '', 'modDate': '', 'creationDate': '', 'page': 0}
```

</aside>

### 3.2 웹페이지(HTML) 문서 로딩 실습

<aside>

<u>**WebBaseLoader**</u>

<aside>
HTML 태그를 자동으로 정제하고 웹페이지의 본문 텍스트만 추출합니다.

</aside>

```python
# langchain_community에서 웹페이지 전용 로더를 불러옵니다.
from langchain_community.document_loaders import WebBaseLoader

# 로딩 대상 웹페이지 URL을 설정합니다.
target_url = "https://www.python.org"

# URL을 지정하여 웹 로더를 초기화합니다.
web_loader = WebBaseLoader(web_path=target_url)

# 웹페이지 소스를 파싱하여 Document 객체 리스트로 적재합니다.
web_documents = web_loader.load()

# 로드된 웹 문서의 메타데이터와 본문 요약본을 출력합니다.
print("=== [웹 문서 로딩 결과] ===")
print(f"문서 제목 및 출처 메타데이터: {web_documents[0].metadata}")
print(f"\n추출된 본문 텍스트 (일부): {web_documents[0].page_content[:120].strip()}")
```

```
=== [웹 문서 로딩 결과] ===
문서 제목 및 출처 메타데이터: {'source': 'https://www.python.org', 'title': 'Welcome to Python.org', 'description': 'The official home of the Python Programming Language', 'language': 'en'}

추출된 본문 텍스트 (일부): Welcome to Python.org
```

## 4. 로딩 문서 기반 LLM 질의응답 실습

<aside>
💡

로딩된 문서 내용과 원본 메타데이터를 LLM 모델에 주입하여 신뢰도 높은 답변을 생성합니다.

</aside>

### 4.1 LLM 모델 연계 질의응답 체인 구현

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.documents import Document

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0  # 답변의 무작위성을 배제하고 사실 기반으로 출력합니다.
)

# 로딩 단계에서 가져온 Document 객체 예시를 정의합니다.
sample_doc = Document(
    page_content="2026학년도 소프트웨어학부 학생은 졸업 전까지 캡스톤 디자인을 필수로 이수해야 합니다.",
    metadata={"source": "2026_학사요람.pdf", "page": 15, "department": "소프트웨어학부"}
)

# 출처 메타데이터를 명시하도록 프롬프트 템플릿을 설계합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "제공된 [참고 문서]에 근거하여 질문에 명확하게 답변하세요.\n"
        "답변 말미에는 반드시 [출처: 파일명 (페이지)] 형식으로 근거를 명시하세요.\n\n"
        "[참고 문서]:\n{context}\n\n"
        "[문서 정보]: 출처={source}, 페이지={page}"
    )),
    ("user", "{question}")
])

# 프롬프트, 모델, 파서를 파이프(|) 연산자로 연결하여 체인을 생성합니다.
rag_chain = prompt | model | StrOutputParser()

# 질문을 정의하고 체인을 실행합니다.
user_question = "소프트웨어학부 졸업 필수 요건이 무엇인가요?"
response = rag_chain.invoke({
    "context": sample_doc.page_content,
    "source": sample_doc.metadata["source"],
    "page": sample_doc.metadata["page"],
    "question": user_question
})

print("=== [모델 생성 답변] ===")
print(response)
```

```
=== [모델 생성 답변] ===
2026학년도 소프트웨어학부의 졸업 필수 요건은 졸업 전까지 캡스톤 디자인을 반드시 이수하는 것입니다.  
[출처: 2026_학사요람.pdf (15)]
```

### 5.2 개념 요약 키워드

- **문서 로더(Document Loader)**: 외부 저장소의 파일을 읽어 통일된 규격의 Document 리스트로 적재하는 도구
- **메타데이터 보존**: 파싱 단계에서 파일 출처, 페이지 정보 등의 부가 속성을 잃어버리지 않고 유지하는 원리
- **LLM 모델 연계**: 적재된 문서 본문과 메타데이터를 프롬프트에 동시 주입하여 환각을 억제하고 출처를 명시하는 체인

### 5.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **문서 로더** | Document Loader | PDF, 웹페이지, 텍스트 파일 등 다양한 포맷의 문서를 LangChain 내부 객체로 읽어 들이는 컴포넌트입니다. |
| **파싱** | Parsing | 비정형 파일 구조에서 불필요한 태그나 코드를 제거하고 유의미한 본문 문자열을 추출해 내는 과정입니다. |
| **PyMuPDF** | PyMuPDF | PDF 문서 파싱 속도가 빠르고 메타데이터 추출 정확도가 높은 오픈소스 파이썬 패키지입니다. |
| **웹 스크래핑** | Web Scraping | 웹 서버에 요청을 보내 HTML 코드를 수신한 뒤, 필요한 텍스트 정보만 선별 추출하는 기술입니다. |
