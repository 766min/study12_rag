## 3. LangChain을 활용한 메타데이터 동시 저장(Upsert) 실습

<aside>
💡

**Document 객체에 본문과 메타데이터를 함께 캡슐화하여 PostgreSQL의 JSONB 컬럼에 적재합니다.**

</aside>

### 3.1 DB 연결 및 PGVector 인스턴스 초기화

<aside>

- PostgreSQL 접속 URL을 바탕으로 벡터 저장소를 초기화합니다.
- `use_jsonb=True` 옵션을 통해 메타데이터를 유연하고 빠른 인덱싱이 가능한 JSONB 형식으로 지정합니다.

```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings
# PostgreSQL pgvector 연동 모듈을 불러옵니다.
from langchain_postgres.vectorstores import PGVector

load_dotenv()

embeddings_model = OpenAIEmbeddings(
    model="text-embedding-3-small"
)

# 환경 변수에서 데이터베이스 접속 문자열을 읽어옵니다.
connection_url = os.getenv("DATABASE_URL")

# PGVector 저장소 객체를 생성하고 연결합니다.
vector_store = PGVector(
    embeddings=embeddings_model,     # 임베딩 모델 인스턴스 지정
    collection_name="university_rules", # 데이터를 보관할 컬렉션 테이블 이름
    connection=connection_url,  # 데이터베이스 접속 URL
    use_jsonb=True # 메타데이터를 PostgreSQL JSONB 형태로 저장
)

print("PostgreSQL + pgvector 연결 및 초기화 완료")
```

```
PostgreSQL + pgvector 연결 및 초기화 완료
```

</aside>

### 3.2 Document 객체 생성 및 일괄 저장(Upsert)

<aside>

- `page_content`에 본문을, `metadata` 딕셔너리에 사전에 설계한 스키마를 할당합니다.
- 고유 `id`를 지정해 데이터의 중복 적재를 방지하고 업데이트를 보장합니다.

```python
# LangChain의 기본 문서 단위인 Document 클래스를 불러옵니다.
from langchain_core.documents import Document

# 설계한 메타데이터 스키마를 적용한 규정 문서 리스트를 생성합니다.
documents_to_insert = [
    # 1번 문서: 2026학년도 도서관 대출 규정
    Document(
        page_content="[도서관 규정] 학부생은 최대 5권까지 14일간 도서 대출이 가능합니다.",
        metadata={
            "source": "library_guide_2026.pdf",
            "category": "library",
            "year": 2026
        }
    ),
    # 2번 문서: 2027학년도 개정 도서관 대출 규정
    Document(
        page_content="[개정 도서관 규정] 학부생은 최대 7권까지 21일간 도서 대출이 가능합니다.",
        metadata={
            "source": "library_guide_2027.pdf",
            "category": "library",
            "year": 2027
        }
    ),
    # 3번 문서: 2027학년도 장학금 규정
    Document(
        page_content="[장학금 규정] 직전 학기 평점 3.5 이상인 학생은 성적 우수 장학금 대상자입니다.",
        metadata={
            "source": "scholarship_2027.pdf",
            "category": "scholarship",
            "year": 2027
        }
    )
]

# 각 문서에 일대일로 매핑될 고유 식별자(ID)를 지정합니다.
document_ids = ["doc_lib_2026", "doc_lib_2027", "doc_sch_2027"]

# Document 객체와 고유 ID를 데이터베이스에 적재(Upsert)합니다.
saved_ids = vector_store.add_documents(
    documents=documents_to_insert,
    ids=document_ids
)

# 저장 완료 결과를 화면에 출력합니다.
print(f"DB에 적재된 문서 총 개수: {len(saved_ids)}개")
print(f"저장된 문서 고유 ID 목록: {saved_ids}")
```

```
DB에 적재된 문서 총 개수: 3개
저장된 문서 고유 ID 목록: ['doc_lib_2026', 'doc_lib_2027', 'doc_sch_2027']
```

</aside>

## 4. 메타데이터 필터 검색 및 LLM 모델 연동 실습

<aside>
💡

메타데이터 필터 조건을 결합해 필요한 데이터만 정확히 선별한 후 LLM 모델로 답변을 도출합니다.

</aside>

### 4.1 메타데이터 필터링 유사도 검색 실행

<aside>

`filter` 인자에 딕셔너리 형태로 조건을 전달하여 일치하는 메타데이터를 가진 청크만 탐색합니다.

```python
# 사용자 질문을 정의합니다.

# 2027년도 규정만 탐색하도록 메타데이터 필터 조건을 설정합니다.
metadata_filter = {
    "year": 2027,
    "category": "library"
}

# 필터 조건과 함께 벡터 유사도 검색을 실행합니다.
filtered_search_results = vector_store.similarity_search(
    query=user_question,
    k=1,    # 가장 연관성이 높은 문서 1건 추출
    filter=metadata_filter  # 메타데이터 조건식 적용
)

# 검색된 최적 문서의 본문과 메타데이터를 추출합니다.
retrieved_document = filtered_search_results[0]
retrieved_context = retrieved_document.page_content
retrieved_metadata = retrieved_document.metadata

# 검색 결과를 출력하여 필터가 올바르게 작동했는지 확인합니다.
print("=== [메타데이터 필터링 검색 결과] ===")
print(f"검색 본문: {retrieved_context}")
print(f"문서 메타데이터: {retrieved_metadata}")
```

```
=== [메타데이터 필터링 검색 결과] ===
검색 본문: [개정 도서관 규정] 학부생은 최대 7권까지 21일간 도서 대출이 가능합니다.
문서 메타데이터: {'year': 2027, 'source': 'library_guide_2027.pdf', 'category': 'library'}
```

</aside>

### 4.2 LLM 모델 연결 및 최종 체인 실행

<aside>

```python
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

# 문맥을 주입할 프롬프트 템플릿을 정의합니다.
qa_prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "당신은 대학 학사 규정 안내 챗봇입니다.\n"
        "제공된 [참고 문서]의 내용에만 근거하여 명확하게 답변하세요.\n"
        "내용에 없는 사실은 지어내지 마세요.\n\n"
        "[참고 문서]:\n{context}"
    )),
    ("user", "{question}")
])

# RAG 파이프라인 체인을 연결합니다.
rag_chain = qa_prompt | model | StrOutputParser()

# 검색된 본문과 사용자 질문을 주입하여 답변을 생성합니다.
final_response = rag_chain.invoke({
    "context": retrieved_context,
    "question": user_question
})

# 생성된 최종 답변을 출력합니다.
print("=== [최종 답변] ===")
print(final_response)
```

```
=== [최종 답변] ===
학부생은 최대 7권까지 빌릴 수 있습니다. 대출 기간은 21일입니다.
```

| **메타데이터** | Metadata | 데이터의 성격을 설명하는 부가 정보로, 문서의 작성일, 출처, 분류 등이 해당합니다. |
| **스키마** | Schema | 데이터베이스나 애플리케이션에서 다룰 정보의 필드명, 자료형, 구조를 규정한 명세서입니다. |
| **도큐먼트 객체** | Document Object | LangChain에서 텍스트 본문과 메타데이터를 하나로 포장해 전달하는 표준 데이터 단위입니다. |
| **JSONB** | JSONB | PostgreSQL에서 JSON 데이터를 바이너리 형태로 변환하여 빠른 탐색과 인덱싱을 지원하는 데이터 타입입니다. |
