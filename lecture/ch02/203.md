## 2. 청킹 품질과 파라미터의 상관관계

<aside>
💡

청크 크기(chunk_size)와 겹침(chunk_overlap)은 인공지능의 답변 품질을 결정하는 양날의 검입니다.

</aside>

### 2.1 청크 크기별 트레이드오프 (Trade-off)

<aside>

- **작은 청크 크기**: 세부 정보를 찾는 정밀도는 높지만, 문맥이 끊겨 주어나 배경 상황을 인공지능이 왜곡하기 쉽습니다.
- **큰 청크 크기**: 풍부한 문맥을 전달할 수 있지만, 핵심 질문과 무관한 노이즈가 유입되어 처리 비용이 늘고 답변 초점이 흐려집니다.

| **설정 구분** | 장점 | 단점 | 적합한 문서 유형 |
| --- | --- | --- | --- |
| 소형 청크 (50~100자) | 단답형 사실 검색에 유리 | 앞뒤 인과관계 유실 | FAQ, 사전, 단순 단어 규정집 |
| 중형 청크 (200~500자) | 문맥과 검색 정밀도의 균형 | 특수한 구조 분석 시 조정 필요 | 일반 학사 규정, 업무 매뉴얼 |
| 대형 청크 (800자 이상) | 문맥 보존 및 서사 이해 우수 | 무관한 내용 혼입, 토큰 소모 증가 | 계약서 전문, 법률 조항, 학술 논문 |
</aside>

## 3. 청크 크기별 분할 비교 실습

<aside>
💡

동일한 원본 텍스트를 서로 다른 크기로 분할하고 조각들의 형태를 직접 비교합니다.

</aside>

### 3.1 소형 청크 vs 대형 청크 분할

<aside>

**RecursiveCharacterTextSplitter**를 사용하여 소형 크기(60자)와 중대형 크기(180자)로 각각 분할합니다. 

```python
# 분할을 위해 랭체인의 재귀적 텍스트 분할기를 불러옵니다.
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 실험에 사용할 대학 도서관 이용 규정 텍스트를 선언합니다.
library_rules = (
    "[2026학년도 중앙도서관 대출 및 열람 규정]\n"
    "제1조(대출 자격) 본교 재학생 및 휴학생은 학생증을 제시한 후 도서를 대출할 수 있습니다.\n"
    "제2조(대출 권수 및 기간) 학부생은 1인당 최대 5권까지 대출할 수 있으며 대출 기간은 14일입니다.\n"
    "단, 학술 연구용 특수 도서는 7일간 대출 가능하며 연장은 불가능합니다.\n"
    "제3조(연체 및 제재) 반납 기한을 초과할 경우 연체 일수만큼 대출이 정지됩니다."
)

# 소형 분할기 설정 (크기: 60자, 겹침: 15자)
small_splitter = RecursiveCharacterTextSplitter(
    chunk_size=60,         # 각 청크의 최대 길이를 60자로 작게 제한합니다.
    chunk_overlap=15,      # 문맥 유지를 위해 15자를 중복 배치합니다.
    length_function=len    # 글자 수 측정 함수로 파이썬 내장 len을 사용합니다.
)

# 대형 분할기 설정 (크기: 380자, 겹침: 30자)
large_splitter = RecursiveCharacterTextSplitter(
    chunk_size=380,        # 각 청크의 최대 길이를 380자로 여유 있게 설정합니다.
    chunk_overlap=30,      # 크기에 비례하여 중복 구간을 30자로 지정합니다.
    length_function=len
)

# 동일한 문서를 서로 다른 기준으로 분할합니다.
small_chunks = small_splitter.split_text(library_rules)
large_chunks = large_splitter.split_text(library_rules)

# 분할된 청크 개수를 출력합니다.
print(f"소형 청크 분할 결과: 총 {len(small_chunks)}개 조각")
print(f"대형 청크 분할 결과: 총 {len(large_chunks)}개 조각\n")

print("--- [소형 청크 1번 조각] ---")
print(small_chunks[0])

print("\n--- [대형 청크 1번 조각] ---")
print(large_chunks[0])
```

```
소형 청크 분할 결과: 총 5개 조각
대형 청크 분할 결과: 총 1개 조각

--- [소형 청크 1번 조각] ---
[2026학년도 중앙도서관 대출 및 열람 규정]

--- [대형 청크 1번 조각] ---
[2026학년도 중앙도서관 대출 및 열람 규정]
제1조(대출 자격) 본교 재학생 및 휴학생은 학생증을 제시한 후 도서를 대출할 수 있습니다.
제2조(대출 권수 및 기간) 학부생은 1인당 최대 5권까지 대출할 수 있으며 대출 기간은 14일입니다.
단, 학술 연구용 특수 도서는 7일간 대출 가능하며 연장은 불가능합니다.
제3조(연체 및 제재) 반납 기한을 초과할 경우 연체 일수만큼 대출이 정지됩니다.
```

## 4. LLM 기반 답변 품질 비교 실습

<aside>
💡

서로 다른 크기의 청크를 LLM 모델에 주입하여 실제 답변 정확도를 검증합니다.

</aside>

### 4.1 모델 연결 및 프롬프트 체인 구성

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

# 검색된 조각을 전달받아 답변을 생성하는 프롬프트 서식을 정의합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "당신은 대학 도서관 규정 안내원입니다.\n"
        "제공된 [참고 청크]의 내용에만 엄격히 근거하여 질문에 답변하세요.\n"
        "내용에 언급되지 않은 사실은 절대 지어내지 마세요.\n\n"
        "[참고 청크]:\n{context}"
    )),
    ("user", "{question}")
])

# 프롬프트, 언어 모델, 파서를 연결하여 QA 체인을 구성합니다.
qa_chain = prompt | model | StrOutputParser()
```

</aside>

### 4.2 청크 크기별 답변 생성 실험

<aside>

"특수 도서를 대출한 경우 며칠 동안 빌릴 수 있고 연장이 가능한가요?"라는 질문으로 두 조각의 답변 능력을 비교합니다.

```python
# 검증 질문 정의
question = "특수 도서를 대출한 경우 며칠 동안 빌릴 수 있고 연장이 가능한가요?"

# 소형 청크 중 관련 단어가 포함된 조각(제2조 후반부만 담겨 자격 조건 누락 가능)
small_context = small_chunks[2]

# 대형 청크 중 전체 맥락이 담긴 조각
large_context = large_chunks[0]

# 1. 소형 청크 기반 답변 도출
small_response = qa_chain.invoke({
    "context": small_context,
    "question": question
})

# 2. 대형 청크 기반 답변 도출
large_response = qa_chain.invoke({
    "context": large_context,
    "question": question
})

print("=== [소형 청크 기반 모델 답변] ===")
print(small_response)
print("\n=== [대형 청크 기반 모델 답변] ===")
print(large_response)
```

```
=== [소형 청크 기반 모델 답변] ===
제공된 규정에 따르면 제2조는 "학부생은 1인당 최대 5권까지 대출할 수 있으며 대출 기간은 14일입니다."라고만 명시되어 있습니다.  
특수 도서에 대한 별도 대출 기간이나 연장 가능 여부는 해당 내용에 언급되어 있지 않으므로 여기서 답변할 수 없습니다. 정확한 사항은 도서관 전체 규정이나 도서관에 문의해 확인해 주세요.

=== [대형 청크 기반 모델 답변] ===
학술 연구용 특수 도서는 7일간 대출 가능하며 연장은 불가능합니다.
```

## 5. 의미론적 분할 (Semantic Chunking) 적용 실습

<aside>
💡

**글자 수 기준의 기계적 분할 대신 문맥이 완결되는 문단, 문장 단위를 우선하여 자릅니다.**

</aside>

### 5.1 구분자(Separators) 우선순위 기반 분할

<aside>

**separators** 파라미터로 줄바꿈(`\n\n`), 문장 마침표(`.` ), 쉼표(`,` ) 순서의 계층적 분할 규칙을 설정합니다.

```python
# 의미 단위 분할을 위한 분할기를 생성합니다.
semantic_splitter = RecursiveCharacterTextSplitter(
    chunk_size=120,
    chunk_overlap=20,
    # 문단 바꿈 -> 줄바꿈 -> 마침표 공백 -> 띄어쓰기 순으로 구분자를 탐색합니다.
    separators=["\n\n", "\n", ".", " "],
    is_separator_regex=False
)

# 의미론적 분할 실행
semantic_chunks = semantic_splitter.split_text(library_rules)

# 결과 확인
print(f"=== [의미론적 분할 완료: 총 {len(semantic_chunks)}개 조각] ===")
for idx, chunk in enumerate(semantic_chunks):
    print(f"\n[청크 {idx + 1}] (글자수: {len(chunk)}자)")
    print(chunk)
```

### 6.2 개념 요약 키워드

- **청킹 품질 실험**: 문서의 성격에 맞춰 chunk_size와 chunk_overlap을 비교 조정해 답변 품질의 최적점을 찾는 작업.
- **문맥 단절(Context Loss)**: 텍스트가 부자연스러운 위치에서 잘려 전후 인과관계가 소실되는 현상.
- **의미론적 분할**: 문단, 마침표 등 글의 구조적 의미 단위를 보존하며 텍스트를 나누는 전략.

### 3.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| 청크 크기 | Chunk Size | 하나의 텍스트 조각이 가질 수 있는 최대 글자 수 또는 토큰 단위입니다. |
| 청크 겹침 | Chunk Overlap | 인접한 두 청크 사이에 중복으로 포함시켜 문맥 단절을 방지하는 구간입니다. |
| 구분자 | Separator | 텍스트 분할 시 우선적으로 절단 기준으로 삼는 기호(줄바꿈, 마침표 등)입니다. |
| 온도 | Temperature | 언어 모델의 출력 무작위성을 제어하는 설정값으로, 0에 가까울수록 사실적이고 일관된 결과를 냅니다. |
