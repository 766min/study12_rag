## 2. 텍스트 청킹(Text Chunking)의 원리와 필요성

<aside>
💡

<u>**텍스트 청킹(Chunking)이란?**</u>
로딩된 긴 문서를 검색과 언어 모델 처리에 가장 적합한 단위인 '텍스트 조각(Chunk)'으로 분할하는 작업입니다.

</aside>

### 2.1 청킹이 필요한 기술적 배경

<aside>

<u>**입력 용량 한계 극복**</u>

<aside>
언어 모델이 한 번에 읽을 수 있는 토큰(글자) 수의 한계를 넘지 않도록 문서를 적절한 크기로 재단합니다.

</aside>

**<u>검색 집중도 향상</u>**

<aside>
전체 문서를 한 번에 검색하는 것보다 특정 주제가 담긴 조각 단위로 검색할 때 연관성이 훨씬 높아집니다.

</aside>

**<u>인덱싱 연속성 확보</u>**

<aside>
지난 강에서 적재한 `Document`를 향후 임베딩 모델에 전달하기 위한 필수 선행 단계입니다.

</aside>

</aside>

### 2.2 LangChain Text Splitter의 동작 원리

<aside>

- **split_text()**: 순수 문자열(String)을 입력받아 지정된 기준에 맞춰 분할된 문자열 리스트를 생성합니다.
- **split_documents()**: Document 객체 리스트를 입력받아 분할하며, 원본에 부여된 metadata를 모든 분할 조각에 자동 복제합니다.
</aside>

## 3. 핵심 파라미터 설계와 시각화

<aside>
💡

<u>**청크 크기(Size)와 청크 겹침(Overlap)**</u>
텍스트를 어떤 크기로 나눌 것인지, 분할 지점 사이의 문맥을 얼마나 보존할 것인지 결정하는 두 가지 핵심 설정값입니다.

</aside>

### 3.1 청크 파라미터 기준 설정

<aside>

- **chunk_size**: 하나의 청크가 가질 수 있는 최대 문자(또는 토큰) 수입니다.
- **chunk_overlap**: 연속된 두 청크 사이에 중복으로 포함될 문자 수입니다.
- **문맥 보존의 목적**: 문장이 중간에 잘려 주어와 목적어가 단절되는 현상을 방지하기 위해 앞 청크의 끝부분을 뒤 청크의 앞부분에 중복 배치합니다.
</aside>

## 4. 텍스트 청킹 및 질의응답 실습

<aside>
💡

<u>**청킹부터 모델 답변 생성까지의 연계**</u>
잘라낸 청크 조각과 원본 메타데이터를 LLM 모델에 전달하여 출처 기반의 답변을 완성합니다.

</aside>

### 4.1 RecursiveCharacterTextSplitter 기본 분할 실습

<aside>

긴 학사 규정 텍스트를 대상으로 재귀적 문자 분할기를 초기화하고 실행합니다.

```python
# langchain_text_splitters 패키지에서 재귀적 텍스트 분할기를 가져옵니다.
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 분할 실습을 위한 2026학년도 학사 규정 예시 텍스트를 선언합니다.
sample_text = (
    "[2026학년도 대학 학사 규정]\n\n"
    "제1조(목적)\n본 학사규정은 2026학년도 대학 입학생의 이수 요건을 규정합니다.\n\n"
    "제2조(전공 이수 학점)\n모든 학부생은 졸업을 위해 전공 필수 36학점을 이수해야 합니다.\n"
    "심화 전공을 선택한 학생은 전공 선택 24학점을 추가로 이수해야 졸업 요건을 충족합니다.\n\n"
    "제3조(졸업 요건)\n학부생은 졸업 전까지 캡스톤 디자인 프로젝트를 반드시 이수하고 통과해야 합니다."
)

# 청크 크기 80자, 겹침 20자로 분할기 규칙을 설정합니다.
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=80,  # 각 청크의 최대 길이를 80자로 제한합니다.
    chunk_overlap=20,   # 문맥 단절을 방지하기 위해 앞뒤 20자를 겹치도록 설정합니다.
    length_function=len,    # 글자 수를 측정하는 함수로 파이썬 내장 len을 지정합니다.
    is_separator_regex=False    # 구분자를 정규표현식이 아닌 일반 문자열로 처리합니다.
)

# 텍스트를 청크 단위 리스트로 분할합니다.
chunks = text_splitter.split_text(sample_text)

# 분할된 전체 조각 수를 확인합니다.
print(f"=== [분할 완료] 총 청크 수: {len(chunks)}개 ===\n")

# 각 조각의 내용과 길이를 순서대로 출력합니다.
for index, chunk in enumerate(chunks):
    print(f"[청크 {index + 1}] (글자 수: {len(chunk)}자)")
    print(chunk)
    print("-" * 40)
```

```

[청크 1] (글자 수: 65자)
[2026학년도 대학 학사 규정]

본 학사규정은 2026학년도 대학 입학생의 이수 요건을 규정합니다.
----------------------------------------
```

### 4.2 Document 객체 분할과 메타데이터 전파 실습

<aside>

```python
# LangChain의 기본 Document 객체를 불러옵니다.
from langchain_core.documents import Document

source_document = Document(
    page_content=(
        "제15조(장학금 지급 기준)\n"
        "직전 학기 평점 평균이 3.5 이상인 학생 중 학과장의 추천을 받은 자에게 성적 우수 장학금을 지급합니다.\n"
        "단, 징계 처분을 받은 사실이 있는 학생은 선발 대상에서 제외됩니다.\n\n"
        "제16조(신청 절차)\n"
        "장학금 신청서와 관련 증빙 서류는 매 학기 개강 2주 전까지 학사지원팀에 제출해야 합니다."
    ),
    metadata={
        "source": "academic_rules_2026.pdf",
        "department": "학사지원팀",
        "page": 4
    }
)

# Document 리스트를 전달하여 청크 Document 리스트로 분할합니다.
split_documents = text_splitter.split_documents([source_document])

# 분할된 총 Document 조각 수를 출력합니다.
print(f"=== [Document 분할 완료] 생성된 청크 수: {len(split_documents)}개 ===\n")

# 첫 번째 청크 Document의 본문과 전파된 메타데이터를 확인합니다.
print("[청크 Document 1 본문]")
print(split_documents[0].page_content)
print("\n[청크 Document 1 메타데이터]")
print(split_documents[0].metadata)
```

### 4.3 분할 청크 기반 질의응답 실습

<aside>

분할된 청크 중 관련 내용이 담긴 조각을 선별하여 LLM 모델에 주입하고 출처가 포함된 답변을 도출합니다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0  # 일관되고 사실적인 출력을 위해 온도를 0으로 고정합니다.
)

# 청크 본문과 메타데이터를 모델에 전달할 프롬프트 양식을 구성합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "당신은 대학 학사 규정 안내 어시스턴트입니다.\n"
        "제공된 [참고 청크]의 내용에만 근거하여 명확하게 답변하세요.\n"
        "답변 말미에는 반드시 [출처: 파일명 (페이지쪽)] 형식으로 근거를 명시하세요.\n\n"
        "[참고 청크]:\n{context}\n\n"
        "[문서 속성]: 파일={source}, 페이지={page}"
    )),
    ("user", "{question}")
])

# 프롬프트, 언어 모델, 출력 파서를 파이프라인(|)으로 연결합니다.
qa_chain = prompt | model | StrOutputParser()

# 분할된 청크 중 장학금 기준이 담긴 첫 번째 조각을 문맥으로 지정합니다.
selected_chunk = split_documents[0]
user_question = "성적 우수 장학금을 받기 위한 직전 학기 평점 요건은 어떻게 되나요?"

# 체인을 실행하고 질의 결과를 도출합니다.
response = qa_chain.invoke({
    "context": selected_chunk.page_content,
    "source": selected_chunk.metadata["source"],
    "page": selected_chunk.metadata["page"],
    "question": user_question
})

print("=== [모델 생성 답변] ===")
print(response)
```

```
=== [모델 생성 답변] ===
직전 학기 평점 평균이 3.5 이상이어야 합니다. (단, 학과장의 추천을 받은 자에게 지급됩니다.)  
[출처: academic_rules_2026.pdf (4쪽)]
```

### 5.2 개념 요약 키워드

- **텍스트 청킹(Text Chunking)**: 입력 한계를 준수하고 검색 정밀도를 높이기 위해 문서를 작은 단위로 나누는 전처리 기법
- **청크 크기 및 겹침(Size & Overlap)**: 조각의 최대 용량과 문맥 보존을 위한 중복 글자 수를 결정하는 핵심 파라미터
- **메타데이터 전파**: 분할된 개별 청크에 원본 문서의 출처 및 페이지 정보를 온전히 복제하여 신뢰성을 확보하는 원리

### 5.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| 청크 | Chunk | 전체 문서에서 일정한 규칙과 기준 크기에 따라 잘라낸 텍스트 조각 단위입니다. |
| 텍스트 분할기 | Text Splitter | 지정된 길이와 구분자 순서에 따라 긴 텍스트를 자동으로 분할하는 모듈입니다. |
| 청크 크기 | Chunk Size | 하나의 청크 조각이 담을 수 있는 최대 글자(문자) 수입니다. |
| 청크 겹침 | Chunk Overlap | 인접한 두 청크 조각이 공유하도록 설정하여 문맥의 연속성을 유지하는 글자 수입니다. |
| 메타데이터 전파 | Metadata Propagation | 원본 문서가 가지고 있던 출처와 쪽수 속성이 쪼개진 모든 청크에 누락 없이 복제되는 과정입니다. |
