## 2. 임베딩(Embedding)과 벡터(Vector) 표현의 원리

<aside>
💡

<u>**임베딩은 단어나 문장이 지닌 의미를 다차원 공간의 좌표(숫자 배열)로 변환하는 기술입니다**</u>. 이는 RAG 시스템에서 컴퓨터가 텍스트 간의 의미적 유사도를 계산하고 적합한 문서를 찾아낼 수 있도록 돕는 핵심 수학적 기반입니다.

</aside>

### 2.1 텍스트의 수치화와 의미 공간(Semantic Space)

<aside>

- **자연어 처리의 한계**: 컴퓨터는 문자 자체를 계산할 수 없으므로 모든 글자를 숫자로 변환해야 합니다.
- **의미 공간의 배치**: 의미가 유사한 문장은 다차원 공간에서 서로 가까운 좌표에 위치합니다.
- **의미적 연산**: 단어와 문장 간의 관계를 거리와 각도로 측정할 수 있게 됩니다.

!image.png

</aside>

### 2.2 차원(Dimension)의 역할과 구조

<aside>

- **차원의 정의**: 문장의 의미를 세부적으로 측정하고 분류하는 기준 축의 총개수입니다.
- **다차원 벡터**: OpenAI의 최신 기본 임베딩 모델은 문장 1개를 1,536개의 실수(Float) 배열로 변환합니다.

| **구분** | **1차원 수직선** | **2차원 평면** | **고차원 의미 공간 (1,536차원)** |
| --- | --- | --- | --- |
| **표현 형태** | 단일 숫자 ($x$) | 좌표 쌍 ($x, y$) | 1,536개의 실수 배열 ($[v_1, v_2, \dots, v_{1536}]$) |
| **표현력** | 크기 비교만 가능 | 평면 상의 거리 측정 | 문맥, 어조, 전문 용어 등 복합 의미 반영 |
</aside>

## 3. 문장 임베딩 생성 실습

### 3.1 OpenAI 임베딩 모델 호출 및 벡터 추출

<aside>

- **embed_query 메서드**: 단일 문자열을 입력받아 부동소수점 리스트를 반환합니다.
- 아래 코드를 실행하여 텍스트가 어떤 형태의 데이터로 변환되는지 확인합니다.

```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings

load_dotenv()

embeddings_model = OpenAIEmbeddings(model="text-embedding-3-small")

# 임베딩할 예시 문장을 정의합니다.
sample_text = "인공지능 모델이 문장의 의미를 이해하기 위해 숫자로 변환합니다."

# 텍스트를 고차원 숫자 배열(벡터)로 변환합니다.
vector_data = embeddings_model.embed_query(sample_text)

# 생성된 벡터의 전체 길이(차원 수)를 출력합니다.
print(f"생성된 벡터의 차원 수: {len(vector_data)}")

# 벡터 내부의 실수 값 중 앞부분 5개 항목을 확인합니다.
print(f"변환된 벡터 앞부분 5개: {vector_data[:5]}")

```

```

변환된 벡터 앞부분 5개: [-0.00907135009765625, 0.046600341796875, -0.006256103515625, 0.0103607177734375, 0.0028438568115234375]
```

## 4. 벡터 유사도 계산과 LLM 모델 답변 생성

<aside>
💡

<u>**벡터 간의 거리를 계산해 질문과 가장 관련성이 높은 문서를 찾아낸 뒤, 이를 LLM에 문맥(Context)으로 전달하여 최종 답변을 생성합니다.**</u> 이를 통해 사전에 인덱싱된 벡터 데이터가 실시간 질의 과정에서 실제로 어떻게 활용되는지 전체 흐름을 확인하고 검증합니다.

</aside>

### 4.1 코사인 유사도(Cosine Similarity)를 이용한 문맥 검색

<aside>

- **유사도 원리**: 두 벡터가 가리키는 방향이 일치할수록 1에 가까워지고, 방향이 다를수록 0 또는 음수에 가까워집니다.
- **문서 청크 비교**: 저장된 여러 문서 중 사용자의 질문과 코사인 유사도가 가장 높은 문서를 추출합니다.

```python
import numpy as np

# 문서 데이터베이스에 보관된 3개의 문서 청크를 정의합니다.
corpus_documents = [
    "장학금 수혜 대상은 직전 학기 평점 3.5 이상이며 F학점이 없는 학생입니다.",
    "도서관 이용 시간은 평일 오전 9시부터 오후 10시까지 운영됩니다.",
    "수강신청 변경 기간에는 최대 3학점까지 추가로 정정할 수 있습니다."
]

# 사용자의 실시간 질문을 정의합니다.
user_question = "성적 장학금을 받으려면 평점이 어떻게 되나요?"

# 질문과 문서들을 각각 임베딩 벡터로 변환합니다.
query_vector = embeddings_model.embed_query(user_question)
doc_vectors = embeddings_model.embed_documents(corpus_documents)

# 코사인 유사도를 계산하는 수학적 함수를 정의합니다.
def cosine_similarity(v1, v2):
    # 두 벡터의 내적을 각 벡터의 크기(L2 Norm)의 곱으로 나눕니다.
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

# 질문 벡터와 각 문서 벡터 간의 유사도 점수를 계산합니다.
similarity_scores = [cosine_similarity(query_vector, doc_vec) for doc_vec in doc_vectors]

# 각 문서별 유사도 점수를 출력합니다.
for idx, score in enumerate(similarity_scores):
    print(f"문서 {idx + 1} 유사도: {score:.4f} | 내용: {corpus_documents[idx]}")

# 가장 높은 유사도 점수를 가진 문서를 최적의 문맥(Context)로 선정합니다.
best_doc_index = int(np.argmax(similarity_scores))
selected_context = corpus_documents[best_doc_index]
print(f"\n최종 검색된 최적 문맥: {selected_context}")
```

```
문서 1 유사도: 0.4146 | 내용: 장학금 수혜 대상은 직전 학기 평점 3.5 이상이며 F학점이 없는 학생입니다.
문서 2 유사도: 0.0797 | 내용: 도서관 이용 시간은 평일 오전 9시부터 오후 10시까지 운영됩니다.
문서 3 유사도: 0.2372 | 내용: 수강신청 변경 기간에는 최대 3학점까지 추가로 정정할 수 있습니다.

최종 검색된 최적 문맥: 장학금 수혜 대상은 직전 학기 평점 3.5 이상이며 F학점이 없는 학생입니다.
```

</aside>

### 4.2 LLM 모델을 통한 답변 생성 연계

<aside>

- **언어 모델 초기화**: 사실 기반 응답 생성을 위해 LLM 모델의 temperature를 0으로 설정합니다.
- **체인 조립**: LangChain의 파이프라인 연산자(`|`)를 사용해 프롬프트, 모델, 파서를 연결합니다.

```python
# 채팅 모델 초기화 함수와 프롬프트 템플릿, 출력 파서를 불러옵니다.
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

# 검색된 문맥({context})과 사용자 질문({question})을 주입하는 프롬프트를 구성합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", "제공된 [참고 문서]의 내용에만 근거하여 정확하게 답변하세요.\n\n[참고 문서]:\n{context}"),
    ("user", "{question}")
])

# 프롬프트 -> 모델 -> 출력 파서로 이어지는 체인을 구성합니다.
rag_chain = prompt | model | StrOutputParser()

# 검색된 최적 문맥과 사용자의 질문을 전달하여 실행합니다.
response = rag_chain.invoke({
    "context": selected_context,
    "question": user_question
})

print("=== [생성 답변] ===")
print(response)
```

```
=== [생성 답변] ===
직전 학기 평점이 3.5 이상(3.5 포함)이어야 하고, 그 학기에 F학점이 없어야 합니다.
```

</aside>

## 5. 임베딩 모델 종류와 선택 기준

<aside>
💡

<u>**임베딩 모델의 벡터 차원 수와 연산 속도는 검색의 정확도뿐만 아니라 벡터 DB 용량과 운영 비용에 직접적인 영향을 미칩니다.**</u> 만약 임베딩 단계에서 텍스트의 의미가 왜곡되거나 손실되면 엉뚱한 문서가 검색되어, 파이프라인 전체의 답변 품질을 떨어뜨리는 치명적인 병목 지점이 됩니다.

</aside>

### 5.1 주요 임베딩 모델 규격 비교

<aside>

차원 수가 클수록 의미 표현력이 정교해지지만, 저장 공간과 연산량이 증가합니다.

| 모델명 | 제공사 | 출력 차원 수 | 최대 입력 토큰 | 주요 권장 용도 |
| --- | --- | --- | --- | --- |
| text-embedding-3-small | OpenAI | 1,536차원 | 8,191 토큰 | 범용 검색, 비용 효율적 시스템 구축 |
| text-embedding-3-large | OpenAI | 3,072차원 | 8,191 토큰 | 고정밀 법률·의료 전문 문서 검색 |
| bge-m3 | BAAI (오픈소스) | 1,024차원 | 8,192 토큰 | 로컬 보안 환경 및 다국어 지원 시스템 |
</aside>

### 6.2 개념 요약 키워드

- **임베딩(Embedding)**: 텍스트의 의미를 고차원 공간 상의 숫자 배열(벡터)로 변환하는 핵심 전처리 작업
- **차원(Dimension)**: 문장의 복합적인 의미를 수치화하기 위해 모델이 사용하는 기준 축의 총개수
- **코사인 유사도(Cosine Similarity)**: 벡터 사이의 각도를 측정하여 문장의 의미적 유사성을 판별하는 척도

### 6.3 용어 사전

| 용어 | 영어 표현 | 설명 |
| --- | --- | --- |
| **임베딩** | Embedding | 컴퓨터가 문장의 의미를 이해할 수 있도록 텍스트를 고차원 숫자 배열(벡터)로 변환하는 기술입니다. |
| **벡터** | Vector | 크기와 방향을 갖는 숫자의 나열로, 의미 공간 상의 특정 위치 좌표를 나타냅니다. |
| **차원** | Dimension | 데이터의 특징을 표현하는 기준 축의 개수이며, 모델에 따라 1,536차원 또는 3,072차원 등이 사용됩니다. |
| **코사인 유사도** | Cosine Similarity | 두 벡터 간 사잇각을 통해 방향의 일치 정도를 측정하는 의미 유사도 계산 지표입니다. |
