## 2. 메타데이터(Metadata)의 원리와 필요성

<aside>
💡

<u>**메타데이터는 데이터 조각에 부착하는 '규격화된 신분증'입니다.**</u>
본문 텍스트 외에 문서의 출처, 생성 일자, 작성자, 카테고리 등을 기록하여 데이터의 맥락을 온전히 보존합니다.

</aside>

### 2.1 메타데이터가 필요한 기술적 배경

<aside>

- **시간적 유효성 구분**: 동일한 규정이라도 구버전과 최신 개정안을 날짜 필드로 명확히 분리합니다.
- **문서 출처 추적성**: 모델이 답변을 생성했을 때 원본 문서의 위치와 근거 페이지를 입증합니다.
- **검색 연산 비용 절감**: 전체 조각을 벡터 비교하지 않고 조건에 맞는 데이터만 선별하여 처리 속도를 높입니다.
</aside>

### 2.2 LangChain Document 객체 구조

<aside>

- **page_content**: 청킹된 순수 텍스트 본문이 저장되는 문자열 필드입니다.
- **metadata**: 출처 및 부가 정보를 키-값(Key-Value) 형태의 딕셔너리로 관리하는 속성입니다.

```python
# langchain_core.documents 모듈에서 Document 클래스를 불러옵니다.
from langchain_core.documents import Document

# page_content와 metadata를 정의하여 단일 Document 객체를 생성합니다.
sample_doc = Document(
    page_content="직전 학기 평점 3.5 이상인 학생에게 성적 우수 장학금을 지급합니다.", # 본문 텍스트
    metadata={
        "source": "2026_학사규정.pdf", # 원본 파일명
        "page": 12,     # 원본 페이지 번호
        "category": "장학", # 업무 분류 카테고리
        "year": 2026       # 작성 연도
    }
)

# 생성된 객체의 본문과 메타데이터 속성을 확인합니다.
print("=== [본문 데이터] ===")
print(sample_doc.page_content)
print("\n=== [부착된 메타데이터] ===")
print(sample_doc.metadata)
```

```
=== [본문 데이터] ===
직전 학기 평점 3.5 이상인 학생에게 성적 우수 장학금을 지급합니다.

=== [부착된 메타데이터] ===
{'source': '2026_학사규정.pdf', 'page': 12, 'category': '장학', 'year': 2026}
```

</aside>

## 3. 메타데이터 스키마 설계 및 분할 연계

<aside>
💡

<u>**검색 목적에 맞는 메타데이터 스키마 설계가 RAG 품질의 출발점입니다.**</u>
식별, 시간, 구조 정보를 균형 있게 정의해야 체계적인 필터링과 원본 역추적이 가능합니다.

</aside>

### 3.1 메타데이터 3대 분류 체계

<aside>

| **분류** | **주요 속성 예시** | **역할 및 검색 시 이점** |
| --- | --- | --- |
| **식별 정보 (Identity)** | `source`, `doc_id`, `author` | 문서의 출처를 명시하고 답변의 인용 근거를 제시함 |
| **시간 정보 (Temporal)** | `created_at`, `updated_at`, `year` | 구버전 정보 배제 및 최신 유효 문서 우선 선별 |
| **구조 정보 (Structural)** | `section`, `page`, `chunk_id` | 원본 문서 내 위치 파악 및 인접 문맥 역추적 가능 |
</aside>

### 3.2 텍스트 청킹과 메타데이터 보존 실습

<aside>

```python
# 텍스트 분할 도구와 Document 객체를 불러옵니다.
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_core.documents import Document

# 원본 문서 내용과 파일 메타데이터를 정의합니다.
raw_text = (
    "제1장 총칙: 본 규정은 컴퓨터공학과의 실습실 이용 규정을 명시합니다.\n\n"
    "제2장 이용 시간: 평일은 오전 9시부터 오후 10시까지 개방합니다. 주말은 미개방합니다."
)
file_info = {"source": "cs_lab_policy.pdf", "department": "컴퓨터공학과", "version": "v1.2"}

# 원본 Document 객체를 생성합니다.
original_document = Document(page_content=raw_text, metadata=file_info)

# 40자 단위로 분할하는 재귀적 분할기를 초기화합니다.
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=40,  # 한 청크당 최대 글자 수를 40자로 지정합니다.
    chunk_overlap=0 # 겹침 글자 수를 0으로 설정합니다.
)

# Document 단위로 분할을 수행합니다 (원본 메타데이터가 각 청크에 계승됩니다).
chunked_docs = text_splitter.split_documents([original_document])

# 생성된 청크별 메타데이터에 조각 순번(chunk_id)을 동적으로 추가합니다.
for idx, doc in enumerate(chunked_docs):
    doc.metadata["chunk_id"] = idx + 1 # 1부터 시작하는 순번을 부여합니다.
    print(f"청크 {doc.metadata['chunk_id']} 내용: {doc.page_content.strip()}")
    print(f"청크 {doc.metadata['chunk_id']} 메타데이터: {doc.metadata}\n")
```

```
청크 1 내용: 제1장 총칙: 본 규정은 컴퓨터공학과의 실습실 이용 규정을 명시합니다.
청크 1 메타데이터: {'source': 'cs_lab_policy.pdf', 'department': '컴퓨터공학과', 'version': 'v1.2', 'chunk_id': 1}

청크 2 내용: 제2장 이용 시간: 평일은 오전 9시부터 오후 10시까지 개방합니다.
청크 2 메타데이터: {'source': 'cs_lab_policy.pdf', 'department': '컴퓨터공학과', 'version': 'v1.2', 'chunk_id': 2}

청크 3 내용: 주말은 미개방합니다.
청크 3 메타데이터: {'source': 'cs_lab_policy.pdf', 'department': '컴퓨터공학과', 'version': 'v1.2', 'chunk_id': 3}

```

## 4. 메타데이터 필터링(Filtering) 원리와 실습

<aside>
💡

<u>**메타데이터 필터링은 검색 대상의 범위를 좁히는 '사전 거름망'입니다.**</u>
전체 데이터를 탐색하지 않고 조건에 일치하는 데이터만 선별하여 검색 정확도를 극대화합니다.

</aside>

### 4.1 필터링 메커니즘 (사전 필터링 vs 사후 필터링)

<aside>

<u>**사전 필터링 (Pre-filtering)**</u>

<aside>
메타데이터 조건을 충족하는 청크만 먼저 걸러낸 뒤 유사도 계산을 수행합니다.

</aside>

**<u>사후 필터링 (Post-filtering)</u>**

<aside>
전체 데이터를 대상으로 유사도 검색을 먼저 수행한 후 조건에 맞지 않는 결과를 버립니다.

</aside>

</aside>

### 4.2 조건부 메타데이터 필터링 실습

<aside>

연도와 소속 부서 속성을 기준으로 원하는 청크만 추출하는 로직을 구현합니다.

```python
# 다양한 메타데이터를 포함하는 청크 리스트를 생성합니다.
documents = [
    Document(
        page_content="컴퓨터공학과 전공자는 졸업 필수 요건으로 캡스톤 디자인을 이수해야 합니다.",
        metadata={"dept": "컴공", "year": 2024, "type": "졸업"}
    ),
    Document(
        page_content="컴퓨터공학과 전공자는 산학 프로젝트 또는 캡스톤 디자인 중 1개를 택할 수 있습니다.",
        metadata={"dept": "컴공", "year": 2026, "type": "졸업"}
    ),
    Document(
        page_content="경영학과 전공자는 전공 필수 36학점을 이수해야 졸업이 가능합니다.",
        metadata={"dept": "경영", "year": 2026, "type": "졸업"}
    )
]

# 필터링 조건 설정: 학과가 '컴공'이면서 최신 연도인 '2026' 데이터만 추출합니다.
target_dept = "컴공"
target_year = 2026

filtered_documents = [
    doc for doc in documents
    if doc.metadata.get("dept") == target_dept and doc.metadata.get("year") == target_year
]

# 필터링 결과를 출력합니다.
print(f"=== [필터링 결과: {target_dept} / {target_year}년도] ===")
for doc in filtered_documents:
    print(f"내용: {doc.page_content}")
    print(f"속성: {doc.metadata}")
```

```
=== [필터링 결과: 컴공 / 2026년도] ===
내용: 컴퓨터공학과 전공자는 산학 프로젝트 또는 캡스톤 디자인 중 1개를 택할 수 있습니다.
속성: {'dept': '컴공', 'year': 2026, 'type': '졸업'}
```

## 5. LLM 모델 연계 질의응답 실습

<aside>
💡

<u>**검색을 통해 엄선된 문서 청크와 출처 메타데이터를 LLM 프롬프트에 문맥(Context)으로 주입하여, 높은 신뢰도를 갖춘 답변을 생성합니다.**</u> 모델이 임의로 내용을 지어내지 않고 오직 제공된 사실에 근거해 명확한 출처(인용)와 함께 응답하도록 파이프라인 체인을 설계합니다.

</aside>

### 5.1 메타데이터 기반 출처 표기 질의응답 체인 구현

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0 # 답변의 무작위성을 배제하고 사실 기반으로 출력합니다.
)

# 필터링을 거쳐 선택된 2026년도 단일 문서 청크를 준비합니다.
selected_doc = filtered_documents[0]

# 출처 정보를 명시할 수 있도록 프롬프트 템플릿을 설계합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "제공된 [참고 문서]에만 근거하여 명확하게 답변하세요.\n"
        "답변 끝에는 반드시 [출처: 문서종류 (연도)] 형식으로 근거를 명시하세요.\n\n"
        "[참고 문서]:\n{context}\n\n"
        "[문서 메타데이터]: 학과={dept}, 연도={year}"
    )),
    ("user", "{question}")
])

# 프롬프트 -> 모델 -> 출력 파서 파이프라인 체인을 연결합니다.
rag_chain = prompt | model | StrOutputParser()

# 체인을 실행하고 결과를 확인합니다.
user_query = "컴퓨터공학과 졸업을 위한 필수 요건이 무엇인가요?"
response = rag_chain.invoke({
    "context": selected_doc.page_content,
    "dept": selected_doc.metadata["dept"],
    "year": selected_doc.metadata["year"],
    "question": user_query
})

print("=== [모델 답변] ===")
print(response)
```

```
=== [모델 답변] ===
제공된 문서에 따르면, 컴퓨터공학과 전공자는 산학 프로젝트 또는 캡스톤 디자인 중 1개를 택할 수 있습니다. 문서에 다른 졸업 요건(예: 학점·평점·필수 교과목 등)은 명시되어 있지 않습니다. 

[출처: 참고 문서 (2026)]
```

</aside>

## 6. 개념 체크 하기

### 6.1 개념 확인 문제

<aside>
💡

### 3.2 개념 요약 키워드

- **메타데이터(Metadata)**: 본문 데이터 조각의 맥락(출처, 시간, 구조)을 명시하는 추가 속성 정보
- **Document 객체**: LangChain에서 본문(page_content)과 속성(metadata)을 일체형으로 묶어 다루는 표준 구조체
- **사전 필터링(Pre-filtering)**: 유사도 연산 전에 메타데이터 조건으로 검색 대상을 미리 축소하여 검색 속도와 정확도를 향상하는 기술
- **출처 추적성(Traceability)**: 모델이 생성한 답변의 원본 파일 및 페이지 근거를 투명하게 검증할 수 있는 신뢰성 지표

### 3.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **메타데이터** | Metadata | 데이터에 부여되는 부가 정보로 작성일, 출처, 카테고리 등의 설명 속성을 의미합니다. |
| **도큐먼트 객체** | Document | LangChain에서 본문 텍스트와 메타데이터 딕셔너리를 함께 묶어 보관하는 표준 클래스입니다. |
| **사전 필터링** | Pre-filtering | 유사도 검색 전에 특정 메타데이터 조건을 충족하는 조각만 먼저 선별하는 방식입니다. |
| **사후 필터링** | Post-filtering | 유사도 검색을 먼저 수행한 뒤 반환된 결과에서 메타데이터 조건에 맞지 않는 항목을 제거하는 방식입니다. |
| **스키마** | Schema | 메타데이터에 어떤 속성 이름과 데이터 형식을 부여할지 미리 정의해 둔 구조 설계 명세입니다. |
