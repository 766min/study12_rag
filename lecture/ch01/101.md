## 2. LLM의 한계: 지식 컷오프와 환각

<aside>
💡

<u>**LLM은 학습된 데이터의 범위 안에서만 통계적으로 그럴듯한 문장을 이어 붙입니다.**</u>
학습 시점 이후의 최신 정보나 비공개 문서는 알지 못하며, 잘못된 사실을 지어내기도 합니다.

</aside>

### 2.1 지식 컷오프와 환각 현상의 이해

<aside>

<u>**지식 컷오프 (Knowledge Cutoff)**</u>

<aside>
모델 사전 학습이 끝난 기준 날짜 이후의 사건이나 최신 데이터는 기억하지 못하는 한계입니다.

</aside>

<u>**환각 (Hallucination)**</u>

<aside>
모델이 답을 알지 못할 때 공백을 채우기 위해 사실이 아닌 내용을 매우 정교하고 확신에 찬 어조로 왜곡해 출력하는 현상입니다.

</aside>

</aside>

### 2.2 model 호출 및 한계 확인

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

parser = StrOutputParser()

prompt = ChatPromptTemplate.from_messages([
    ("system", "당신은 질문에 솔직하고 정확하게 답변하는 비서입니다."),
    ("user", "{question}")
])

chain = prompt | model | parser

question_text = "2026년 스파르타대학교 컴퓨터공학과 1학기 축제 개최일과 초청 가수를 알려줘."
response = chain.invoke({"question": question_text})

print("=== [단순 LLM 호출 결과] ===")
print(response)
```

## 3. RAG(검색 증강 생성)의 원리와 기본 구조

<aside>
💡

<u>**RAG는 답변을 생성하기 전 외부 데이터베이스에서 관련 근거를 먼저 찾아 LLM에 제공하는 기술입니다.**</u> 이는 기억력에만 의존하던 기존의 '암기식 시험'을 필요한 책을 참고해 답을 작성하는 '오픈북 시험'으로 바꾸는 것과 같습니다.

</aside>

### 3.1 단순 질의와 RAG 방식 비교

<aside>

- **단순 LLM 호출**: 모델 내부 가중치(기억)에만 의존하여 답변을 생성합니다.
- **RAG 파이프라인**: 관련 문서를 먼저 탐색(Retrieve)하고, 확보한 근거를 프롬프트에 주입하여 신뢰성 높은 답변(Generate)을 생성합니다.

| **비교 항목** | **단순 LLM 호출** | **RAG 기반 생성** |
| --- | --- | --- |
| **정보의 최신성** | 학습 종료 시점(컷오프)에 머무름 | 최신 문서를 즉시 검색하여 반영 가능 |
| **비공개 사내 데이터** | 학습되지 않아 답변 불가 | 보안 문서, 사내 규정 문서 직접 참조 가능 |
| **답변의 근거 제시** | 출처 추적이 불가능함 | 인용한 원본 문서 출처 명시 가능 |
| **환각 발생률** | 모르는 질문에 환각 발생 가능성 높음 | 문서 내 사실에 기반하므로 환각 억제 |
</aside>

### 3.2 외부 문맥을 결합한 RAG 기초 파이프라인 구현

<aside>

검색기(Retriever)로부터 가져온 외부 문서를 프롬프트의 `{context}` 변수에 주입하여 사실 기반의 정확한 답변을 유도합니다. 

```python
# 외부 문서(Context)를 주입받을 수 있는 RAG 전용 프롬프트 템플릿을 정의합니다.
rag_prompt = ChatPromptTemplate.from_messages([
    (
        "system",
        "당신은 제공된 [참고 문서]의 내용에만 근거하여 정확하게 답변하는 전문 튜터입니다.\n"
        "문서에 나와 있지 않은 내용은 절대로 지어내지 말고 모른다고 답변하세요.\n\n"
        "[참고 문서]:\n{context}"
    ),
    ("user", "{question}")
])

# RAG 체인을 조립합니다
rag_chain = rag_prompt | model | parser

# 데이터베이스나 검색기로부터 찾아왔다고 가정한 외부 최신 문서 데이터입니다.
retrieved_context = """
[공지] 2026학년도 스파르타대학교 컴퓨터공학과 봄 축제 안내
- 일시: 2026년 5월 14일(목) ~ 5월 15일(금)
- 장소: IT융합관 앞 잔디광장
- 초청 아티스트: 뉴진스, 악동뮤지션
- 유의사항: 학생증 지참 필수
"""

# 질문과 함께 검색된 문맥(context)을 모델에 전달합니다.
rag_response = rag_chain.invoke({
    "context": retrieved_context,
    "question": "2026년 스파르타대학교 컴퓨터공학과 1학기 축제 개최일과 초청 가수를 알려줘."
})

print("=== [RAG 기반 생성 결과] ===")
print(rag_response)
```

```
=== [RAG 기반 생성 결과] ===
개최일: 2026년 5월 14일(목) ~ 5월 15일(금)
초청 아티스트: 뉴진스, 악동뮤지션
```

## 4. RAG와 파인튜닝 비교 및 선택 기준

<aside>
💡

<u>**파인튜닝이 모델의 '말투나 행동 양식'을 체화시키는 과정이라면, RAG는 모델에게 '새로운 지식 서가'를 주입하는 기술입니다.**</u> 따라서 해결하려는 문제의 성격과 데이터의 업데이트 주기를 고려해 적합한 방식을 선택해야 합니다.

</aside>

### 4.1 핵심 차이점 비교

<aside>

<u>**파인튜닝 (Fine-tuning)**</u>

<aside>
대량의 질의-응답 데이터셋으로 모델 파라미터(가중치)를 미세하게 재학습시키는 기법입니다.

</aside>

<u>**RAG (Retrieval-Augmented Generation)**</u>

<aside>
모델 파라미터는 그대로 두고, 검색 시스템을 연결해 외부 데이터를 실시간 주입하는 아키텍처입니다.

</aside>

| **비교 지표** | **RAG (검색 증강 생성)** | **파인튜닝 (미세조정)** |
| --- | --- | --- |
| **지식 갱신 주기** | 실시간 (새 문서를 DB에 추가하는 즉시 반영) | 주기적 재학습 필요 (모델 재학습 비용 발생) |
| **구축 비용** | 상대적으로 저렴하고 인프라 관리가 용이함 | GPU 학습 자원과 데이터 구축 비용이 큼 |
| **적합한 목표** | 최신 팩트 전달, 사내 규정 조회, 환각 방지 | 특정 어조·화법 습득, 고정된 출력 포맷 준수 |
| **출처 제공 여부** | 답변에 참조한 문서의 제목/페이지 표기 가능 | 모델 내부 기억이므로 출처 확인 불가 |
</aside>

### 4.2 실제 프로젝트 적용 가이드

<aside>

<u>**RAG를 선택해야 하는 경우**</u>

<aside>

- 매주/매월 제품 가격표나 사내 취업 규칙이 변경되는 경우
- 사용자가 모델 답변의 신뢰도를 위해 근거 문서 링크를 요구하는 경우
</aside>

<u>**파인튜닝을 선택해야 하는 경우**</u>

<aside>

- 금융·의료 전문 용어의 독특한 문체나 특정 페르소나를 모델에 이식해야 하는 경우
- 복잡한 JSON 스키마 규격을 오류 없이 엄격하게 준수해야 하는 경우
</aside>

### 5.2 개념 요약 키워드

- **지식 컷오프 (Knowledge Cutoff)**: 모델의 공부가 멈춘 시점으로 인해 최신 정보를 알지 못하는 한계
- **환각 (Hallucination)**: 모르는 질문에 대해 그럴싸한 거짓말을 지어내는 현상
- **RAG (Retrieval-Augmented Generation)**: 최신·외부 문서를 검색하여 모델에게 전달하는 오픈북 방식의 답변 기술

### 3.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **지식 컷오프** | Knowledge Cutoff | 인공지능 모델이 학습을 마친 기준 시점 이후의 정보를 반영하지 못하는 한계 |
| **환각** | Hallucination | 인공지능이 사실이 아닌 내용을 마치 확실한 진실인 것처럼 그럴싸하게 생성하는 현상 |
| **검색 증강 생성** | RAG | 외부 저장소에서 질문과 관련된 문서를 검색(Retrieve)하여 문맥으로 제공한 뒤 답변을 생성(Generate)하는 기법 |
| **파인튜닝** | Fine-tuning | 특정 도메인의 작업 방식이나 문체를 익히기 위해 기존 사전 학습 모델에 추가 데이터를 학습시키는 방식 |
| **모델 초기화 함수** | init_chat_model | 특정 벤더에 종속되지 않고 환경에 맞춰 LLM 인스턴스를 동적으로 생성하는 LangChain 범용 함수 |
