## 2. 청킹(Chunking)의 원리와 필요성

<aside>
💡

<u>**청킹(Chunking)**</u>
방대한 텍스트 문서를 정보의 손실 없이 처리할 수 있도록 일정한 크기의 조각(Chunk)으로 나누는 작업입니다.

</aside>

### 2.1 청킹이 필요한 기술적 배경

<aside>

<u>**입력 창 크기 한계**</u>

<aside>
언어 모델과 임베딩 모델은 한 번에 입력받을 수 있는 최대 토큰 수가 정해져 있습니다.

</aside>

**<u>의미의 선명도 유지</u>**

<aside>
너무 긴 문서를 통째로 임베딩하면 여러 주제가 섞여 벡터의 의미 표현력이 약화됩니다.

</aside>

**<u>검색 효율성 극대화</u>**

<aside>
질문과 연관성이 높은 핵심 문단만 선별하여 인공지능에게 전달하므로 응답 속도와 정확도가 올라갑니다.

</aside>

</aside>

## 3. 주요 청킹 분할 전략 비교 및 실습

<aside>
💡

<u>**분할 전략(Splitting Strategy)**</u>
문서를 자르는 기준에 따라 고정 크기, 재귀적 문자, 의미론적 분할 방식으로 구분됩니다.

</aside>

### 3.1 고정 크기 분할 (CharacterTextSplitter)

<aside>

지정된 글자 수로 분할하여 연산 속도는 매우 빠르나, 단어·문맥 단절로 검색 정확도를 떨어뜨리는 한계가 있습니다.

```python
# langchain_text_splitters 모듈에서 CharacterTextSplitter를 불러옵니다.
from langchain_text_splitters import CharacterTextSplitter

# 테스트를 위한 긴 문자열 데이터를 정의합니다.
sample_text = "청킹은 긴 문서를 작은 조각으로 나누는 과정입니다. 문맥 유지가 매우 중요합니다."

# 글자 수 15자를 기준으로 분할하는 고정 크기 분할기를 초기화합니다.
fixed_splitter = CharacterTextSplitter(
    separator="", # 특정 구분자 없이 글자 수 단위로 분할합니다.
    chunk_size=15, # 청크 1개의 최대 글자 수를 15자로 지정합니다.
    chunk_overlap=0 # 조각 간 겹치는 글자 수를 0으로 설정합니다.
)

# 텍스트를 분할하여 리스트 형태로 반환합니다.
fixed_chunks = fixed_splitter.split_text(sample_text)

# 생성된 청크를 순서대로 확인합니다.
for idx, chunk in enumerate(fixed_chunks):
    print(f"고정 청크 {idx + 1}: {chunk}")
```

```
고정 청크 1: 청킹은 긴 문서를 작은 조각
고정 청크 2: 으로 나누는 과정입니다. 문
고정 청크 3: 맥 유지가 매우 중요합니다.
```

</aside>

### 3.2 재귀적 문자 분할 (RecursiveCharacterTextSplitter)

<aside>

문단·문장·공백 순으로 구분자를 단계 적용해 의미 단위를 온전히 보존하므로, 범용 텍스트 처리에 가장 최적화된 표준 청킹 방식입니다.

```python
# 문맥 보존에 적합한 RecursiveCharacterTextSplitter를 불러옵니다.
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 문단과 문장이 포함된 실습 문서를 정의합니다.
campus_rules = (
    "제1조 (목적)\n본 규정은 장학금 지급 기준을 정의합니다.\n\n"
    "제2조 (선발 기준)\n직전 학기 평점 3.5 이상이어야 하며 F학점이 없어야 합니다."
)

# 문단과 문장 경계를 우선 유지하는 재귀적 분할기를 초기화합니다.
recursive_splitter = RecursiveCharacterTextSplitter(
    chunk_size=35,  # 목표 청크 크기를 35자로 설정합니다.
    chunk_overlap=0 # 겹침 글자 수를 0으로 설정합니다.
)

# 문서를 분할합니다.
recursive_chunks = recursive_splitter.split_text(campus_rules)

# 분할된 조각들을 출력합니다.
for idx, chunk in enumerate(recursive_chunks):
    print(f"재귀 청크 {idx + 1}:\n{chunk}\n")
```

```
재귀 청크 1:
제1조 (목적)
본 규정은 장학금 지급 기준을 정의합니다.

재귀 청크 2:
제2조 (선발 기준)

재귀 청크 3:
직전 학기 평점 3.5 이상이어야 하며 F학점이 없어야

재귀 청크 4:
합니다.
```

</aside>

### 3.3 의미론적 분할 (Semantic Chunking)

<aside>

<u>**작동 원리**</u>

<aside>
문장 단위로 분할 후 인접 문장 간의 벡터 유사도(Cosine Similarity)를 연속적으로 산출하며, 유사도가 설정된 임계값(Threshold) 이하로 급락하는 경계면(Breakpoint)을 탐지하여 청크를 분리합니다.

</aside>

**<u>기술적 특성</u>**

<aside>
청크 내 의미론적 응집도(Semantic Coherence)를 극대화해 검색 재현율(Recall)과 정확도를 향상하지만, 인덱싱 파이프라인 단계에서 다수의 임베딩 모델 추론이 강제되므로 레이턴시(Latency) 및 API 비용 부담이 수반됩니다.

</aside>

</aside>

## 4. 청크 크기와 오버랩 설정의 트레이드오프

<aside>
💡

<u>**트레이드오프(Trade-off)**</u>
청크 크기와 오버랩 설정값에 따라 검색 정확도와 모델의 문맥 이해도 사이에 상충 관계가 발생합니다.

</aside>

### 4.1 청크 크기(Chunk Size)와 오버랩(Chunk Overlap)의 관계

<aside>

- **청크 크기가 작을 때**: 검색은 정밀해지지만 문장의 앞뒤 인과관계가 누락될 수 있습니다.
- **청크 크기가 클 때**: 문맥은 충분히 유지되지만 질문과 무관한 문맥이 포함되어 노이즈가 발생합니다.
- **오버랩(Chunk Overlap)**: 앞 청크의 끝부분을 뒤 청크의 시작 부분에 중복 포함하여 경계면 문맥 단절을 방지합니다.

| **설정 항목** | **작은 값 설정 시** | **큰 값 설정 시** |
| --- | --- | --- |
| **청크 크기 (Size)** | 검색 정밀도 향상, 문맥 누락 위험 | 문맥 풍부함, 연산량 및 노이즈 증가 |
| **청크 오버랩 (Overlap)** | 중복 데이터 최소화, 경계 단절 위험 | 문맥 연속성 보장, 저장 공간 및 중복 증가 |
</aside>

### 4.2 오버랩 적용 분할 실습

<aside>

```python
# 문맥이 끊어지기 쉬운 연속된 문장을 정의합니다.
notice_text = "기숙사 입사 신청은 8월 1일부터 시작됩니다. 제출 서류는 건강진단서이며 보건소에서 발급 가능합니다."

# 청크 크기 25, 오버랩 10으로 설정하여 분할기를 구성합니다.
overlap_splitter = RecursiveCharacterTextSplitter(
    chunk_size=25,
    chunk_overlap=10    # 앞 조각의 마지막 10글자를 다음 조각 앞부분에 복사합니다.
)

# 텍스트를 분할합니다.
overlap_chunks = overlap_splitter.split_text(notice_text)

# 오버랩 적용 결과를 확인합니다.
for idx, chunk in enumerate(overlap_chunks):
    print(f"오버랩 청크 {idx + 1}: {chunk}")
```

```
오버랩 청크 1: 기숙사 입사 신청은 8월 1일부터 시작됩니다.
오버랩 청크 2: 시작됩니다. 제출 서류는 건강진단서이며
오버랩 청크 3: 건강진단서이며 보건소에서 발급 가능합니다.
```

## 5. LLM 모델 연계 질의응답 실습

<aside>
💡

<u>**문맥 주입과 답변 생성**</u>
분할된 청크를 프롬프트에 문맥(Context)으로 주입하고 LLM 모델을 호출하여 사실 기반 답변을 생성합니다.

</aside>

### **5.1 청크 기반 질의응답 체인 구현**

<aside>

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0          # 답변의 무작위성을 배제하고 사실 기반으로 출력합니다.
)

# 실습에 사용할 학사 공지 원문입니다.
raw_document = (
    "2026학년도 2학기 국가장학금 신청 안내입니다.\n"
    "신청 대상은 재학생 전체이며 직전 학기 평점 3.5 이상이어야 합니다.\n"
    "신청 마감일은 2026년 9월 30일 오후 6시까지입니다."
)

# RecursiveCharacterTextSplitter로 문서를 적절한 크기로 분할합니다.
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=50,
    chunk_overlap=10
)
chunks = text_splitter.split_text(raw_document)

# 질문과 가장 관련된 청크를 선택합니다 (여기서는 두 번째 청크를 사용합니다).
selected_chunk = chunks[1]

# 언어 모델에 전달할 프롬프트 구조를 설계합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", "제공된 [참고 문서]에만 근거하여 명확하게 답변하세요.\n\n[참고 문서]:\n{context}"),
    ("user", "{question}")
])

# 프롬프트 -> 모델 -> 출력 파서 파이프라인 체인을 연결합니다.
rag_chain = prompt | model | StrOutputParser()

# 체인을 실행하고 결과를 확인합니다.
user_query = "장학금을 신청하기 위한 최소 학점 기준은 얼마인가요?"
response = rag_chain.invoke({
    "context": selected_chunk,
    "question": user_query
})

print("=== [모델 답변] ===")
print(response)
```

```
=== [모델 답변] ===
직전 학기 평점 3.5 이상입니다.
```

### 6.2 개념 요약 키워드

- **청킹(Chunking)**: 긴 문서를 검색과 언어 모델 처리에 적합하도록 분할하는 전처리 과정
- **청크 오버랩(Chunk Overlap)**: 분할 경계선에서 문맥이 끊어지지 않도록 조각 간 중복 영역을 부여하는 기술
- **재귀적 분할(Recursive Splitting)**: 단락, 문장, 단어 순으로 구분자를 차례대로 적용하여 자연스러운 문맥을 유지하는 분할 기법

### 3.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **청크** | Chunk | 긴 문서에서 잘라낸 하나의 텍스트 조각 단위입니다. |
| **청킹** | Chunking | 텍스트 데이터를 검색 및 모델 처리에 최적화된 작은 단위로 나누는 작업입니다. |
| **청크 크기** | Chunk Size | 하나의 청크 조각에 포함될 수 있는 최대 문자 수 또는 토큰 수입니다. |
| **청크 오버랩** | Chunk Overlap | 청크 간 경계 단절을 막기 위해 앞뒤 청크 사이에 중복시키는 문자 수입니다. |
| **재귀적 텍스트 분할기** | RecursiveCharacterTextSplitter | 문단, 문장, 단어 순으로 자연스러운 경계면을 찾아 나누는 LangChain 표준 분할기입니다. |
