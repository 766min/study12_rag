## 2. 벡터 유사도(Vector Similarity) 계산 원리

<aside>
💡

<u>**벡터 유사도 (Vector Similarity)**</u>
텍스트를 변환한 고차원 숫자 배열(벡터) 간의 거리와 각도를 수학적으로 측정하여, 의미적 유사성을 판별하는 핵심 척도입니다.

</aside>

### 2.1 유사도 및 거리 측정 방식 비교

<aside>

<u>**코사인 유사도 (Cosine Similarity)**</u>

<aside>
두 벡터 사이의 각도 코사인 값을 측정하며, 값의 범위는 `-1`에서 `1` 사이입니다. 문서 길이 차이에 따른 왜곡이 없어 자연어 검색에서 가장 표준적으로 쓰입니다.

</aside>

**<u>유클리디안 거리 (Euclidean Distance)</u>**

<aside>
두 벡터 끝점 사이의 최단 직선거리를 측정하며, 값이 `0`에 가까울수록 두 데이터가 유사합니다.

</aside>

**<u>내적 (Dot Product)</u>**

<aside>
두 벡터의 방향과 크기를 동시에 반영하는 연산입니다. 단위 벡터로 정규화된 상태에서는 코사인 유사도와 수학적으로 동일한 결과를 냅니다.

</aside>

| **척도명** | **주요 계산 대상** | **결과 범위** | **자연어 처리 활용** |
| --- | --- | --- | --- |
| **코사인 유사도** | 두 벡터 사잇각의 방향 일치도 | -1 ~ 1 | 문서 길이와 무관하게 주제 유사성 판단에 최적 |
| **유클리디안 거리** | 공간 상 두 점 사이의 직선거리 | 0 ~ $\infty$ | 물리적 거리 측정, 크기 차이가 중요한 데이터 |
| **내적** | 방향의 일치도 및 벡터의 절대적 크기 | $-\infty$ ~ $\infty$ | 정규화된 임베딩 환경에서 초고속 유사도 계산 |

## 3. 벡터 유사도 연산 및 문맥 검색 실습

<aside>
💡

OpenAI 임베딩 모델로 문서를 벡터화하고, 3가지 방식으로 유사도를 계산하여 최적 문맥을 찾는 실습을 진행합니다.

</aside>

### 3.1 텍스트 임베딩 및 유사도 측정 코드 작성

<aside>

```python
import os
import numpy as np
from dotenv import load_dotenv
from langchain_openai import OpenAIEmbeddings

load_dotenv()

# OpenAI의 표준 임베딩 모델(1,536차원)을 초기화합니다.
embeddings_model = OpenAIEmbeddings(model="text-embedding-3-small")

# 데이터베이스 역할을 수행할 문서 청크 목록을 정의합니다.
corpus_documents = [
    "장학금 수혜 대상은 직전 학기 평점 3.5 이상이며 F학점이 없는 학생입니다.",
    "도서관 이용 시간은 평일 오전 9시부터 오후 10시까지 운영됩니다.",
    "수강신청 변경 기간에는 최대 3학점까지 추가로 정정할 수 있습니다."
]

# 사용자 질문을 정의합니다.
user_question = "성적 장학금을 받으려면 평점이 어떻게 되나요?"

# 질문과 문서를 각각 고차원 실수 벡터로 변환합니다.
query_vector = embeddings_model.embed_query(user_question)
doc_vectors = embeddings_model.embed_documents(corpus_documents)

# 코사인 유사도 계산 함수를 정의합니다.
def calculate_cosine_similarity(v1, v2):
    # 두 벡터의 내적을 각 벡터 크기(L2 Norm)의 곱으로 나눕니다.
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

# 유클리디안 거리 계산 함수를 정의합니다.
def calculate_euclidean_distance(v1, v2):
    # 두 벡터 차이의 L2 Norm(직선거리)을 계산합니다.
    return np.linalg.norm(np.array(v1) - np.array(v2))

# 내적 계산 함수를 정의합니다.
def calculate_dot_product(v1, v2):
    # 두 벡터의 단순 행렬곱을 수행합니다.
    return np.dot(v1, v2)

# 문서별 유사도 점수를 계산합니다.
cosine_scores = [calculate_cosine_similarity(query_vector, doc_vec) for doc_vec in doc_vectors]
euclidean_dists = [calculate_euclidean_distance(query_vector, doc_vec) for doc_vec in doc_vectors]
dot_scores = [calculate_dot_product(query_vector, doc_vec) for doc_vec in doc_vectors]

# 각 문서의 연산 결과를 비교 출력합니다.
print("=== [문서별 유사도 지표 비교] ===")
for idx in range(len(corpus_documents)):
    print(f"[문서 {idx + 1}]")
    print(f" - 코사인 유사도: {cosine_scores[idx]:.4f} (높을수록 일치)")
    print(f" - 유클리디안 거리: {euclidean_dists[idx]:.4f} (낮을수록 일치)")
    print(f" - 내적 결과: {dot_scores[idx]:.4f}")

# 코사인 유사도 기준 최적 문맥을 선정합니다.
best_index = int(np.argmax(cosine_scores))
selected_context = corpus_documents[best_index]
print(f"\n최종 검색된 최적 문맥: {selected_context}")
```

```
=== [문서별 유사도 지표 비교] ===
[문서 1]
 - 코사인 유사도: 0.3512 (높을수록 일치)
 - 유클리디안 거리: 1.1390 (낮을수록 일치)
 - 내적 결과: 0.3511
[문서 2]
 - 코사인 유사도: 0.0556 (높을수록 일치)
 - 유클리디안 거리: 1.3741 (낮을수록 일치)
 - 내적 결과: 0.0556
[문서 3]
 - 코사인 유사도: 0.3029 (높을수록 일치)
 - 유클리디안 거리: 1.1807 (낮을수록 일치)
 - 내적 결과: 0.3029

최종 검색된 최적 문맥: 장학금 수혜 대상은 직전 학기 평점 3.5 이상이며 F학점이 없는 학생입니다.
```

## 4. ANN(근사 최근접 이웃) 검색과 벡터 인덱스

<aside>
💡

<u>**근사 최근접 이웃 (ANN, Approximate Nearest Neighbor)**</u>
대규모 벡터 공간에서 전수 조사를 피하고, 오차 범위를 허용하면서 탐색 속도를 수천 배 향상시키는 고속 색인 기술입니다.

</aside>

### 4.1 완전 탐색(K-NN)의 한계와 병목

<aside>

<u>**전수 조사(Brute-force) 방식**</u>

<aside>
모든 저장 벡터와 질의 벡터 간 거리를 일일이 비교하므로 데이터가 늘어날수록 연산량이 선형적으로 증가합니다.

</aside>

**<u>성능 저하</u>**

<aside>
수백만 건 이상의 문서가 누적된 운영 환경에서는 질의 지연 시간이 급증하여 실시간 서빙이 불가능해집니다.

</aside>

</aside>

### 4.2 ANN 알고리즘과 벡터 인덱스 원리

<aside>

<u>**구역 분할(Clustering)**</u>

<aside>
벡터 공간을 사전 군집화하여 질의가 위치한 특정 영역 내부의 후보군만 압축 탐색합니다.

</aside>

**<u>트레이드오프(Trade-off)</u>**

<aside>
약간의 검색 정확도(Recall)를 양보하는 대신 검색 속도를 획기적으로 개선합니다.

</aside>

</aside>

## 5. 검색 문맥 연계 및 LLM 모델 답변 생성 실습

<aside>
💡

선정된 최적 문맥을 프롬프트에 주입하고,  LLM 모델을 호출하여 사실 기반 답변을 생성합니다.

</aside>

### 5.1 LangChain 체인 구성 및 응답 생성 코드 작성

<aside>

```python
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 사실에 기반한 정밀한 답변을 유도하기 위해 temperature를 0으로 고정합니다.
model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

# 검색된 문맥({context})과 사용자 질문({question})을 결합하는 프롬프트를 구성합니다.
prompt = ChatPromptTemplate.from_messages([
    ("system", "제공된 [참고 문서]의 내용에만 근거하여 정확하게 답변하세요.\n\n[참고 문서]:\n{context}"),
    ("user", "{question}")
])

# 파이프라인 연산자(|)를 사용하여 프롬프트 -> 모델 -> 출력 파서 체인을 조립합니다.
rag_chain = prompt | model | StrOutputParser()

# 검색된 문맥과 질문을 입력으로 전달하여 최종 응답을 생성합니다.
response = rag_chain.invoke({
    "context": selected_context,
    "question": user_question
})

# 생성된 응답 결과를 출력합니다.
print("=== [생성 답변] ===")
print(response)
```

```
=== [생성 답변] ===
직전 학기 평점이 3.5 이상(3.5점 포함)이어야 하며, F학점이 없어야 합니다.
```

    온도를 0으로 설정하면 확률적 무작위성이 최소화되어 제공된 근거 문서에 기반한 사실적이고 일관된 응답이 생성됩니다.

### 6.2 개념 요약 키워드

- **코사인 유사도(Cosine Similarity)**: 벡터 사이의 각도를 측정하여 문장의 의미적 유사성을 판별하는 척도
- **유클리디안 거리(Euclidean Distance)**: 다차원 공간 상 두 점 사이의 최단 직선거리
- **ANN(Approximate Nearest Neighbor)**: 속도 최적화를 위해 공간을 분할 탐색하는 근사 색인 기법

### 3.3 용어 사전

| **용어** | **영어 표현** | **설명** |
| --- | --- | --- |
| **코사인 유사도** | Cosine Similarity | 두 벡터 간 사잇각을 통해 방향의 일치 정도를 측정하는 의미 유사도 계산 지표입니다. |
| **유클리디안 거리** | Euclidean Distance | 공간 내 두 점을 잇는 최단 직선거리로, 수치가 작을수록 두 데이터가 가까움을 의미합니다. |
| **내적** | Dot Product | 두 벡터의 각 성분을 곱해 더한 값으로, 정규화된 벡터 환경에서는 코사인 유사도와 같습니다. |
| **근사 최근접 이웃** | ANN | 완벽한 정답 탐색 대신 허용 오차 내에서 가장 가까운 벡터들을 초고속으로 찾는 알고리즘입니다. |
| **벡터 인덱스** | Vector Index | 대규모 벡터 데이터를 빠르게 검색할 수 있도록 미리 공간을 나누어 구조화한 색인 체계입니다. |
